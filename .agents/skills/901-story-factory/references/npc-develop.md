# npc-develop — 已有重要人物的性格、动机与背景深化

## 触发与输入
- 用户要求深化已有重要人物，或现存人物即将承担重大故事决策、关系转折。
- 必须能识别该人物在 901 中的 **现有 ID / 唯一身份**，获得原团已核准事实、当前时间线言行/关系/经历、已知能力边界及相关原作移植范围。缺 ID 或身份混淆，先列待确认项；不可擅自创建一个新角色代替。

## 深化方向
1. **观察事实**：列出有来源的表现、言行、反复选择与现有关系。分开记录人物主观信念与客观历史。
2. **心理机制**：建立当前诉求、长期价值、恐惧、矛盾、行为习惯；可以保留未解之谜。不要为了“有深度”给每人补童年创伤、悲剧或终局秘密。
3. **关键场景反应**：给出 2—3 种条件式反应（受到帮助、失败、利益冲突等），解释为什么；不固化未来命运。
4. **背景补全**：只补对当前人物理解有实际用途、且不违反时间线和来源映射的事实。对未产生证据的候选过去标 `DRAFT`。
5. **能力边界**：允许记录人物已确认能力、已表现的风格和剧情所需能力约束；**不分配属性、技能、等级、特殊资源或战斗数值**。如能力需要新建/重构，交给 `901-character-builder`。
6. **交接**：在已批准路径存人物深化草案并注明证据、争议、待批准项；已有角色 ID 保持不变。

## 跨作品人物
先查看该人物在 901 中是土著改编还是穿越者，核对来源版本。只将已确认沿用的原作性格或经历作为参考；原作朋友、敌人、身世和能力不能自动进入 901。优先尊重 901 已经表现的行为。

## 检验问题
- 换成另一位相似人物会不会得到完全一样的回答？如果会，深化不够具体。
- 用已有场景重新解释其选择，是否与原记录吻合？
- 面对新证据是否能合理改变判断，而不会突然改变已确立的过去？
- 是否误把“需要更强的战斗力”转化成无依据的新能力？
