# 901 证据与时间线审查协议

## 三个互相独立的判断

1. **来源**（这句话来自哪里）：Approved 901 设定 / 原团记录 / 外部作品 / 推断 / 新增 / 未知。
2. **时间线适用性**（主张指向哪条故事线、哪个时间范围）：重开故事的切入点前历史、原团切入点之后的旧记录、重开故事的切入点后时间段（包含尚未发生的计划）。
3. **内容状态**（是否可以当作事实使用）：待创作、经审查、游戏内已确立、经授权进入正式 Canon。

不要把 `ORIGINAL_RECORD` 自动当成 `APPROVED_CANON`，也不要把 `ELIGIBLE` 当成 `ESTABLISHED`。

## 来源类别
| 值 | 可证明什么 | 不足以证明什么 |
|---|---|---|
| `APPROVED_901` | 已核准设定中明确陈述的事实 | 超出批准范围的推论 |
| `ORIGINAL_RECORD` | 原始记录中确实出现过这句话/行为/描写 | 角色台词必然真实；旧团后续必然重演 |
| `SOURCE_WORK_ONLY` | 相关影视/游戏/小说版本的来源设定 | 901 已经继承了该事实 |
| `INFERENCE` | 基于证据提出的合理解释 | 唯一正确的隐藏原因 |
| `NEW_901` | 本次创作新增候选 | 原作/原团的原始意图 |
| `UNKNOWN` | 暂无证据或无法判定 | 任意填补的许可 |

## 证据质量
- 按范围搜索权威资料；结果必须能返回实际定位。若没有行号，使用合法的章节/消息编号及短摘录，不发明行号。
- 对角色台词区别 `utterance`（某人说了）、`belief`（某人相信）、`world_fact`（世界客观成立）。
- 负面证据：“尚未在已检查范围出现”，不能写“原团绝不存在”。标明具体搜索覆盖范围。
- 重大主张优先关联两种可独立验证的材料；不足时明确不确定性，不为了补齐数量编造证据。

## 重开时间线
- 切入点须从项目中的实际批准说明取得；如未定位，**先 HOLD 时间线继承判定**。
- `PRE_CUT_HISTORY`：901 重开切入点之前的历史时期，包含已继承事实和拟加入该时期的原创候选；是否真的继承、批准或确立由来源、证据及 `content_state` 决定。
- `OLD_POST_CUT_REFERENCE`：**原团**切入点之后的旧记录，只供开发者理解人物、进行设计或审核兼容性；不会自动转为重开故事历史。角色若在新时间线得知其中内容，须有当前信息来源或已批准的记忆继承机制。
- `NEW_TIMELINE`：**重开故事**切入点之后的时间范围，包括已发生事件、当前状态与尚未执行的未来计划；此标签本身不宣称事件发生。
- 附上 `time_ref`（日期、相对顺序或证据对应事件；不知道填 `null`）。只在无法确定主张属于哪一时间范围时使用 `unknown`，不能因为原创仍为 `DRAFT` 就将已知时间写成未知。
- **逐条区分主张**：“甲已经决定明天查城门”可能是已记录的当前意图；“甲明天成功查到违禁品”仍是尚未发生的预设结果。两者的状态和证据不能混写。

## 示例（虚构，只演示审查方法）
输入：“某将领袭击商队，因此他一生仇恨商人。”
- `claim_1`: 袭击商队 → 若记录有对应消息，可为 `ORIGINAL_RECORD`。
- `claim_2`: 一生仇恨商人 → 单次袭击不足以证明长期人格，为 `INFERENCE`，需要人物档案/其他行为确认。
