# 跨作品改编审核：本土化与穿越

## 首先检查 901 已有版本
- 统一人物 ID，不允许只凭同名合并不同角色。来源角色、901 土著改编版、穿越版及复制体可能互相独立。
- 若某角色在901有明示身份/经历/性格/技能，901已经确立的版本优先于外部作品原设定。
- 若作品具有多个版本/时代/媒介，写明选用版本；无法定位就标 `UNKNOWN`，不补全原作细节。

## 逐字段映射
| 维度 | `adapted_native` 本土化 | `cross_world_arrival` 穿越 |
|---|---|---|
| 出生与成长 | 必须与901历史一致；原作过去需明确取舍 | 原世界历史可供本人记忆参考，须确认离开时点 |
| 身份与社会关系 | 901 职业、组织和亲属关系另行确定 | 不能自动把原世界人物一起带入901 |
| 能力 | 需适配901规则与已知战力 | 带入能力的保留、弱化、限制及代价须有依据 |
| 世界认知 | 以901经历形成的认知为准 | 初来时对901可能无知，后续依所获信息变化 |
| 到来机制 | 不需要跨世界机制 | 需要与世界既定跨界规则相容的解释 |

每维输出 `inherited` / `modified` / `excluded` / `unresolved`，并逐条附来源。外部作品资料缺失时停止具体还原，不假定“众所周知”可以替代证据。

## 引入整个势力
对 Overlord 等完整阵营的引用，额外检查：组织是否整体进入、有哪些成员、权力结构是否保留、后勤与领地、忠诚关系、内部情报、力量尺度。**阵营名字出现不等于全套原作人物与历史已经导入。**

## 示例（仅审查方法，不构成901事实）
某角色在原作与甲存在恋爱关系，901中已确立为本土出生但未确认甲是否存在。
审查结论：原作恋爱为 `SOURCE_WORK_ONLY`；901关系 `UNKNOWN`，不能写“二人在901必然相恋”。
