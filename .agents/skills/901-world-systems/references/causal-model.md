# 可游玩的最小社会因果模型

## 单条规则的最小结构
`参与者 → 需求/利益 → 可获得资源 → 制度、文化、能力与时空约束 → 可行行动 → 可观察后果`

每条 `causal_rule` / `causal_rules[]` 带 `basis_status`（`confirmed`、`inferred`、`proposed`）和 `basis_refs`（定位到实际证据，或包内 `confirmed_facts` / `inferred_rules` / `proposed_rules` 等前提的 ID）。一条规则同时依赖不同状态的前提时，逐一注明各前提状态，并以最弱的必要前提标注整条规则；缺依据的部分明确为原创假设，不能在后续场景中变成“已证实”。

例如（完全虚构，不是901事实）：某关口守卫要收通行费，商队为节省钱改走山道，雨季道路更危险，因此护送需求增加。这里足以产生交易、争执、护送和绕路的日常事件；不需要计算整国 GDP。

## 规则应回答的问题
- 角色为什么要工作或行动？其生存/地位/信念/关系需求是什么？
- 资源从何而来？谁在控制？若资源短缺，短期会影响谁？
- 法律、礼仪与习俗怎样限制行为？是否存在地区/阶层差异？
- 时间和消息怎样传递？距离、交通、语言、保密是否阻止即时响应？
- 变化如何落实为 GM 可叙述、可让玩家干预的事实？

## 地区差异的最小集
1. 生产与日常生计：主要工作和生活节奏。
2. 统治与纠纷处理：有权力的机构及其有效范围。
3. 交换与交通：当地获取物资的主要方式与瓶颈。
4. 人际文化：居民实际会如何称呼、交易、待客、庆祝、避讳。
5. 当前利益矛盾：即使玩家不介入也可能存在的普通问题。

只增加确实影响场景/角色决策的字段。没有证据时用“待设计”，不将真实历史国家的制度默认套用901。

## 世界事件的粒度
- 普通场景：根据地区规则临时裁定，不写宏观更新。
- 局部扰动：说明相关角色、短期变化、可能后果；不用后台模拟所有居民。
- 重大局势：交剧情规划模块；世界 Skill 提供约束条件，不替它编造幕后黑手。

## 常见失败
- 文化只有装饰性形容词，无法改变对话、规则或习俗。
- 每个普通委托都暗藏世界级阴谋。
- 用未给出的确切人口和粮价预测装作科学计算。
- 全大陆沿用一套制度，既有地域设定消失。
- 后台 NPC 瞬间得到距离很远、没有渠道的信息。
