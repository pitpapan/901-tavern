# 901 — 大陆社会逻辑与地区差异

**目标**：在用户授权范围内，建立有自身生计、文化、利益和对外联系的地区社会，从局部深入并逐步扩展世界。具体事件可以作为入口；建设范围也可以由地区自身的发展需要确定，无须每项内容对应当前玩家行动。细节深度服从本轮目标。起始资料已完成，不重新提炼 A 阶段，不建设人口/GDP/货物流量的完整自动模拟。

## 适用范围
- `generic_rule`：整理或创作可跨地区复用的制度、社会关系或因果机制，保留适用范围与地方例外。
- `region_extension`：完善一个地区的生态资源、经济生产、社会生活、政治文化及对外联系；可沿这些联系继续建设其他地区。
- `stress_test`：按明确检查目标检视已有社会机制；不作为前两种模式的固定后续阶段。
- 世界制度、文化与资源条件由本 Skill 处理；具体人物深化和幕后行动规划交 `901-story-factory`。一个事件可以深入讨论，但人物的下一步行动不自动成为地区建设的下一项任务。
- 不承担批量造人、机械数值构筑或酒馆打包；不自动创建代理、切换模型或启动其他 Skill。未来 Builder、`tavern-cards` 仅按项目已有授权使用，正式 Canon 的采用权限仍由项目规则决定。

## 执行流程
1. **定位相关资料**：沿真实仓库 `AGENTS.md`、`docs/901_skills_integration.md` 和当前项目入口，读取本轮所需资料。复用仍在上下文中的未改说明，按主题检索，避免全仓重读。区分原团事实、用户确认、已采用作者方案、推断与未采用提案；按条目处理后续修订，不用较早摘要撤销已有采用。时期、分支和人物知情分别保留。
2. **确定本轮建设主题**：选择一种模式，明确本轮要完善什么。剧情案例、地区经济文化、社会生态或向外扩展均可直接构成目标。用户已给方向时直接工作；普通可逆细节可提出候选，重大未决选择才询问。事实核查不得补造缺口；明确授权的创作可以提出 `proposed` 内容，无原团出处本身不构成 `needs_sources`。仅在所需事实或关键约束确实缺失时记录缺口，并继续不受影响的部分。
3. **连接关键社会关系**：用 `参与者/群体 → 需求与价值 → 资源、环境和制度条件 → 日常活动 → 社会后果` 解释关键联系。将被后续引用的因果规则保留 `basis_status`（`confirmed` / `inferred` / `proposed` / `unknown`）和 `basis_refs`，指向实际出处、采用记录或包内前提。普通风俗与生活描述无须逐句拆成因果链。详见 [因果模型](references/causal-model.md)。
4. **深入地区并沿联系扩展**：在本轮主题内联系生产、交换、居住、职业、公共服务、自然条件、习俗及群体差异，产出实质设定。利用旧事件时区分长期机制、特殊案件做法和人物临时决定；案例不能自动证明普遍制度。沿物资、人口、知识、文化或政治往来，识别值得继续建设的腹地和外部地区，优先衔接已采用地图与地点。远方未定时可保留有范围的候选，不复制帝都制度，不自动展开全部地区。允许平凡生活、文化意义和审美特色，不强制产生任务、秘密或危机。
5. **按需使用例子或检验**：普通创作不强制输出 `ordinary_day`、`disruption` 或独立测试报告。可以用一个生活例子说明设定；只有用户要求、存在具体不一致或确需判断某项因果关系时才做相应检验。选择 `stress_test` 时完成约定检查，不擅自增加另一项；示例不成为分支已发生事件，也不为使测试通过而补造制度。
6. **局部核对并结束当前主题**：写作时留意已知相关约束。只有用户要求审查、具体证据争议、实际连续性冲突，或重要采用/变更确需定向评估时才调用 `901-canon-review`；普通草案不默认送审。按本轮建设目标决定完成，不能仅因某个剧情案例已可运行就宣布地区建设完成，也不因世界仍有空白而无限追加任务。交付后按已授权范围继续或等待下一项。详见 [完成与交接](references/done-and-handoff.md)。
7. **保存可复用成果**：优先沿用现有作者文件；讨论阶段可用自然语言，只在保存或明确要求结构化输出时使用 [地区模板](assets/region-packet.yaml) 或 [通用规则模板](assets/generic-rule-packet.yaml)。保留关键来源、已采用范围、新候选和真正影响使用的未知项，不重复抄写全部历史或套满无关栏目。模板检验块未执行时保留默认 `null` / 空列表；它们不表示测试通过。`ready_for_review` 仅表示本次内容可供查阅，不触发审核、不代表通过或采用。默认保存草案，不覆盖已批准文件或运行包；已获授权的保存与采用不重复请示。

## 完成判据
- 本轮约定的主题已有可使用的具体内容，能够说明地区居民如何生活、资源如何联系、群体如何相处，以及相应差异与限制。
- 深入案例得到的通用关系和案件特例清楚区分；需要向外扩展时，已有少量明确联系或候选方向，无须一次完成大陆。
- 继承事实、采用方案、推断和新提案可区分；`basis_status` 保留完整因果关系的依据性质，不能仅凭前提已确认就将推导标为事实。
- 已有且适用的人口、尺度、货币和储备数值直接沿用；新估算明示假设。无须为填满模板建立全国物价表或完整模拟。
- 仅实际执行的检查报告结果。未执行的日常/扰动检验、没有安排的独立审核，以及本轮之外的世界空白，均不妨碍交付。
