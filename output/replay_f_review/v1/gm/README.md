## 剧情如何产生

世界书提供事实、制度和力量限制；人物资料提供NPC的性格、职责、目标、关系及可用手段；当前聊天和摘要提供此刻局面。主持将这些与御临风本轮的选择结合，裁定直接后果，生成NPC反应，并按实际经过的世界时间和消息推进有关外部行动。回复停在玩家能够继续回应的位置。

已完成的历史不会因为新选择而取消。御临风改变了报信方式，军官原有关系仍然存在，但是否冲突、受阻、被捕或获得帮助由新局面决定。NPC可以主动行动，势力也不会因主角暂不参与而停摆；它们的知识与资源仍受资料和已发生事件限制。原团未来作为作者参照，不能替代本分支的因果。

日常直接聊天。场景收束或重要变化后，用一份短摘要保留有后效的结果；需要从过去另选道路时使用酒馆原生Branch或Checkpoint。摘要加近期聊天承接下一轮，不要求你每轮维护JSON或核对全套事件表。
