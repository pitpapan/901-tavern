## 本版采用范围

帝国、旁线提供的制度和人物事实按同一世界整理；沐透与大墓地不作为整条剧情载入。高塔双潮、旧空间龙秘境仅悠悠幸存、美杜莎身份与忠诚、雷光职责及秘密情报部门、帝哈克亲缘、御临风主神来历与村庄软重启，均沿用已接受设定。

人物作者档案保存原线全时期证据，运行卡按T0或明确条件截取。后期身份、婚约、能力与原线结局不会因为存在于作者库便自动成为开局事实。资料不足的人物保持短档，原型参考与本团事实分开。梦境专属人物和世界条目不进入本版；原始归档保留。

## 审核时关注什么

- 世界书是否准确、主题划分是否合适，帝国和势力是否有足够具体内容。
- NPC是否有可辨识的行事、表达、关系和能力依据，是否把一次行为误写成恒定人格。
- 人物卡是否泄露后来信息、提前授予能力，或越过用户对御临风的控制。
- 身份归并、别名和真实资料缺口是否处理恰当；可按人物或条目直接提出修改。
