## 具体变化

- 普通背景人物默认用自然、简洁的现代汉语，按工作、关系和实际权限行动；不靠古装市井、江湖或官场套话塑造时代。既有人物的确证称谓、礼貌与半文言保留，不统一改声线。
- 中文双引号只用于真正说出口的话。地名、店名、术语与在逃等文字标注直接写；告示和书信默认由旁白概述，确有依据且需要逐字展示时使用标签和独立文字块。人物实际朗读才加对白引号。
- 玩家内心使用的【……】不挪给任务标题或公文。保留历史事件，但不模仿旧回复的错误语气与标点。新版提示自身的非对白装饰引号已清理。
