# 药品与休息隔离验收包

基于御临风2026-10-21初始卡及已确认的T0接口。世界书沿用008源卡的136条原entries与UID。本包只有御临风；安全休息室、完好2/B1/L6/A3、流风10/22、意志1/3均为合成验收夹具，不代表正式剧情事件。

初始库存沿原卡：雪莲子1、培元丹3、药A2、药B3、药C4。雷霆药剂数量未记，保持未知并要求补参。雪莲子标准动作；其余已接入药品缺省移动等效动作。药B立即移除至多5L；药C须明确选择严重伤害治疗或肉体异常处理，短休后触发；药A长休后移除至多力量+2的A。培元丹长休后移除合计力量值的伤害，按用户2026-10-23确认的A→L→B顺序，不叠加。雪莲子对流风恢复3，未自动加东方标记。

短休15分钟恢复1B。长休8小时恢复1意志、任选一项属性伤害1、按规则处理任选一项状态，并按流风条文回满。持续无行动的长休按完整15分钟实休区间累计B恢复，是本次实现对自然休息的组合解释，不是人物卡另有一条独立文字；长休不额外产生32次短休状态豁免。L两天含至少两次长休恢复1；A七天含至少七次长休恢复1。普通休息不等于剧情节点，不额外奖励或回满意志。

流风打坐每15分钟按敏捷+感知检定、按成功数恢复；双属性相加由用户2026-10-23确认。自然掷骰通过运行时骰源，验收不固定游戏骰值。

`work/rules_engine/gm_runtime/build-recovery.mjs`生成卡和`public/901-recovery-playtest/`。`recovery-live-setup.mjs`只经本机酒馆官方import/save接口新建独立卡及两个聊天，不覆盖旧擂台结果。`recovery-live-inspect.mjs`保存各阶段原始JSONL和摘要；`recovery-live-verify.mjs`核对刷新与同楼重生成前后完整MVU、世界书、部署文件及模型恢复。实际UI与运行记录单独保存在本目录，脚本检查不视为模型实测通过。

正式`901-opening-combat`只部署变化的JS代码及恢复依赖，不覆盖人物卡、聊天、设置、原baseline或scene-binding。前后哈希记录在`formal-opening-deploy.json`；后续三文件的事实投影修正记录在`own-condition-projection-deploy.json`。

现已支持一句声明按顺序执行多个明确的恢复动作，例如“服下培元丹，然后长休八小时”，整组原子提交，后续条件缺失时整组不执行。独立复合声明实测、刷新与重新生成去重证据位于相邻`recovery_sequence_20261023_candidate/`，保留本目录既有单步验收记录。
