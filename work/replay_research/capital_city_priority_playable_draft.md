## 一、先固定这一回合究竟有什么在逼近

本分支可由城内接应异常先启动，也可由峡谷外的护送线索先启动，不指定玩家分队。两处线索不需要全部由玩家取得；右近、哈克等人可以在自身真实职责内核对，但不会自动拥有另一地点的观察。

启用新场景前，主持用现有笔记确定三项：
1. 两武士和悠悠的当前位置、实际路线、已交代的接应时段；从已发生行程接续。不能从“本应翌日到达”直接变成此刻已经进城。
2. 凌迟在帝都现有接报驻处是否还留有经手者、哪些人还认可他的旧协查命令；若驻处已被接管，就呈现旧指示或已经失败的接应，不重造一个同功能秘密基地。
3. 己方哪支现有力量已在都内、哪项峡谷任务即将使其离开、哪种替代手段能否及时到达。保城缺口须具体，不把偌大帝都写成只有右近几人能守。

**紧迫性来自行程与调度相撞。** 当前护送若仍很远、己方能两头兼顾，这就是一项可提前处理的风险，不足以强迫帝取消峡谷布局。没有悠悠固定死亡倒计时，也没有“每查一条线索敌人便自动前进一步”的进度条。

## 二、场景一：城内收到一项不该悄悄办掉的交接

### 新拟的有限接应安排〔DRAFT〕

在未与实际分支冲突时，凌迟曾给现有驻处的经手者交代：在指定的下一次换岗时段，派一辆已有车辆或现有人手到本次入城城门外的实际接应口，接两名佩刀护送者及一位年幼同行者，再带到驻处等候；到达后先报自己这条经手线，不必等独立核问便继续交接。

这是凌迟借战争英雄声望、既有协查关系推行的一项越权接应尝试，不是帝已经批准了全城免检。经手者可能认为接的是主将要保护或核问的证人，是否明知违规、是否受控沿人物实际状态，不统一写成邪恶同谋。此处不新定全套城门制度；凡该现场原本需要核对、告知的步骤，都不能凭一句“达卡斯要人”当然跳过。

接应目的仅是把护送对象纳入凌迟仍可影响的交接与报讯链，具体由谁施法、传送何物、何时发动并不写在这项指示里。悠悠不必知道城内接应方式，她只沿已有托付理解赴都。新安排不改变两武士原本先到帝都附近的护送任务；他们是否继续随车进入，要看当时交接、风险和意愿，不强行进城。

### 可见开场

在已经有理由接触该驻处或其协作人员时，可以看见现有经手者准备车辆、询问外门接应口的当值人，或者向接待者要求：“人到了先送过去，别在这里另问一遍。”若现场没有玩家，右近实际派出的核查者或正在处理相同军务的欧基可遇见；没有这种接触，就不会凭空收到密报。

可查内容：

| 查问／观察 | 实际可得线索 | 限度 |
| --- | --- | --- |
| 为什么备车、接谁、何时去 | 本次接应人数、粗略外观、地点、约定时段、命令经手人；答不出的部分就不知道 | “年幼来客”不等于已识别悠悠或空间龙；备车本身不违法 |
| 是否确有此项上级授权 | 原经手者出示实际便条或口头指令来源；右近向真实负责者核对，并确认并无帝方给予的独占接收与封锁报讯权限 | 不凭笔迹立即证明全部伪装，不发明盖满官印的全案密信 |
| 与另一名独立见过交代的人核对 | 谁要求先报驻处、谁尚未收到通知、准备进行到何处 | 同一口令被转述十次仍是一项来源；分歧可能是误解而非人人撒谎 |
| 留意接应实际去向 | 若车辆或人员已走，可取得实际出发时间、前往接应口的目击；可在合法权限内叫停或另作核查 | 叫停一辆车只打断这一程；不直接使城外护送者停止或让全城接应网瓦解 |
| 既定受控守卫确在这条链上且出现异常 | 沿已采用催眠规则，由实际有资格者查出影响与当事人真实收到的命令 | 不自动把其他经手者判为受控；解控后也不赠送他从未知道的后手情报 |

欧基适合核对经手、跟踪已存在的交接；诺斯莉可按实际命令保护接应现场或报告者。二人已有正式官职，不当作随叫随到的私人帮手；具体到场与授权须成立。普通接待人可以把异议报上去，但不能因此拥有撤销全城军令的权力。

## 三、场景二：城外有一支没有跟随主力进入战场的护送队

沿原团#817—818和已采用调查稿：实际观察者可见主力与两名佩刀护卫带着的小个目标分开，听到相关称呼或前行指示。看不见、听不懂或距离不足就只报所得，不给作者镜头里的完整身份。

**这条分支新增的有限可查话语〔DRAFT〕：**护送者在实际收到交代或对接信使时，可以出现“先去帝都附近那个接应口”“对面有人按达卡斯的交代接手”之类的任务确认。若现场已设具体地标与时段，就使用同一地点和时段；没有掌握足够位置的旁听者只知道方向，不能自动画出精确路线。

原团“一个时辰后执行”原本是主力行动口信，不能机械当成悠悠一小时后死亡、到城或发动传送。新护送窗口是本分支按实际路程交代的安排；不为了赶上城内场景新增无依据的瞬间移动。

能够互相支持的证据是：护送从主战方向分离；可核对的城市方向／接应点；对同一经手线与时段的独立说明；城内确有对应接收动作。单凭两名佩刀者带着小孩，不能完成身份鉴定。

**若听到“空间龙”称呼：**报的是敌方这样称呼该目标。若已有真实能力表现或有资格的鉴识，才能进一步确认空间资质。即使确认，也不知道其身上封了什么、是否可自主发动、作用对象和触发条件。

### 不要求必须抓到护卫

可持续观察、从真实往返信使查问、向已经接触过的人核对、直接与护送对象接触，或只报告已有见闻。两武士不是为供口供而固定落单；他们也不必知道城内经手者全部身份或催眠情况。

护送改道后，报告保留最后位置与时间，不能继续用旧路线冒充实时位置。反之，跟踪取得可靠新位置就是实质成果，不临时让敌人再换一条不可追踪的路线以抹去成功。

## 四、场景三：将两处消息拼到一起，指出还剩多少处置时间

任何一条线先有可信警讯即可先报，不等完成整张证据网。

- 城内：右近或其他有权经手者收到交接异常，可以先保护人、暂停具体交接、核实来客与命令来源，再上呈。
- 城外：哈克核对军中部署与主力位置，黄翔沿已用渠道向右近报简情；实际可用的副官通信另按既有终点处理，不自动直连帝。
- 内容：谁看到什么、哪个接应口、何时观察、谁正在准备、到达时段的依据是什么、哪项知情仍只是称呼或推断、现有力量能做什么。

时间沿[行程稿](capital_travel_messages_draft.md)及已采用[第一案回令估值](capital_canyon_early_intervention_playable_draft.md)：黄翔接通短报10—15分钟；右近在场核对处理10—20分钟；宅邸至宫门30分钟；帝在宫中且急件通路正常时转递10—20分钟、简短决断10—20分钟。城内接收者不必等外线回令往返才开始职责内的保护。外线回令若沿已核实双向渠道，整套约110—150分钟，另加找人、实体材料与实际位置路程。

同一接应口若就在本次入城城门外，可用门口至医馆30分钟、医馆至宅邸60分钟这一已知路线作为步行绕行参考；若有更直接已知路线，以实际可行行程为准。不能从“城内”一词推定几分钟就能到。护送队的剩余旅时按最后位置、实际交通与道路估计，不把黄翔马车速度套给徒步护卫。

### 紧迫性应呈现为三个实际时点

1. 护送队根据已见位置最早何时可能到接应区域。
2. 现有可处理对应威胁的力量，何时将按旧命令离都、进入外线不可及时折返的位置，或被另一项实际任务占用。
3. 别的可用力量与鉴识者最早何时能真正接手。

这些时点允许修正，但须由新的行程、消息或改令解释。对玩家给足当前可知估计，不把幕后提前准备的时间当突然宣布的隐形死线。对未知传送机制，不能凭一项估计宣称全城将在某刻毁灭。

## 五、什么条件足以让帝优先保城

帝先区分“必须处理的局部异常”和“必须牺牲峡谷收益的调度冲突”。

| 已知情况 | 相称选择〔新增DRAFT〕 |
| --- | --- |
| 只有一项越权接应，护送关联未明 | 核查接应、恢复独立报讯、保护相关人员；通常不足以放弃峡谷围剿 |
| 城外护送与城内接应有独立印证，但留守足以处理且有时间核实 | 两头兼顾，调整具体负责者；不能硬造兵力不足迫使选第二案 |
| 关联可靠，目标及高危护卫正逼近，接应会绕开己方既定核查；关键处置力量若按旧令离开，另一力量来不及补位 | 留下或调回确能赶到的力量处理帝都方向威胁，缩减峡谷完整围剿；接受敌军少受消耗、部分目标可能逃离的代价 |
| 交接已完成、来客身份和能力未明，既有记录又被实际截留 | 先恢复对具体人员与物件的掌握、保护并鉴识；不凭“可能已入城”便全城封锁或默认大批民众受控 |
| 真正查出咒术生命代价、死亡触发或其他新机制 | 只针对已证部分改变看护和处置，接既有悠悠／求治稿；完整结论未得时不宣称早已掌握 |

第三行是本分支足以改变布局的核心。它不是一个默认成立的兵力缺口：主持必须指出实际任务、所需能力、被抽走的人和来不及替代的原因。例如右近或原已安排承担特定高阶目标拦截的现有力量正在被调往谷外，而普通留守只能控制交接点、无法承担已知护卫的强行突破；是否确实如此，要与当前部署和能力相符。帝都其他高手若有时间、有渠道而且愿意／获命承接，就承认可以兼顾。

**为什么此时还要提前限制凌迟？** 城内核对若明确下一段接收、调人或送往驻处仍在等凌迟本人及其经手线的指示，撤回其对应协查、接收与调动权便有立即效果。若命令已经送出，控制其本人也无法取消已发指令，须另行撤令、通知现场。只有护送危险、没有凌迟仍可影响交接的证据时，帝可以先处理护送而暂不拘捕；不能以保城为由自动跳过拘捕的具体判断。

帝在实际认为两头不可兼顾时，可给出简短理由：“谷外先守住来路。此处的人，先留下。”是任务优先级改变，不是宣布他过去全不知情或已洞悉死亡传送。

## 六、改令：切断实际接应机会，保留必要防务

本篇可用命令〔DRAFT〕分四项落实，不要求一次全部下达：

1. **城内交接。** 停止该项以达卡斯名义提出的排他接收和封锁报讯；实际接收地点、经手者和来客行踪向指定负责人直接报告。遇到现有命令矛盾，核明来源与范围，不以英雄声望压过帝新令。正常守备及不相关来客事务继续。
2. **现场力量。** 明确谁暂不赴峡谷、谁到已知接应区域、谁负责保护与询问、哪项原任务缩减。右近、欧基、诺斯莉等按真实职责及所在选用，不自动全体到场；已经在外线者按真实折返时间计。临时保留一支力量，不等于帝都所有军队都围住一个孩子。
3. **凌迟指挥。** 撤回本次涉接应的调动与接收权限；根据实际证据与可用力量，要求其说明、留在指定位置或接受控制。哈克和副官承担各自收到的军令，不因需要保城就凭空有足够战力生擒他。峡谷方面可转为阻截、侦察和保护已出动部队，不将改令写成全军原地消失。
4. **接触对象。** 先辨认护卫、普通同行者、受托来客与实际施术者，制止正在发生的危险。未确认悠悠身份时不凭银发或年龄抓错人；已接触她时说明保护、核问与限制的真实范围。若必须限制自由，明说其原因，不能以“请休息”掩盖拘束。

识别为幼年空间龙不等于认定她是知情同谋。她可以说自己答应来帝都、等待咒文起作用，但不能被主持写成知道传送端点、军队规模或黄祸所有安排。医者先按已采用资料分项检查；未得死亡触发结论前，安排活体核查、避免无必要致命冲突是合乎任务的谨慎，不假装帝已知道杀她会发生什么。实际查明死亡触发后，再把禁止致命处置的明确理由传给需要知道的人。

截断接应车辆、改变落脚点或带离城门，分别只改变该项交接与位置；不等于解咒，也不保证任何城外地点天然安全。原本没有处死命令，就不虚构“撤销处刑”。

## 七、凌迟如何应对

| 他实际收到的变化 | 可采取的行动〔DRAFT〕 | 不能自动发生的事 |
| --- | --- | --- |
| 接应口要求补充核问，经手者来询问 | 用“保护证人／避免走漏军情”解释原指示，要求直接交给自己；可能只以为地方经手者过分谨慎 | 不立刻知道帝已将两处消息对上，不能读到所有报告 |
| 证实接应者受查、己方报讯线被切断 | 取消还来得及取消的交接，另告已有联络者等待；尝试利用剩余合法关系重新接触来客 | 不新增备用密站、无限催眠者或自动知道来客新住处 |
| 得知原定帝方力量未赴峡谷、城内接应被接管 | 判断帝正在防备另一条线，争取让外线制造压力，或以“错失战机／工兵待援”要求恢复原安排 | 若要催主力行动须真实传令，敌军不凭他的念头改变行军 |
| 相关权限被撤、尚未被控制 | 维持英雄姿态要求解释，反咬调查者搅乱军务；也可争取离开、亲自交代或转移仍在手里的物件 | 旧遇刺协查令不能自动覆盖新限制，声望不等于合法无限权力 |
| 被拘捕或判断无法争回交接 | 保留实际未暴露信息、要求谈判、接受看管或尝试真正可行的脱离 | 不能宣称拘捕必使所有后手更成功，也不能凭更大布局保证处死／不处死都中计 |

对悠悠的托付仍可被他重申，但只有她实际收到联系才影响她。若他知道她求医，也不自动知道诊断进度。凌迟与黄祸的信息分开；被捕后不能照搬原线#1110的狱中会面，须有实际接近、看守与通信条件。

## 八、黄祸如何处理护送受扰

**起始知情〔本分支DRAFT的有限补足〕：**黄祸知道护送要与正面主力分开，前往帝都附近一个约定接应方向；城内交接由凌迟一侧负责。他知道应等护卫或既有联络者回报，不掌握每名经手者是否受催眠、每项军令或帝的调度。

黄祸只有通过实际会面、信使、目击或已建立通信获知变化后才反应。失约首先是失联，不自动等于护送失败；他是否本人赴接点还受其在正面主力的职责与行程限制。

| 查到的真实情况 | 条件式行动〔DRAFT〕 | 留下的损失／未知 |
| --- | --- | --- |
| 护送只迟到，仍与两武士同行 | 核实通路与下一次联络，转告新位置或暂候；有可行道路时再决定继续 | 旧窗口可能过期，不能说延误本来就是安排 |
| 原接应口被实际控制，悠悠尚在城外 | 与护卫确认就近等待、绕开暴露接点或改变会合；以现有人手与道路安排 | 不能凭空再开一条全都已布妥的接应线，绕路需要时间且可能被追查 |
| 接应车被拦，但未找到护送者 | 查最后联系和真正去向，不急着带全军营救不存在的俘虏 | 不会知道玩家所有分组，也不能感应悠悠所在 |
| 悠悠被军方或医者接走，具体处置不明 | 查谁接手、是否仍安全、是否可以联系；可暂不强夺以免继续暴露 | “被接走”不证明已到适合施术的位置、能力仍完好或帝不知风险 |
| 得到可信消息：她在帝都、仍相信托付 | 可能认为局部计划尚有机会，隐蔽观察并回报 | 这只是他的判断；保护与鉴识同样可能破坏后手，不预定有利结果 |
| 确知她获知新的危险、接受治疗或拒绝继续赴都 | 尝试实际可达的联系、说服或调整尚可调整的协作；联系不了就承认 | 不因她拒绝便宣布咒术解除，也不远程加速其病情；治疗真正成功时损失必须保留 |
| 知道凌迟已被控制 | 权衡保住现有执行条件、救援可行性与自身风险，再决定行动 | 不默认必去劫狱，也不照搬原线不营救；更大任务内容未定，不借此新增万能后手 |

黑白武士有自己的责任和判断，不是黄祸一声令下便同时丢下悠悠。他们在自己先看到接点异常时可以先处理安全与联络，不必等黄祸远程批示；黄祸也不能无条件替二人承担全部选择。

原计划受扰造成的改道、延误、暴露、对象重新建立关系，都是真实损失或新局面。敌方可以利用偶然，但不能事后把玩家改变的一切写成凌迟预谋。

## 九、接续与收束

- **接应被切断、对象尚未接触**：记实际控制的接点、最后路线与未知去向；保城调度可暂时维持，继续有限查找。没有找到悠悠也能完成“阻止未经核对的交接”这项成果。
- **接触悠悠且暂时安全**：进入既有[悠悠接触](capital_yoyo_playable_draft.md)与[求治](capital_curse_playable_draft.md)，从真实知情开始。她不是一份自动交接的奖励，不预定跟随御临风、获救恩情或同意全部检查。
- **城内可以兼顾**：帝仅调整局部安排，峡谷仍按实际条件推进；调查依然产生价值，不能判为玩家没有触发正确分支。
- **保城成功而敌军撤离／凌迟脱身**：承认放弃了围剿或生擒机会，后续防务与追踪继续，不为了弥补战果再造一场相同峡谷决战。
- **改令晚到或只到一处**：分别处理已进入峡谷的部队、仍在城内的力量和已经出发的护送；不得瞬移回收部队或同步让敌我双方知道新令。
- **对象已经自行入城、原接应失败**：沿她实际同行者与落脚点核实，不能因为备选协会入口好用就覆盖已经建立的路线。入城不自动触发咒术或让黄祸认定大功告成。
- **玩家不参加或只交线索**：既有人物按获得的信息行动，不要求主角团包办两地；没有查到的事实也不会被NPC自动免费补齐。仍允许主角团选择其他事务。

resolution_conditions：已经形成有限核查、保城改令、接触保护、失败交接或失去接点等可交接结果；不以解咒、查清更大布局、捕获黄祸或消灭魔兽军作为本段完成条件。
