# 901 帝都重玩防幻觉 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留自由重玩的前提下，减少无据背景和身份混同，并控制错误进入分支记忆。

**Architecture:** 先用人工选择的场景事实包和唯一记忆来源完成M1；随后可选增加只读结构检查与有来源的语义审核M2；验证实际生成及保存接口后，才考虑展示前拦截M3。每层独立可回退，作者事实不由生成器或审核器改写。

**Tech Stack:** 现有Markdown/JSON/JSONL与SillyTavern 1.19.0；M1无额外服务。M2优先Python标准库做只读检查；审核模型、渠道及M3接入方式在对应阶段凭真实接口确定，不预设新模型或新依赖。

**Spec:** [同目录设计草案](design.md)。用户随后要求实施并选择先做通用包、不固定当前场景。M1离线文件已准备；实际酒馆应用、请求载入及当前记忆开关未验。复选框只表示相应资料工作已完成，不代表安装或模型效果通过。详见delivery_status.json。

5. 超时、审核不可用或遗漏生成入口：任务6、7只报告限定覆盖，不无限重试或静默放行。

**Files:** 先完成compatibility.md与本阶段单独的接入规格；只有接口被证实后才创建独立扩展或中间服务候选，不能先写一个默认有效的占位拦截器。

- [ ] 优先评估能在展示和保存之前暂停的本地扩展入口；若只有生成后通知，就不得冒充拦截。再评估能缓冲响应的中间层；不支持时停留M2，不为交付强行改变用户后端。
