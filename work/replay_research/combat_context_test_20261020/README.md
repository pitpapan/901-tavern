# 901战斗上下文补丁实测

2026-10-20，用户授权“保存和commit，然后替我测试”。补丁先提交为 `0e9e38e`，再在本机SillyTavern 1.19.0中新建独立测试卡及聊天。测试模型沿用现有连接 `gemini-3.5-flash-lite`，未更换模型、修改正式人物或正式存档。

## 结果

**历史过滤通过，选招与能量扣减通过；短指导不能保证完整动作记账。** 全局《开拓者》世界书给901测试带来了大量额外上下文及变量更新指令。

| 检查 | 实际结果 |
|---|---|
| 本地正则检查 | 11项通过，调用本机SillyTavern实际的`getRegexedString`／`runRegexScript`函数；仅外围UI设置使用替身。 |
| 真实发送提示 | 两次生成的复制提示中，旧计算标记均消失；旧结果、旧状态、最近计算及当前状态标记均保留。 |
| 指引加载 | 两次实际提示都包含共用短指导及标签格式要求。 |
| 显示与保存 | 聊天显示仍可见旧计算；磁盘JSONL保留原有标签和计算文本。安装卡内的正则与补丁一致，角色正则启用状态已保存。 |
| 模型选择能力 | 两次都选择了能打断8米外弩手的“震响”，没有选择超出2米射程的普通剑击。 |
| 能量与结果 | 两次都将能量由2/3扣至1/3，并描述攻击被打断。未替御临风新增行动。 |
| 计算格式 | 首次虽使用完整标签，但块内主要是能力说明，未给出扣减算式；第二次原文使用完整标签并写出`2 - 1 = 1`，剩余能量在块外。 |
| 动作记账 | 第二次把“使用标准动作”写在可被过滤的明细块中，没有在块外明确留下标准动作余0。两次都写了“踏前一步”，未说明是姿态描写还是位移；测试卡的移动动作余0，不能据此确认位置保持不变。 |

本测试没有加载engine或MVU执行脚本，能量与动作均为模型文本裁定。它验证提示加载、正则过滤与一个简单选招场景，不证明特殊能力、自动扣费、冷却或状态接口已经完成。动作额度与实际位置仍应由结算及状态接口核定。

## 全局世界书干扰

首次测试保留用户原设置：全局启用《开拓者-失落之地V1.1-世界书》。原始发送提示含PF1e和`UpdateVariable`指令，回复末尾输出了额外的变量分析及空JSONPatch。

仅临时取消该全局书选择，对同一次玩家请求重新生成：

| 酒馆提示词窗口读数 | 原全局选择 | 临时取消后 |
|---|---:|---:|
| 提示总token估算 | 189,124 | 2,440 |
| 世界书token估算 | 133,961 | 1,700 |
| 扩展部分token估算 | 54,423 | 0 |
| 复制到剪贴板的原始提示字符数 | 100,447 | 7,228 |

这些是SillyTavern界面估算与复制文本长度，不是模型供应商的计费token。大幅减少来自取消全局《开拓者》加载，不能归功于这条历史正则。第二次提示不再包含PF1e或`UpdateVariable`，回复也不再输出变量更新块。

测试结束后，已恢复全局选择，并从保存的设置读回确认仍为《开拓者-失落之地V1.1-世界书》。因此这个跨卡加载问题仍存在于原配置；本次没有永久调整用户的全局运行方式。独立测试卡和聊天保留供复查。
