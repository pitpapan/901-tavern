# 2026-10-05定点修订：普通人物语域与对白符号

来源为UCL_20261005_001。用户明确确认样例在完整应用r2后生成，按此状态继续修订；不再归因为尚未更新。实际完整模型请求未读取，因此不声称已证明模型内部原因。样例不收入正典。

## 具体文件缺口

1. r2文风与主持符号段只说明双引号表示说出口的话，没有规定其排他用途。文风本身又用双引号标帝、右近、风貌分类、形容词和本能反应等非对白内容，主持提示也用双引号标突然领悟。新版清掉这些装饰用法，唯一保留的一对仅说明对白符号本身；并明确文书、专名、强调和玩家内心的不同呈现方式。
2. r2规定幻想帝国陈设与机构边界，但没有明确普通背景人物的默认中文语域和正式文书的表现方式。新版让普通NPC按自然、平实的现代汉语说当前事情，正式感依职责、态度与已证权限呈现，不成套移用古装市井、公案或官场模板。既有角色确有的称谓、礼节、半文言仍保留。
3. 旧聊天仍含错误的语气和标点。新版明确保留已成立事件，不照搬其表达习惯；这项只约束新回复，不自动改聊天、摘要或角色事实。

这次是对r2实际反馈的针对性修订。古风问题此前已修过，继续叠加泛化风貌标签不足以回答这次反馈，因此本轮改的是默认人物语域、文书写法和符号语义。没有改采样参数、插入额外高优先级模块、创建大测试矩阵或再次启动自动文风复跑。
