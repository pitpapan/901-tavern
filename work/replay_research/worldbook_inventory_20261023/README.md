逐项表采用三档，均是准备/调用建议，不是新的启用开关：

- **A 开局准备优先：10条。**妄想大陆、大陆法则限制、飘零大陆、帝国、帝都、第一次魔兽大侵攻、弃风剑、黄泉、布莱特、901通用事实与边界。先抽必要摘要并处理其中旧口径，不将10条全文都设常驻。破关幕后真相不直接变成主角记忆。
- **B 帝都篇按需：74条。**报信、协会、医馆、修理、求治及相关任务按实际行动触发；包括需要时手动启用的后台和未实名人物。B不表示都在城门或都必须出场。
- **C 后续/旁线：52条。**远方城市、龙族、古史、旁线研究等继续可查。若玩家当下真实涉及它们，可以提前调用，不把分类变成禁止探索。

御临风不必新增一条与Persona重复的人物世界书。其身份与玩家控制沿现有Persona，开场机械资源沿新初始卡，进行中的伤势与库存沿本聊天状态；三者不得互相整份覆盖。

## 重复与名称边界

- **空间龙旧事**同时见于空间龙部族、空间龙秘境、空间龙部族覆灭及悠悠等人物材料。完整因果主要维护在历史条目；种族/地点/人物保留理解自身所需的短摘要。族长与凌迟反击先后的来源差异不能在去重时抹掉。
- **古代精灵古史**分布于古代精灵社会、永恒之井、灾变、内乱、腰带、Faer。可减少同一段转述，但灾变与内乱的次序尚未统一，不能为压缩合成一件确定事件。
- **帝与右近知情**在帝国、军令、人物帝、人物右近及专门后台重复。当前剧本维护T0知识基线与后续变化，人物条目留必要定位，避免旧副本把知情重新拉回T0。
- **假面与公共生活**分别在八柱将/帝赐假面、帝国/帝都市政/工坊等重复。保留简短交代，完整机制与服务边界各有主要维护处。
- **世界树**已经是YGGDRASIL的触发别名，后续作者资料又有本土世界树。导入后者前需要区分名称或触发条件，不能让一次提及同时当成游戏原乡与本土地理。
- 高等评议会与魔兽最高评议会、空间龙秘境与龙族秘境、真达卡斯与凌迟、城门接报队长与怪眼队长都不是应合并的重复条目。现有手动启用项继续保留其身份确认用途。
