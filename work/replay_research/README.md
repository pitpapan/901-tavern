## 已固定的整理原则

御临风由主神带来异界，早期接收主神任务；从村子开始软重启，主神与幻剑机制直接移除，早期经历仍然保留。异乡龙血采用用户对“华夏人都是龙的传人”的解释。既有帝哈克亲缘、情感交易、师承和军籍不再重选。

高塔受到魔物与魔兽之潮双重冲击；美杜莎是Phantom且忠于白魔；雷光对白魔的职责、专队和自有秘密情报部门按明确补充保存。欧基、欧吉尔德、沐透分别是不同人物。其他已确认事实和逐字来源见[user_clarifications.md](user_clarifications.md)，不以旧研究措辞覆盖新说明。

事实有效时期、人物知情时期和本次分支分别保存。原线后期能力、婚约、战争成果不能整组提前进入T0；开局后的御临风行动与成长由用户选择，同伴按原模板和实际条件发展。固定历史和自主事件保留，新选择只重评真正受影响的因果。
