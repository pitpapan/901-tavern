## 一、开启这一分支时的现场

最佳入口是已与哈克取得联系、主力尚在宿营或谷外行进，工事先行、下一步进入峡谷的命令仍可改变。沿既有场景保留工兵约四十、安装法师四名、两侧哨兵与真实施工位置；不另外生成一批“知道真相的法师”。已经发生的毁阵、暴露、行军与伤亡优先。

主持开场前在现有笔记写清：主力目前在哪里，已传达的下次行军时点，两阵分别做到哪一步，谁在工地／营地，黄翔如何联系右近，副官此刻能联系谁，以及哪些接管力量确实可用。这是当前事实，不要求写分钟级系统。缺乏原线精确时刻时按当场进程给合理估计，在玩家选择之前确定，不故意设成无论怎样都迟一分钟。

哈克能直接交代：“工事先去了。下一道命令是进谷；哪一段已经能用，我这里还没有核准。”可沿旧稿告知目前命令是次日清晨迎敌。玩家不调查时，施工与军令照已有原因推进；本分支不会凭空送来完成的帝令。

这条分支也可以在行军途中开启，但越接近谷口，越可能只有局部暂停和撤离来得及。若主力已进入两阵范围，改接已有交战／救援稿，仍可提前介入，不能倒写为战前阻止。

## 二、场景一：把“有魔法工事”查成具体撤离风险

### 可见事实与线索

| 接触途径 | 可取得的具体内容〔新DRAFT〕 | 能证明什么／不能证明什么 |
| --- | --- | --- |
| 从实际观察点查看施工 | 岩壁与地面各有相连阵段，几处回路往谷口和上方延伸；现场有人逐段核对，部分施工已收尾。可摹下看得到的纹路、节点和地形对应关系 | 给出实际布置与进度，不能仅因规模大便判定用途、启动时刻或敌我白名单 |
| 问既有工兵自己的任务 | 他可以指认自己搬过的预制部件、交接给谁、哪段尚未完工；没有完整阵图和敌方全盘计划 | 帮助找到经手人及未完成部分，不把工兵口供当魔法鉴定 |
| 接触四名安装者中负责供能接驳的一人 | **本分支新增固定知识**：他知道自己这一组预制供能如何接好、节点在哪里、开启后不用一直守住；知道口头安装交代是“封住整片作战区的出入，另一道处理跨界移位”，但不能重制整个传奇术式 | 是启动与撤离风险的第一手技术证言；不证明幕后制造者、谁被指定牺牲或每种能力都会被封 |
| 有资格者检查足够的阵段与节点 | 能核对实体边界与空间边界的不同作用，指出己方原撤离／传入路线是否跨过对应边界；可指出某段真实破坏是否会使其失效 | 职业鉴识可以发生在战前，但不能从一条远看不清的线读懂全阵；知识不足时保留轮廓与待核问题 |
| 对照当前行军部署 | 哈克核对实际计划中哪些部队要进入覆盖区、谁负责接应、接应如何进出；工地进度与命令时点分别有来源 | 可以发现具体救援方式受阻，不把“全军必死”当作已经证实 |

供能接驳者是原四人中的一名工作角色，不新增第五人，也不预定姓名或人格卡。启用本分支且无冲突时，主持先指定其实际位置与任务，不让他跟着玩家选择到处出现。

### 为什么他可能说，为什么也可能说不全

普通军务核问、得到上级许可的技术检查，可以令他先解释自己负责的事项；他会把这称为阻止敌人脱逃的部署，未必觉得自己在帮助凌迟杀己方士兵。他不自动知道冒名。发现己方也要进入而撤离没交代时，他会要求指挥者说明，不因此立刻投诚。

若在遭袭或被拘束后询问，他更在意自身安全与是否被直接定为同谋；可信的停止伤害、保护承诺或事实对质可能使他合作，不需要必经拷打。他可以拒绝，也可以隐瞒，但不得为了堵掉玩家成功取证临时设为必然自杀或失忆。

安装者无法接触时，可从真实可观察阵段交给合资格者鉴识，或先以施工异常和撤离疑点报信。艾利在场也需足够材料与对应知识；不把炼金／治愈经历自动等同通晓任意传奇阵法。法师塔的鉴识者收到的只是短报时，只能评估所述风险，不能当作已亲眼核定整个阵体。

**可直接呈现的技术答复〔新编〕：**“开了以后，不是从正门进来就能从正门出去。人要撤，得先停这一道。”另一阵的作用须由确知者或足够鉴识另证，不靠一句话附送所有答案。

## 三、场景二：独立查到七曜石，辨别它并不负责给两阵供能

### 默认可主持的证据机会〔本轮新增，不伪称原团事实〕

上述供能接驳者在出发安装前，曾奉命近看凌迟随身保管的一枚七曜石，回答其能否接入预制阵。他当时判断纯度远高于自己日常处理的同类物件，不能用手头接驳材料随意调用；最终沿预制阵既有供能施工，结晶仍留在主将手里。他知道物件和接驳问题，不知道凌迟准备何时、对谁释放。

这一段新增经历只在本DRAFT使用。它解释安装者为何会知道结晶，又不让他掌握完整作战计划；不发明检测神器、定量爆炸测试、结晶碎片或全案密信。可核对的地方是：两阵已有独立供能、安装材料未接入该物、物件仍可能由凌迟亲自保管。若当前分支已确立另一种保管或经手事实，按已有事实另找相容证据，不覆盖旧记录。

### 军营里的第二个入口

哈克或沃西斯副官若**实际收到**阵势风险，可沿原团#932的行为逻辑询问：“退路可能被封，继续进去的把握是什么？”这里问的是当时具体的兵力和安全问题，不是替玩家承接任务。

凌迟面对军心和军务压力，有三种合理回应：

1. **展示物件以证明有把握。** 在场者看见实物、知道由谁保管；有对应知识者才可辨认和评估。哈克可以记录眼见和凌迟原话，但不能凭一次惊讶自动推算释放范围。供能安装者先前的描述若与眼见吻合，形成交叉核对。
2. **只保证有后手，拒绝展示。** 记录为他拒绝说明，不升级成结晶确证。安装者的证言仍可作为一项带来源的紧急警讯，帝可以据此采取预防措施，不必等待实物入手。
3. **质疑问话者、要求先继续进军。** 哈克可报告拒绝提供安全说明及新的行军命令；普通士兵会有各自反应，不能自动全体倒戈。若因此提前出发，是凌迟对此时压力的反应，不是玩家问问题便必触发的倒计时。

御临风等人若通过自己的合理接触看见、获得或另行查清该物，也可直接贡献证据；不用非得由哈克问出来。玩家若不在场，只能经真实转报获知营内对话。

### 判断危险到哪一步

- “随身有一枚晶体”不是“能毁灭军团”；普通兵士的传闻与主将夸口不是独立鉴定。
- 有实际经手资格的安装者证言，结合实物或可用的专业鉴别，可支持异常高纯、巨大储能潜势及不能按普通随军材料估计。具体释放仍需施用办法，不能推导碰一下必爆。
- 在没有见过实际释放时，报告应写“足以严重改变战场风险、具体输出未明”，不能写已经发生了原团重创魔兽军的战果。
- 两阵独立供能可由现场或安装记录核对；毁阵不自动销毁结晶，夺晶不自动停阵。此区分已由采用规则支持。
- 结晶被可靠控制、两阵确可在进军前排除，可能降低帝继续原布局的风险；主持不故意新增第三个后手来坚持改令。

## 四、场景三：哈克整理急报，消息真正到帝手里

哈克在自己确知的范围内把事实排清，不要求御临风交完美书面档案。可以由任何实际能报告的人发出；下面是足用内容，不是必须照填的新表格。

> 我军在何处，下一道进入峡谷的命令何时生效；哪道阵目前完整／将完工；谁亲见或经手，哪种撤离／接应方式会受阻；主将另持高纯结晶的消息来自谁，核实到了哪一步；现有人员能否在军队入谷前排除，缺的是时间、位置、手段还是权限。请求暂停哪一项行动，由谁能在现场接收新令。

要补一项实际条件：**为什么现在不能稳妥处理掉危险再照旧进军。** 例如另一阵所在仍未查清／无法接近、独立供能使制伏安装者不足以停阵、消息表明行军比处理所需时间更早、或结晶仍在凌迟手里而接管力量未到。不能只用“传奇”作不可处理的标签；已经有可靠办法就承认。

### 路线A：黄翔→右近→帝

沿已采用行程：找到黄翔和可联络点的路程另算；短报接通后10—15分钟到约定接收处；右近在场处理约10—20分钟；宅邸至宫门送信步行30分钟。右近把原始见闻、技术判断与未核处区分后，以军事急情请求改令，不把自己第一次知道冒名写成帝第一次知道。

**本分支新增正常回报估值〔DRAFT〕：**当帝在宫中、既有急件渠道能用、无需寻找本人时，宫门转递并使帝读到约10—20分钟；信息足够、无需另调人核查时，简短决断及形成回令再约10—20分钟。回令由原信使送回宅邸30分钟；若出发时已确认黄翔渠道能双向回报，短令再用10—15分钟抵外线接收者。合计从首次短报发出到外线收到回复约110—150分钟，不包含找人、返营、额外鉴定和调兵。

若帝不在、右近移动、渠道不双向或需要核实，就给实际下一步，不硬套区间。军情急报可以先于实体摹图送达；摹图若只能实送，按地面4—6小时及其他路段计，不能冒称短报同时传送完整图像。帝可据具体可信风险先暂停，不以完美鉴定为硬门槛。

### 路线B：军内副官的已核实通信

哈克先问清副官能联系的对象、此刻是否接通、回令是否可核验。若对方只连沃西斯，就先到沃西斯，由其实际渠道转呈；不是默认直通帝。接通后的几分钟短报不包含找人、转呈和帝作决定的时间。没有确认对象便不能承诺比路线A更快。

双渠道可互相校验，但同一传闻经两人转述不变成两项独立证据。已经可靠送达一次，不要求玩家为流程再跑一趟。

### 等回复时

哈克能警告实际能接触的部队、核问命令、请求暂缓，或在已有职责内先保护人；没有帝令和相应权限，不能凭自己一句话接管全军。右近能先准备人手与请专业者看已有材料，不表示已经获准取消全局布局。各人可以作有限判断并承担后果，不冻结现场等玩家决定，也不强迫玩家留在营地等回信。

## 五、帝的判断：危险是否真的改变原来的取舍

这段可作为后台处理，不强制一场玩家必须到场的朝见。

| 实际收到的组合 | 帝的合理处理〔DRAFT〕 |
| --- | --- |
| 只有复杂法阵或冒名重复证言，没有具体新增风险 | 保留原布局，要求核对作用与进度；有限保护仍可进行 |
| 撤离障碍与独立结晶警讯有可信来源，但尚缺确认，部队还未入谷 | 可以先下短暂停军令，为核对争取空间；暂停不等于已决定拘捕或永不再战 |
| 具体风险可信；来不及可靠排除；继续进入会让预期战损或接应失败显著上升；有谷外暂驻／撤转条件 | 改令阻止入谷，收回凌迟本次进军指挥，安排有权者接管并控制其继续施用危险物的机会；接受敌军未被消耗、可能散走的代价 |
| 阵已可靠破坏、危险物已受控，接应条件仍成立 | 重估后可以继续外线行动；报告仍有功，不因未取消战事判玩家失败 |
| 警讯来晚，已有部队进入或两军接触 | 先制止后续入谷、救出可撤部队或缩减围剿目标，接已有交战稿，不把“来晚”处理成全团无成果 |

临时暂停可规定“收到核对回令前不越过已确认谷口”，并要求再次回报敌情；不设一个到了就自动让部队投入未知死地的行政时限。战场危急时由已有军事职责处理实际防御，不能借暂停令禁止自保。

帝不需要公开冒名秘密才能解释新的军令。反过来，若下令限制凌迟本人，命令须真实说清看管和交接，不能用一句“请来谈话”隐瞒已经决定的拘束。**停军、撤权、控制危险物、拘捕是不同动作，可分阶段落实。**

## 六、新军令怎样落在一个能执行的现场

建议回令的具体内容〔本轮DRAFT，不预设已经发出〕：

1. 暂停进入指定阵区，已进入者按可通行路线撤转；保留侦察和应对魔兽进攻的职责。部队实际位置未掌握时不下精确到未知道路的指令。
2. 凌迟以“达卡斯”身份掌握的本次进军指挥暂时停止，由**实际被帝指定、能在当地履职的人**接收。可在确认在场并可接令后指定沃西斯副官暂管军令交接，哈克协助核对部队与传递；任命来自本次授权，不是副官称号天然等于全军统帅。
3. 要求主将在说明的安全位置接受核问和看管，不再调动亲随转移危险物；收取结晶须有实际能承担风险的接管者，不能把缺少实力的哈克推上去徒手夺物。
4. 工地停止启动与修复危险阵势，现场人员撤离或交接；完整阵体须真正失效或被可靠控制，停工令不是驱散法术。
5. 如掌握催眠风险，告知接管者并请求法师塔准备查验。士兵停止旧令、制止危险、解除控制分别处理，不承诺文书到达即全体恢复。

来源和范围经可靠渠道核实后，新军令具有效力；执行仍需要传达给各部。亲兵听到、哨兵收到、工地知道、外围部队收到分别记。无需所有普通士兵获知凌迟真身才能服从停止进军。

地面援手在帝都待命且交通就绪，也需整备30—60分钟、赴原营地4—6小时及实际外线路程；不是回令抵达就让右近站到凌迟身后。已有预置力量或空中投送只有在本分支确实成立时使用。接管力量暂不足，先落实停止入谷、分散无关部队、保护报告者与传令链，拘捕仍是待执行目标。

## 七、凌迟按实际察觉作反应

| 他实际知道的事 | 可采取的反应〔DRAFT〕 | 实际限制与留下的变化 |
| --- | --- | --- |
| 工地有人问了启停与撤退，尚不知查到何处 | 要求经手者复述问话、派现有人手核对；以军务保密限制后续接近 | 不自动知道已送出急报或谁看懂了术式；已经取得的证据不会被收回 |
| 哈克在军中追问后手，开始影响行军信心 | 以救工兵、敌军将至解释前进；展示结晶稳定军心，或只向少数人说明 | 展示会产生目击证据；不展示保留秘密但未消除具体风险。不能替他两头都占 |
| 确知报信者身份与内容 | 指控对方误解军务、以旧追缉和逃兵／叛徒说法反咬；试图控制仍在其可及范围的传令者或证物 | 需要真实识别、命令与行动，不能追杀不知道位置的人；已离开的消息不能隔空截回 |
| 收到仅暂停进谷的真实帝令 | 先称服从，请求缩短暂停或申请局部救援；核查谁来接手并维持英雄姿态 | 他仍可能设法推进别的尚可用安排，但不能把已撤令下的强行前进写成当然合法；不自动当场暴露 |
| 指挥权被正式交接、看管力量尚未到 | 争取当面解释、要求体面交接；也可尝试转移结晶、联系亲随或脱离 | 取决于实际警戒与路线。他成功逃走就是提前行动付出的代价，不回写为帝早已放行 |
| 察觉即将被控制，但尚有节点、操作者、时间与联络条件 | 可指使实际能接令的安装者提前启动阵，掩护某项行动，或转移已有部署 | 阵只影响原覆盖区，不能把留在谷外的人吸进去；不能跨城遥启、令失效阵复原或凭空换阵地 |
| 判断继续抵抗无利、有可信接收条件 | 可以真实停止抵抗，要求谈判、保留最后的体面或接受看管 | 无需每次装降；交出危险物须真正落实，既有后手不因此自动解决 |
| 发现关键部署已受阻 | 可能撤离、改变局部目标或抵抗以争取实际需要的时间 | 不预定自爆、死亡或“损失都是算计”。更大死亡布局未定，不能用来保证他的任何选择都赢 |

若他在帝令前真的改变进军时点，必须让整队、传令、催促等变化可被看见；不因玩家花一次问话就自动全军入谷。若要求催眠士兵抗令，要核实谁受控、已有何种命令、是否能接到新指令；普通亲随、攀附者和受控者有不同选择，没有全体同步遥控。

**新编短句：**对哈克：“你的顾虑，我听见了。可前面的工兵也在等援。”对新令：“帝要暂缓，我自当遵命。只是误了军机，由谁向将士交代？”面对已到场的正式看管：“看来，这次要问的，不只是阵法。”这些是可用声线，不是固定触发对白或强制选择。

黄祸、黑白武士与悠悠的行动只在收到实际消息或遇到实际阻碍后改变；凌迟被限制不使远处护送自动停下。战争与更大死亡安排按已有边界留待后续，不在本分支揭底。

## 八、结束、失败与回接

- **预防成功但未捕人**：主力留谷外、危险报告获采信，凌迟仍在控制争夺中或逃离。保留已避免的入谷风险，不宣布已经消灭敌军；转接实际抓捕、追踪或守御。
- **成功接管并生擒**：交接实际控制的物件与人员，接既有[善后](capital_recovery_playable_draft.md)和医馆恢复；不再为兑现原团安排第二场同样的峡谷战，不默认处刑。
- **只停住部分部队**：写明谁收到命令、谁仍在阵区、哪些路线还通，接局部撤离与既有交战稿；不套原线固定伤亡。
- **帝听后决定继续，但做了局部调整**：解释其实际取舍及给出的保护安排。玩家可接受、质疑、继续查、救人或退出，不被强制承担拆阵任务；帝承担继续等待的决策责任。
- **消息失联或送迟**：沿已观察的进度继续。保留证据、已救者和被破坏的阵；传令链恢复后迟到消息仍可用于追查与善后，不能倒改成从未取得。
- **不参与**：哈克和副官只对自己确实得到的军情行动，没有替玩家自动拿齐两份证据；帝依原有资料继续布局。未发生原线贡献则真实重估，不额外惩罚玩家拒绝。

resolution_conditions：新增风险已报告并形成真实的决定／局部结果，或调查者退出、消息暂断而转接眼前局面；不以生擒凌迟、完全取消所有交战或帝承认错误作为通关条件。
