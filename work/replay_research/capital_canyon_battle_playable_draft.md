## 一、接上一幕的事实，不重新布置战场

主持开始本段时沿实际记录确认下列少数事项；这是场景衔接，不建新状态机或计时系统。

| 当前事实 | 决定本段怎样开始 |
|---|---|
| 两处术式各自完好、未完工、受损或已失效，谁确实知道 | 决定现场威胁和凌迟的可用办法；未知不等于失效，也不能随玩家选择事后更换术式效果 |
| 两军最新位置、命令与是否已经接触 | 决定呈现出发、接敌、正在交战或交战后的现场，不强行跳到尸横遍野 |
| 黄翔、哈克、另一副官和帝方分别收到什么 | 决定谁能够改令、提醒或派人；发出消息不等于收到和执行 |
| 护送者最后实际位置、路线及是否知道被跟踪 | 决定护送继续、改道、等待或应对；旧位置不会因援军想去而继续有效 |
| 四名队员及其他同行者分别在哪里、伤势与约定是什么 | 决定其眼前危机与可联络对象；不强行把四人集中或分成原团两队 |
| 帝方哪些力量已经受命、出发、到达 | 决定可提供何种介入，不能把一纸命令当作已完成包围 |

若此前实际改令阻止两军接触，本段转为控制、交接或追踪，不额外制造一场大战。若两军继续按既有目标接近，即使玩家已经撤离，战事仍可能发生；之后只能通过真实观察或传回消息了解。

## 二、场景一：调查者听见战场开始变化

选择玩家实际所在处开场，先给可观察变化，而非全知战报。

| 所在处 | 可直接呈现的现场〔新DRAFT运用〕 | 不能直接知道的事 |
|---|---|---|
| 军营／行军队伍附近 | 集合令、收帐整队、军队踏上谷道；若集合提前，原先休息与回营约定受到影响 | 魔兽是否真加速、另一侧毁阵是谁做的、援军是否出发 |
| 峡谷工事附近 | 警戒方向改变、施工人员收工具或守住阵位，谷道逐渐出现队伍；双方到达后才有交战声与实际攻击 | 每个士兵的阵营、远处法阵状态、谷底伤亡总数 |
| 林地／护送线路 | 主力的行进动静，或护送者收到消息后停步、改变方向；只描述当场发生的变化 | 军营的新命令与帝的安排；远处轰鸣不证明凌迟已死 |
| 已离开危险区域 | 能看见的烟、火光或远处声音，之后真实送来的消息 | 没有观察渠道的战斗过程与同伴状态 |

真实攻击临近时，先说清来自何处、正在威胁谁、可见地形怎样，再交还玩家行动。地面崩落、阵地火力和强者交手只有确实发生才改变道路；不为了推动救援先宣布所有退路断绝。

### 凌迟怎样把局势推进交战

阵势仍可用、对方按预期接近时，他可以继续催军进入预定战区，借胜利前景维持军心。阵势没有准备好时，他要选择催促、等待、改变部署或承担缺口；已毁部分不能通过一句命令重新运作。

收到可信毁阵报告后，他可以要求确认，尝试另用实际可用力量，或以救援工兵为由坚持前进。哈克或另一副官若实际在场并获知危险，可以要求说明保障；新编短句：“前面的阵已经出了问题。继续走，凭什么？”

他是否展示、何时动用七曜石结晶由实际局势决定。沿原团它足以构成重大战场威胁；本稿不编精确范围、耗能、能用几次或自动爆炸。在场者只能按自己识别能力与实际表现认识它；真实威胁可以促成改令、求援或撤退，不要求玩家先破解结晶才获准离场。

双方接敌后，交战双方会按各自目标、所收消息、伤亡与可用力量调整。黄祸龙狼的军势不会只因御临风毁阵就无条件撤走，凌迟也不能仅凭“早有后手”抹去毁阵价值。原线五百余伤亡、敌军几乎全灭与展示首级不作为本段默认结果。

## 三、场景二：决定退出时，撤离有具体接点

离开战场可以发生在交战前、局部冲突后或帝方到达后，不需要先打败追兵首领。玩家提出撤离时，主持说明已经知道的道路与现实障碍，不替其选择路线或断后者。

| 实际可选接点 | 主持当场交代 | 局势变化时的处理 |
|---|---|---|
| 黄翔与原先约定的营外道路 | 是否仍在那里、车马与道路是否可用、有哪些人实际到达 | 已依约迁移就呈现真实告知途径；没收到迁移消息就承认失去联系，不默认车夫永远等在炮火里 |
| 哈克或仍可接触的己方部队 | 谁能确认来意、是否可接收伤者、是否正在奉令行军 | 可以暂接或转交，但不保证每支部队都认识调查者；军令、追缉与新命令按实际核实 |
| 雪老提过的林间湖与旧巢穴 | 只有确实获告者知道位置；此前查看所得仍有效，未查看则只是旧记忆 | 本次若护送者到达或通路已被占，就成为新的危险；若没有，湖边可以平静，不强行把两武士搬来 |
| 已抵达且能确认的接应力量 | 用可见接应者、实际呼喊或可信引介说明谁在接人、接到哪里 | 不凭远处白袍或光点认定必然友军；核对到足够程度即可，不临时增加密码谜题 |

受伤、昏迷、负重、地形和追击影响实际行动。没有伤就不补伤；撤出眼前攻击不等于治愈。雪老可以未受重伤、未坠崖，也可以因实际状态需要别人帮助；谁愿意帮助、怎么做留给当事人。

### 追击者也有自己的取舍

- 工兵、哨兵或军中追兵若仍须守阵、接敌、救援或失去目标，可以停止追赶；只有收到具体追捕安排或仍有追击理由与能力才继续。不能所有敌人无限追至帝都。
- 黑白武士只有实际遇见、识别并决定介入才构成拦阻。黑衣武士的雪老旧怨、白衣武士对姜子尤的态度沿已采用人物；相遇不强制一成功力试招、秘法失控或两人死战。
- 卡泽只有实际在场、发现目标并作出行动才出现；原线他在援军压倒性到场后尝试撤离，支持其会衡量风险，不设必须追杀至死的规则。

**失散不是自动死亡。** 知道某人留在危险处，应如实说明最后位置与时间；之后可联络、探查、请求实际接应或暂时撤出。既不因玩家没即时返回就后台处决，也不无根据报告全员平安。队伍四人的所在分别承接，不以“主角团撤离”一句带过。

## 四、场景三：帝怎样决定介入，此刻付什么代价

本节主要是主持后台，只有实际传达给人物的内容进入对白。帝在场外处理报告，不要求玩家突然切到朝堂替他作决定。

**既有布局的主动性：**原团#1018说明帝组织围剿两败俱伤后的双方；#1037他承认计策由自己决定、无辜将士被舍弃，并感谢众人减少损失。因此，继续等待可能是他有意接受眼前伤亡以取得较有利收网条件的决定，不能写成“因为没人报告所以无能为力”。所谓最低损失是他的判断，不是主持保证。

他可通过官方、协会与兄弟会实际渠道推进筹划；各线的接收者和任务分开。尚未获得的精确阵图、受控名单与护送新路线不能由统属关系补齐。

| 帝方实际获知的变化 | 可作的具体调整〔DRAFT场景选择〕 | 必须保留的成本或局限 |
|---|---|---|
| 两阵已被可靠确认失效，目标仍集中、行动力量可及 | 利用已经打开的窗口推进围控与接手；可更有把握争取生擒、减少接近损失 | 毁阵不等于敌人失去全部抵抗；到达与执行仍需发生 |
| 一阵仍在或毁阵报告不完整 | 说明已知危险，改变接近、先处理威胁、缩小控制范围；也可有理由承担风险立即介入 | 不把未知当安全，不由强者出场自动抹去阵势；等待可能错过目标并继续产生伤亡 |
| 可靠警讯表明士兵正面临超出原预估的伤害 | 提前介入、调出能接人的力量，或放弃完整包围以保存更多人 | 可能放走重要目标、牺牲隐蔽或失去原定消耗优势；不保证各项目标兼得 |
| 敌军已接触，但双方尚未充分消耗 | 可继续原定等待，也可根据实际风险提前动手 | 继续等待是帝的责任；提前出动也可能增加帝方投入与风险 |
| 护送路线已有可靠新位置 | 将能调整的追查或拦截力量改向该位置，并说明消息时效 | 不能兼顾所有方向；消息迟到可能只剩痕迹，未知真假目标仍需核实 |
| 只知护送目标曾离开，现已失去位置 | 保留相关警戒与追查，军事收网按自身条件继续 | 不能宣布空间龙问题已解决，也不把追查全部压到御临风身上 |
| 联络中断、支援迟到或帝都留守不足 | 执行已可落实的部分，延期、缩减、转为拦截或守御 | 不无代价复制另一支支援力量，也不把一次收网未成直接等同帝国败亡 |

局部真实结果可以改变决定，不要求玩家必须亲自面见帝才能发挥作用。帝也可以在同样信息下坚持自己的取舍；后果由他承担，不将所有损失归咎于调查者没完美执行。

## 五、场景四：援军到的是一个具体现场

原线有空中投送、宗近与左近进入峡谷、右近转向湖边、协会与其他力量接手局部追击。这里保留这些已有行动能力与协作依据，不固定“四道流星”出现在玩家将死的一刻，也不为未知运输者另造身份或能力。

**本次可用调度模板〔DRAFT，按实际可用者选用〕：**

| 任务 | 可承接的已有力量 | 到场前必须成立的事 |
|---|---|---|
| 面对凌迟、压制其现实威胁并接收停止抵抗者 | 宗近、左近等实际受调力量；不要求二人同时或必以原线方式出手 | 当前目标位置、实际出动安排及其掌握的命令；不能只知出征方向就精准落在敌人两旁 |
| 接应暴露的调查者、伤者或处理已定位的护送威胁 | 右近及实际能同行的人员 | 有足够位置依据，留守已按命令交接或安排，本人确能到场；不靠与主角关系感应求救 |
| 保护交接处、应对局部追击与接收伤者 | 实际参与的协会人员、艾利等已有协作者和军方人员 | 各人真实受邀、可用、到达并知道自己负责什么；布莱特的熟人不全员自动传送到他身边 |

具体参与者若缺席、受伤或忙于另一处，就改变分配或承认这一处暂时无人接手。原团原型的战力不能替代本分支到达条件。

### 可直接主持的到场场面

**确认身份与任务：**到场者先说明眼前可执行的指示。新编短句可用：“奉帝命，接管此处。停止追击，退到指定位置。”实际宣令者只能在获授权范围内说话；不是全地图士兵立即解除控制。

**交接一个具体人或一条具体消息：**右近可以先问“谁还在里面？”哈克可以指明最后见到的部队或伤者，调查者可以报告未清的术式、护送来向或敌人的实际表现。接收者复述自己能承担的一项工作，如“这边交给我”，不承诺所有人都已安全。

**强者介入改变现场，但不替玩家收尾所有事：**压住敌人、接手追击或提供撤离机会后，玩家仍可退出、继续报告、救助眼前的人或提出其他行动。若其现实位置仍暴露于攻击中，应继续按现场处理；不能以一句“援军到了”跳过未解除的危险，也不强迫其留下观看必然胜利。

原团军中有人突然动手清除特定目标，不能移植成所有士兵都是清楚名单的潜伏者。本稿只让获有真实任务与识别依据的人执行对应处置，不借帝的全局布局授权无差别杀戮。

## 六、凌迟、护送者与士兵如何面对局面变化

| 对方实际看到／知道的事 | 可采取的行动 | 不预定的结果 |
|---|---|---|
| 凌迟见到有权接管者与相应力量，但尚不清楚全局 | 维持英雄身份、质询命令、试探对方掌握多少；可指控破坏军务，也可听取交接条件 | 不立即自报全部真相，不自动全军相信任何一方 |
| 可用阵势失效、结晶后手受限制或兵力明显不利 | 调整目标、用仍在手里的条件谈判、尝试脱离或继续抵抗 | 没有阵不等于必被生擒，有结晶也不等于必能逆转；不新添无限备用后手 |
| 判断继续抵抗代价过高且有可信接收条件 | 停止行动、交出当前危险物、接受控制 | 投降可真实成立，不强制装降反转，也不等于获赦免 |
| 护送者获知主战场失利或接应中断 | 继续原任务、寻找实际可行的新接点、带目标撤离或尝试联络 | 不自动放弃护送，也不因峡谷胜负同步知道悠悠现状 |
| 黑白武士遭实际拦阻或认出私人相关者 | 按护送、旧怨、兴趣与风险取舍交涉、交手或撤走 | 不必重演湖战、秘法过载、两武士合攻或右近重伤 |

**普通士兵、魔兽伪装者与受控者不能混为一类。** 停止抵抗者需有实际接收与看护，仍造成迫近伤害者按当前危险处理。解释命令可能使部分人停手，也可能对受控者无效；是否受控通过后续鉴识，不用衣着、阵营或士气直接诊断。

催眠施术者若确在场且被发现，可制止其实际威胁；没有被发现便不能顺手宣告已斩杀。施术者死亡或帝令到达都不自动解控。能安全转送的人接法师塔稍作研究后的解除方案，不新增稀有材料、活捉施术者或完成另一支线的治疗门槛。

## 七、场景五：撤出与收场，不拿战报覆盖事实

在可暂时停留的位置，先确认实际到达者、已交接伤者、仍失联的人及最后所知去向。哈克、右近或其他实际接收者可明确说“此处暂时安全”“那一路尚无回报”，不要用全局胜利代替逐项确认。

| 本次实际结果 | 下一场从哪里接 |
|---|---|
| 凌迟受控，主战场已能交接 | 人员接收、危险物与证言交接，随后沿[善后稿](capital_recovery_playable_draft.md)做排查救治、责任与名誉恢复 |
| 战场被控制，但凌迟或重要护送目标逃脱 | 交代最后位置、已知方向与仍在持续的危险；决定谁实际追查，不强制玩家立刻追到下一场战斗 |
| 仅撤出部分人员，收网缩减或未成 | 保留未获救、失联与仍危险的真实情况，继续接报与有限救援；不抹去已救下的人或已破坏的工事 |
| 玩家提前撤走、未看见主战场结束 | 经真实回报得知有限结果；旁人的胜报保留来源，不能由旁白补上玩家从未见过的幕后 |
| 原团悠悠救援未发生 | 沿UCL_20261015_017与[悠悠接触稿](capital_yoyo_playable_draft.md)，仍可在随后一两天帝都安排行程相容的相遇；没有自动救命恩情或既定关系 |

**损失与贡献：**只记录实际形成的伤亡、救助、术式状态及战果；具体数字没有依据就保留待清点，不搬原线“五百余”。毁阵使某处威胁消失、回报使一支队伍避开已知危险、拖延让伤者离开等，可以按真实因果承认，不以玩家是否亲手击败凌迟衡量全部贡献。普通士兵牺牲和帝的决策责任不被“取得胜利”抹去。

弃风损伤、雪老重伤、右近负伤、魔物掉落、军职、奖赏与好感均不随本段结束自动初始化；只有实际发生或另有明确授予才接入后续。善后也不必等追查全部完成才救人。

## 八、知识与交接边界

- actor_knowledge／visibility：帝按自己的渠道、报告和既有秘密判断；右近、哈克、宗近、左近及协会人员只获各自任务和真实告知。凌迟从实际宣令、交战与接报判断，不读帝内心。各队员不共享远方镜头；看到空中光点不自动知道其中是谁与落在哪里。
- hidden_facts：两阵、结晶、催眠与伪造空间龙沿已采用后台。未明确的法术精确机制、伪造方法、目标对应与暗线隶属仍不补定；不能以未知作为额外绝对杀招。展示头颅不独立证实目标死亡，军事获胜不独立解除悠悠咒术。
- unknowns：战场精确距离与即时规则结算、尚未落实的交通到达时间、原线未解的目标关系继续留白；需要结算时复用已有规则与实际能力，不在本稿新增引擎。调度决定与伤亡结果随本分支发生，不先填。
- resolution_conditions：调查已转为实际交战或处置，并形成可交接的局部结果；或玩家撤出、帝方缩减／改变行动。允许未生擒、未追到护送者和部分失联，后续处理真实未决项。
- continuity_checks：不因拒接或撤退额外惩罚，不让帝无代价填补全部原线贡献；不将等待描述为纯被动，也不把所有死亡预写为帝精确指定；实际消息改变行动，护送改道改变接触位置；无强制伤亡、打法、原团救援或固定胜利。
- role_requirements：无新具名NPC、战力配置或特殊资源开发。
- handoff：本稿按UCL_20261015_021整版采用；三处调查按UCL_20261015_020采用。本稿与城内收网稿分别适用，结果接善后、悠悠接触；后续[战后会合、返都与召见](capital_canyon_return_audience_playable_draft.md)已按UCL_20261015_023整版采用。未更新人物profiles、World、实际分支记录或运行导出。

## 2026-10-18：峡谷交战、撤离与介入的剧情向主持

依据UCL_20261018_001—002，采用[场景共通原则](capital_event_dependencies.md#2026-10-18st指南融入后的场景使用原则)。以下是本稿的演出与裁定方式；原有初始条件、知情边界及后果继续有效，不预定玩家路线。

**现场与人物。** 围绕峡壁、栈道、真实站位和已经启动的阵势呈现战场，让遮挡、退路和伤者成为可判断的环境；不靠持续夸大威势替代空间。

**节奏与简化。** 大量无重要选择的军队交锋可概述，聚焦玩家实际介入的毁阵、护送、掩护或撤离；关键交锋可简化，要求细打时才按需配置具体数值。不能因跳过战斗就抹去未解除的阵势或直接保存全员。

**能力运用。** 怪物先按T阶梯定位，再用RE特性构筑；强者与普通部队可展现体系内合理手段。不能靠补出能力倒改已成功毁阵或已经封路的事实，后手沿已采用机制；若有人按已定体系实际修复阵势或另开通路，须有新的行动、时间与代价，并保留此前毁阵、封路造成的影响。

**奖励依据。** 减损、护送、破坏实际威胁、有效联络及有难度的怪物击杀均可奖励；与战场总人数无关，不把NPC独自击杀全算给主角，不压掉玩家使强援能够介入的贡献。 数额由主持按实际难度与成长节奏明确，同一贡献不重复发放。
