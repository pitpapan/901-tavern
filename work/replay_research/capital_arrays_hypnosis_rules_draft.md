## 一、已经有依据的部分

**原团：**#905说明阵式复杂、属于传奇级别，现场四名法师更像搬运安装者；不是四人现造整套术式。#909／#922为玩家的破坏行动，#910／#923确认地面／岩壁上的阵体被毁、阵纹发出黑光。#1018右近说明两座陷阱为结界与封印，毁阵使围剿与生擒更顺利；#1021另说凌迟使用高纯七曜石结晶，不能据此认定结晶就是两阵唯一能源。#1023说明催眠魔兽已死而军中仍进行逐个排查，普通民众未查尽。

**已采用作者约束：**停止施工、赶走法师与彻底毁阵不是同一结果；一阵受损不自动毁掉另一阵，不能临时补隐藏备份抹去成果。催眠魔兽被制伏／死亡与受控者解控分开。法师塔稍作研究即可开始解除，无须另寻稀有材料、活捉施术者或完成新支线。

**现成规则：**901以已确认核心和未替代PHB为基线。普通法术／特殊能力无特别规定用标准动作；异常抵抗、状态阈值与同名状态不叠加均有规则。PHB“迷情”允许服从，但明显送死或完全违背道德的命令给予额外抵抗。精神束缚的重度效果是昏迷，不能拿它代替服从；RE的状态阈值、驱散通则不整套移入本案。

## 二、两阵的作用与启动〔以下为新DRAFT〕

建议给本场两阵较明确而有限的分工：**结界限制实体进出；封印限制跨界空间移动。**原团没有明确封印的对象，这是本次补充、现已获作者采用；不宣称原团已写过，也不扩成封住所有力量的万能阵。

| 项目 | 结界阵 | 封印阵 |
|---|---|---|
| 作用区域 | 施工时已铺设的谷底作战区域，边缘与上方组成封闭范围 | 同一预设作战区域的边界 |
| 启动后的作用 | 阻止人物、坐骑及普通实体投射物穿越边界；界内原有道路、活动与普通攻击仍可发生 | 阻止跨越该边界的传送、空间移位；不以普通步行、攀爬或实体飞行作为封印对象 |
| 不自动附带的效果 | 不抽取生命、不读取思想；不默认阻断视听和普通魔法通信 | 不封武技、斗气、施法的一般资格、既有被动能力或人物记忆；不使区外空间能力一并失效 |
| 两阵的关系 | 独立安装、独立启动、独立失效 | 同左；一阵坏掉不使另一阵自动完成或停机 |

边界在玩家决定进入、破坏或发出支援请求之前，由主持依实际施工位置固定；可以向知情者展示粗略范围，不事后扩大以罩住撤离者。能量攻击、穿透或破界能力是否能跨过结界，按该能力对屏障／实体的实际描述处理，不能由“传奇”二字推导绝对免疫。区域内部未跨界的短距离移位不触发本稿封印；传入、传出都受限。

**启动须同时满足：**

1. 对应阵体安装完成，主回路连通，启动节点及预置供能可用；未完成的另一阵不替它补条件。
2. 有知晓该阵启动方法者在节点处操作。现场安装法师中实际掌握方法者可做；凌迟是否亲自操作也须实际到场并已掌握。没有跨城遥控或仅凭喊名字启动的能力。
3. 操作者用一个标准动作完成启动。完成前失去操作条件则未启动；只是受伤不额外发明必中断规则，按实际伤势、动作与已有能力判断。

两阵使用预制术式的既有供能，**本稿新拟其启动后可自行维持，不需操作者持续站在节点旁**；不指定其由高纯结晶供能。启动节点和主回路依然属于阵体，破坏后仍能使该阵失效。不是杀掉一名安装者便解除全部阵势。

作用对阵区边界一致生效，不自动辨认帝军、魔兽或凌迟。施工入口只能在实际留下缺口或主动关闭时通行；不新增秘密白名单。凌迟也不能借本稿得到免费跨界逃生。他的结晶释放若无跨界空间移动，不因封印阵而不能用；结晶仍不因本稿获得穿透结界的权限。

本次只保证预置供能覆盖其设计的一次现场交战，不建立永久设施、固定日耗或战后无限运行资源。若本分支形成长期封锁或消耗战，供能持续时间是须另定的真实字段，应在角色作持久等待决定前说明，而非事后宣布恰好耗尽。

## 三、破坏、干扰与停止〔新DRAFT〕

| 实际发生的变化 | 对应结果 |
|---|---|
| 工兵停工，或安装者被带离 | 未完成部分不继续完成；已完成阵体仍在，尚可由真正会用的人启动 |
| 仅清掉表面尘土、伤及无关地面，或局部装饰纹样受损 | 不直接宣告整阵失效；应如实说明碰到了什么，不把普通外观划痕当成主回路断裂 |
| 主回路被实质截断、承载关键阵段的地面／岩壁被毁，或启动节点毁坏 | 对应阵不能启动；若已启动，则该阵停止。本稿不加自动爆炸或杀伤反噬 |
| 操作者被打倒，但阵尚完整 | 阻止他继续启动、修改或主动关闭；已经自行维持的阵不会因此自动消失 |
| 具备对应资格的解除／压制能力实际成功 | 按该能力明确是暂时压制还是解除处理；鉴识成功本身不等于已解除 |
| 阵体被修复 | 须有实际材料、会安装的人员及完成工作的时间；中断部分需重装和核验，不能下一动作凭空恢复。原线大面积毁损不视为简单补一笔 |

**如何判定而不新增耐久系统：**看清主回路需要实际观察与相应知识，普通近看可发现纹路，判断功能另看资格。无人阻拦、可接触的脆弱阵材用适合工具确已截断时，不为了拖延另设无来源DC；若要毁掉坚岩、在战斗中命中节点或对抗魔法屏障，则复用现有攻击、物体、技能及对应能力规则。原有能力够不到或不能破坏的材质，不因“我要毁阵”自动成功。

结界阵停机只放开实体边界；封印阵停机只取消该项跨界空间限制。两阵均失效也不等于敌人失去全部战力、士兵全部获救或结晶消失。法阵变化必须以可观察反馈呈现：主回路断续、启动失败或既有阻隔消退；不能让角色已经成功解除却永远得不到任何确认。

## 四、催眠采用哪套规则〔新DRAFT适配〕

建议将该魔兽的已知催眠定义为：**魔幻来源、影响心灵，以PHB魅惑／迷情表现对达卡斯的异常服从。**不附带记忆改写、思想读取、远程共享感官或自动自杀。

### 建立影响的条件

- 本次施术针对一个能受影响心灵作用的对象。施术者能清楚定位并看见目标，目标能看见施术者并听懂其引导话语；通过普通当面交谈可以建立这个机会，慕名投靠不会免去抵抗。
- 以一个标准动作实施一次明确的引导。双向可见、听见且理解的条件在完成时不成立，则该次未能建立影响。不存在隔墙、经转述命令或听见达卡斯名字就传播的效果。具体米数留给单项能力字段，本稿不把任意远距离可见直接当成可施术。
- 引导必须让目标认识所要服从的对象；以真实见闻、明确身份介绍等建立“达卡斯”的形象，不能任意指定一个目标完全无法理解的人。催眠魔兽施术与达卡斯成为服从对象分开；这是本次适配条款。
- 对方当场明知在受攻击、已有警觉或持反对意见，仍按实际抵抗与可用防护结算，不设“看它一眼必受控”，也不凭普通怀疑直接判免疫。

### 复用901的结算骨架

为避免新造一套控制等级，本稿拟用施术检定最终成功数作为该次原始魅惑点数S；**成功数转点数是新增DRAFT映射**，并非从原团推得。施术骰池、消耗及修正须来自实际采用的能力资料，本稿不替魔兽填属性或法术强度。

1. 抵抗使用现成异常规则：`min(意志,风度)＋有效求生技能`，加真实适用的防护／修正；有明确特殊抵抗条文时按该条文。不再同时追加一次普通`意志＋风度`豁免。
2. 残留魅惑点数＝`max(0,S－抵抗成功数)`；901自动成功依已采用核心计入。
3. 点数**超过**`max(意志,风度)`才进入迷情、产生PHB规定的服从；未达到时只用PHB魅惑的限定减值，不把轻度魅惑写成完全听命。
4. 多次同类效果按PHB分别留来源、并列取最高，不把低强度施术次数相加成必然控制。重复尝试仍须真实接触机会、动作及消耗，不能为了达成故事结果后台无限重骰。
5. 本能力不产生毁灭性后果；不能因点数很高就改为不可治疗的永久人格毁灭。此项也符合PHB对法术直接产生异常通常不带毁灭性后果的限制。

**持续性的新DRAFT选择：**已建立的这次魔法影响留在受术者身上，至有效解除；短暂离开施术者、普通睡眠、撤销军令不会自动终止。作为尚未解除的持续魔法来源，不单靠常规短休／长休消去，符合核心“未解除来源及条目例外优先”的使用方式；这不是所有魅惑的统一新规则。下述特殊命令抵抗仍可发生。解除这项魔法成功即移除其对应控制，不留下必须另做支线才好的残余催眠。

旧背景已确认的受控个体不用追溯重骰，也不由本稿批量填点数；若该个体在本场需要额外抵抗，应在触发前落实其当期属性和残留点数。只确认“已有不少士兵受控”不足以指定任何新出现士兵必受控。

## 五、受控士兵仍然能做什么

| 情形 | 本场处理 |
|---|---|
| 已进入迷情，接到达卡斯明确命令 | 依其能理解的内容执行，仍使用原有判断、训练、感官与行动能力；不知道的秘密不会自动知道 |
| 凌迟不在场，士兵继续守门、押送或保护某人 | 可以继续已经收到且尚可执行的命令；不能从遥远处自动取得新目标和新命令 |
| 普通军官或帝方传来新令 | 若不冲突，可按正常职责执行；若与达卡斯旧命令明确冲突，会倾向被强化的服从。新令本身不是解除魔法，也不证明拒令者一定受控 |
| 命令是阻拦或拘提 | 不能自行解释为杀死所有人、杀害家人或自杀；事态升级须来自实际命令、判断与威胁 |
| 明显送死或完全违反其道德观 | 沿PHB迷情规则获得一次额外抵抗，以结果减少相应魅惑点数。达到退回轻度条件则恢复该项自主选择；抵抗失败仍可能受命，不把道德底线写成自动免疫 |
| 执行军中高风险任务 | 不是每次危险都等同明显送死。依其当时知道的情况判断，不能用作者知道有埋伏就提前授予抵抗，也不能将明知无意义自杀伪装成普通军令来取消抵抗 |
| 收到互相矛盾的命令、条件无法实现或失去目标 | 按理解询问、等待、寻找原目标或作有限应变；不自动发狂、随机杀人或爆炸 |
| 被缴械、擒抱、压制、打昏 | 依901／PHB对应动作和伤势限制其行动；受控仍不提供额外力量或免伤，制伏也不自动解控 |

**等值的局部处理〔新DRAFT〕：**PHB对迷情降回轻度写“以下”，进入重度则写“超过”。本案拟统一按当前点数是否超过门槛判断：额外抵抗后降到`max(意志,风度)`或更低，就退出迷情；尚有点数时保留轻度魅惑。明确补定这个边界，避免正好相等时反复争议；不据此修改其他异常的统一规则。

受控者不是所有行为都由魔法强迫。受控前的主动投靠、独立犯罪、被命令时知道多少及解除后的供述分别核查。熟人劝说、展示帝令或揭露骗局可改变理解并提供判断命令性质的依据，但不是人人都会的驱散术。

## 六、制伏施术者与解控

- **对施术者：**昏迷、死亡或确实失去本次施术所需的视听与表达条件，阻止新的这种催眠。普通擒抱只具有擒抱条文的效果，不附送沉默、封魔或昏迷；还能满足条件者仍可能行动。制伏不是无条件成功，结算复用已有动作与伤势。
- **对旧影响：**魔兽被捕、死亡、凌迟撤权或死亡，都不使既有魔法自动消失；也不触发士兵统一自杀、自动改认新主人或向全城传播。
- **对鉴识：**异常服从是调查入口，确认魔法仍需实际鉴识能力与检查条件；不能凭忠诚、恐惧、口供矛盾或不合作就确诊。
- **对治疗：**沿已采用World与善后方案，法师塔短期研究后可以开始逐人解除，施术者不在、拒供或死亡不封死治疗。按实际在场医者、病人与现有解除手段落实，不需要另立破解任务。若玩家自己尝试，只检查其是否确有相应解除能力，并按该能力的实际条文处理，知识技能高不自动授予法术。
- **解除后的表现：**当事人能重新权衡命令，可以困惑、羞愧、仍尊敬自己相信的英雄，或对遭到强制感到愤怒；这些不等于仍受控。不赠送全部记忆恢复、真相识别或立刻作出完美证词。

## 七、交接与剩余字段

- leads／visibility：观察与鉴识可以分别发现阵体、启动节点、边界出现、魔法影响及具体命令；充分证据才能连起用途。法师、施术者与士兵不自动知道彼此全盘安排，玩家也不会直接得到后台表。
