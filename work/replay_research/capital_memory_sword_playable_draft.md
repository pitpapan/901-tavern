## 一、两件事都可以单独开始

| 当前情况 | 本段怎么接 |

| 记忆、感情尚未取回，御临风提出求助 | 从一次咨询与检查开始，不要求先说出自己尚未知道的真相 |
| 只想问清能否恢复，尚不想施术 | 医者给出能力、当期安排与已知不适的说明，允许本次止于咨询 |
| 已经恢复过 | 沿实际结果安排必要复查或交谈，不为本稿再封一次记忆 |
| 弃风有实际损伤 | 检查损伤和材料，讨论恢复可用与进一步重铸的区别 |
| 弃风尚未损坏 | 可以检查、保养，或直接讨论已有重铸方向；不倒填原团损伤 |
| 弃风已完成本分支重铸 | 按已取得性能使用，可反馈问题，不重复消耗同一份材料和重新收费 |

这两件事可以在一个白天分别处理，也可以相隔数日；安排以实际人手、材料、已有职责为准，不要求采用某个顺序。没有相应紧急情况时，NPC可以介绍帮助渠道，但不以通知代替御临风同意治疗或交剑。

|---|---|---|
| 威廉 | 检查可见纹路、听取已知交易经过，判断交换契约；可实际恢复记忆与感情。采用其原团孔雀、法印的施术表现 | 已联系上、有安静场所且无实际紧急事务时，可安排当次诊疗。不是看到纹路就知道所有未被讲出的旧事 |

## 三、场景二：检查、说明与是否恢复

**现场〔新DRAFT〕：**使用实际接诊者能够安排的一处安静房间，只让御临风同意的人留下。先听他能说明的感情缺失、记忆断层及已有经历；手上契约纹路若当前存在，可以检查。相关可信者可补自己的见闻，不要求公开全部私人往事。

接诊者应给出能支持决定的答复：“可以帮你取回。”“过程会不舒服。”“你可以先想清楚。”这是本稿短句参考，不是所有医者共用的固定台词。检查所得说明到实际覆盖之处；不能承诺恢复后不悲伤、一定释怀或与某人更亲近。

**本次时间安排〔新DRAFT〕：**在接诊者有空、检查没有发现实际障碍、本人愿意的条件下，可在同一次会面内完成准备与施术，之后留出安静恢复时间；当日可结束这次诊疗，不加数天住院或必须连做数次的门槛。原团只支持一场施术完成，不给精确分钟。若有真实伤势、诅咒状态或忙碌冲突，医者说明影响的是哪项安排，不自动判定必须先治好所有问题才可恢复。

**帮助与代价〔新DRAFT〕：**接手者在这次已答应的求助中愿意投入检查和施术的专业时间；代价主要是实际准备、施术耗力、御临风经历不适并留出休息。若帝安排帮助，可由已承诺的资源承担这次实际准备；若私人求助有需另行购买的材料或费用，先说清用途、现有条件和报价再决定，不能临场增加赎回感情、寿命或长期效忠的价格。原团没有给统一医疗收费，本稿不编固定金额或终身免费资格。

雪老可以陪同、帮忙联络，或在确有可支配赏赐时主动提出承担；不要求他先放弃追加赏赐才能解锁治疗。帝如想听军情，可以另提请求，不能将御临风全部私人记忆列为默认回报。

御临风可接受检查后暂缓，选择别的接手者，要求独处或陪同；只想恢复一部分时，由医者根据具体能力回答可否，本稿不新增任意挑选、删除情绪与记忆的技术。开始前的讨论不是施术许可。

## 四、场景三：恢复事实，留出玩家的回应

若实际接受并成功施术，可参考威廉原线的孔雀与法印、伴随头痛的过程。描写医者动作、环境变化和有依据的不适即可，不固定御临风昏倒、哭泣、狂奔或精神崩溃；玩家如何表达由玩家决定。

**可以交付的恢复内容，按已有前史和实际恢复范围分段呈现：**

1. **前一次交易。** 为救雪老，以感情向韩诺付价。若本来已记得此事，则是确认并恢复失去的部分，不当成全新秘密再演一次。
2. **边关败亡与追杀。** 呈现原有亲历的战事、追逐、贞子出现并施救的片段；具体人物和军情沿最新采用资料核对，不把原团旧称谓、误认或后来情报混作目击事实。
3. **贞子的选择。** 她重伤后坚持由自己付出，韩诺提出以她的一切换取御临风活命，她答应并打晕试图阻止的御临风。这是原线恢复内容，不改成玩家已经同意牺牲她。
4. **最后的声音。** 原帖明确呈现御临风曾短暂醒来，听到贞子要求消去他的记忆并将他送走，韩诺答应。可以交回这段短暂记忆；失去意识期间的全部幕后经过不因此成为亲历。

这些可以一次治疗完成后分段叙述，停顿供玩家回应；停顿是叙事节奏，不是按好感或任务解锁回忆。未亲历、未被原记忆覆盖的韩诺动机、交易后贞子去向与当前状态不能凭恢复补齐。

**术后场景〔新DRAFT〕：**接手者确认目前是否仍有不适，允许安静休息或实际需要的照护。同伴可以问“要留下吗”，也可以按御临风要求离开。雪老若知自己获救的代价，可以表达感谢和歉意，但不能替他概括“你现在终于完整了”。恢复感情不使此前的选择失效，也不自动引出复仇、复活贞子或寻找韩诺的新任务。

如御临风愿意谈军情，听者按他实际说出的部分获得知识；不将治疗写成众人共同观看全部回忆。帝原线笑而不答不作为早知全部交易的证据。

## 五、场景四：托尔金看剑并确认委托

**可见场面〔新DRAFT〕：**托尔金接过实际交来的弃风，先检查剑身、旧有刻纹和力量运行，再问哪些部分必须保留、要恢复可用还是进一步发挥潜力。可以说：“先拿来。”“修好，还是再往前做？”他对好料兴奋，也要把追加改造说在开工前。

| 可选委托 | 当前承接内容 | 不自动附带什么 |
|---|---|---|
| 检查／普通保养 | 说明实际损伤和可用状态；若没有问题可以当场归还 | 不制造必须大修的裂纹，不强制将剑留店 |
| 修复实际损伤 | 保全原剑，恢复约定的可用状态，材料由检验决定 | 不背着委托人扩大为完整强化或另造同名替代剑 |
| 修复并重铸／完好状态下提升 | 沿已采用REFORGE_001发挥潜力，明确材料、工期和目标 | 不要求剑灵先觉醒、悠悠受伤或御临风先获得魔力体质 |

**实际材料：**原团支持合用的超上级风属性魔核，或高品质风七曜石结晶，配合工坊材料。可以查工坊现有渠道、市场、协会，使用真实获得的讨伐报酬，或请求兑现已经承诺的赏赐。Chuul讨伐报酬中的风结晶只有实际取得后才能交给托尔金，不改成Chuul必然产出风魔核。

悠悠如在当前分支确有合用材料且愿意赠送，可提出帮助；没有则不自动从口袋里生成。接受材料、借用材料、支付费用、请她陪同是不同选择。拒绝赠石不阻断其他来源，也不使她偷偷以身体补偿。

托尔金先检验主材是否合用，普通辅料依工坊库存或帝都实际采购安排。主材已符合已采用重铸条件时，不加一颗隐藏核心或新讨伐任务。工坊若真实损毁，需要解决具体工具与场地；未损毁就正常使用，不复演爆炸后借仓库的旧情节。

## 六、工期、费用与两件事并行

**修剑工期。** 沿已采用工期：主材、设施齐备并开始工作后，按数小时安排，当日完成检查、修复／重铸和交付，不追加数日观察。仅检查保养可以更短，实际报价时说明；确需等料或等工匠空闲时，在收剑前说明原因和下一次能确认的时间，不能因原团同日完成就忽略真实障碍。

**重铸费用。** 沿REFORGE_001：御临风提供主材，承担普通辅料、炉火等实际成本；托尔金因对弃风的兴趣减免本次手工费。原采用的费用设计在本次讨伐后御临风个人分得酬金可承担的范围，精确报价仍未定；未走讨伐路线也可从实际资金或已同意资助支付，不能自动扣伙伴份额。单做修复由工匠按实际范围报价，不把原线拒收旧补偿解释为一切永久免费。

**收剑时的交代〔新DRAFT〕：**说清留在何处、预计哪一时段再来问、是否准许现场观看。原剑留在工坊的这段时间，御临风不能同时在别处使用它；借剑、另用装备或调整活动由玩家决定，不自动生成替代武器。

两件事并行时可如此接续：先把剑交给托尔金、材料验过并确认委托；随后到已约好的医者处接受治疗；休息后按约问交付情况。也可先治疗、后交剑，或始终留在工坊。只是可用安排，不是规定日程。

普通进度在约定处传话。托尔金遇到需要改变委托范围的问题，可以停在可安全等待的阶段，请人联络；医者正在施术时不因一条普通工坊询问被强行打断。真实紧急情况需按现场可行渠道告知，并说明已有谁处理，不默认御临风是唯一能救剑的人。

## 七、若修剑发生异常，沿已采用原因与真实处置接续

**默认可以平稳完成。** 剑灵存在为已确认隐藏事实，但不等于本次必然显现或失控。若采用已有REFORGE_001的异常分支，原因固定为新旧导引冲突与剑灵本能维持原有运行方式；这是重开可选解释，不追认原团事故真相，更不是记忆恢复引爆剑。

能观察到的内容沿原方案：调整刻纹后风势仍返回旧方向，停止外部注入后内部扰动还有残留。托尔金据此判断不能继续蛮加力量，暂停、处理积聚并说明危险；这些迹象尚不足以让所有人知道剑灵身份。

御临风在场时，可以自行提出观察、联系剑、按熟悉方式配合、要求停工或离开等行动，按已有能力与工序判断；不指定解法，也不凭空赋魔力。御临风不在场，托尔金仍有停工、求援、疏散和承担返工的行动，不等主角回来才开始自救。

悠悠若在场，有自己的愿望与选择，可以传话、提醒、观察、离开或提出力所能及的帮助；她不承担必须徒手救热剑、透支魔力的岗位。已决定不进入危险工序就不因镜头切走而被强制送回。雪老也不预定废腿；真实损失依实际事故与行动成立。

及早中止可以只留下延期、返工或实际材料损耗；严重失控时仍需处理积聚，不能一句“停炉”保证消失。成功干预应保留成果，不为引出剑灵继续追加爆发；工匠失误也需实际说明与补救，不能由悠悠的宽容替代责任。

## 八、场景五：交剑与收束

托尔金完成必要检查后交还弃风，说明处理了什么、能使用哪些效果、哪些仍取决于技艺。普通修复只交付约定范围；完整重铸沿已采用目标体现破甲破魔、挥剑加速、可恢复的剑内风能量、格挡防护及满足条件时的风势干扰，不在本稿新增数值。

交付时可以有普通试握、核对功能与使用反馈，不强制再打一场验证战斗或先受高手指点才能使用已经完成的强化。御临风如何看待剑与逸冷的关系由玩家决定。剑有可辨回应则记为当次观察，不自动听见名字、认主、建立终身契约或获得新战技。

| 御临风的选择 | 下一步 |
|---|---|
| 只恢复，不修剑 | 医疗可独立完成，剑保持实际状态 |
| 只修剑，暂缓恢复 | 工匠按委托工作，不用事故或同伴责备逼他治疗 |
| 只咨询、检查后都暂缓 | 得到明确帮助渠道与实际条件，人物继续自己的安排，没有错过唯一窗口 |

| 开工后提前取回或改目标 | 托尔金说明当前能否安全中止、已耗材料和返工影响，再按真实决定处理 |
| 恢复后想求证贞子、韩诺或逸冷 | 只沿已有可追查线索进入新的自选行动，不在此预告下落、复活条件或强制使命 |

- resolution_conditions：恢复成功并落实必要休息，或咨询后明确暂缓；修剑完成交付，或明确等待材料、停工、改期及原物保管。两条各自可结束，顺利完成足以成为完整场景。
