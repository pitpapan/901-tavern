# 帝都重玩世界书与人物档案第一版审核稿

本版已将接受的研究范围编写为世界书、人物作者档案、NPC运行卡稿和御临风开局Persona，等待你审核文稿内容。世界书共182条，其中99条为世界、势力、地点、概念与重要历史，83条为人物简传；另有94份NPC档案及对应卡稿。125个研究标签均有去向记录，它们不等于125名独立NPC。

## 建议审核顺序

1. [世界书全文](worldbook.md)：先看世界结构、帝国及各势力、法则与力量，再看重要历史与人物简传。精确来源在各条末尾；[结构化世界书](worldbook_source.jsonl)沿用项目世界书格式。
2. [人物审核索引](characters/index.md)：每名人物都有独立可读档案，集中检查背景、性格依据、关系与能力时期，无需一次读取所有人物。[主要人物合册](characters/main_characters.md)与[扩展人物合册](characters/extended_characters.md)保留全量来源。
3. [NPC运行卡稿](characters/runtime_cards.md)：查看供审核的扮演文字及其开局适用条件。标为“出场前确认时期”的卡保存来源场景参考，不是T0已就绪卡；[人物索引](characters/index.md)可直接跳到具体人物，并查看所有研究标签的处理。
4. [御临风作者档案与开局Persona](persona/yulinfeng.md)：重点审核已有身份、记忆缺口、初始能力和玩家控制边界。

## 本版采用范围

帝国、旁线提供的制度和人物事实按同一世界整理；沐透与大墓地不作为整条剧情载入。高塔双潮、旧空间龙秘境仅悠悠幸存、美杜莎身份与忠诚、雷光职责及秘密情报部门、帝哈克亲缘、御临风主神来历与村庄软重启，均沿用已接受设定。

人物作者档案保存原线全时期证据，运行卡按T0或明确条件截取。后期身份、婚约、能力与原线结局不会因为存在于作者库便自动成为开局事实。资料不足的人物保持短档，原型参考与本团事实分开。梦境专属人物和世界条目不进入本版；原始归档保留。

## 审核时关注什么

- 世界书是否准确、主题划分是否合适，帝国和势力是否有足够具体内容。
- NPC是否有可辨识的行事、表达、关系和能力依据，是否把一次行为误写成恒定人格。
- 人物卡是否泄露后来信息、提前授予能力，或越过用户对御临风的控制。
- 身份归并、别名和真实资料缺口是否处理恰当；可按人物或条目直接提出修改。
