## 对本次重玩的用法

一条需要产生后效的消息，按已有证据记录以下内容；不是每次聊天都必须展示的流程表：

| 记录内容 | 判断所需依据 |
|---|---|
| 发生了什么 | 当场结果、行动者与实际目击者；区分行为和企图 |
| 谁表达或发送了什么 | 区分亲历、转述、猜测、谎言；保留发送对象与实际载体 |
| 谁收到什么 | 有接触、送达或回应的依据；发送与收到可以不同时 |
| 接收者如何理解 | 记录其判断、证据和未解疑点；不把听见变成相信全部内容 |
| 谁采取了什么行动 | 意向、承诺、命令、出发、实际执行各保留成立时点 |
| 已留下哪些变化 | 已发生的资源支出、安置、接触或行为反应；未证的后果保留未知 |

帝在T0本就知道破关与达卡斯冒名，右近等仍在怀疑；新报信的作用应按具体接收者已有知识判断，不能每次将事件重置为帝首次得知。〔[UCL_20261004_041](user_clarifications.jsonl:57)〕角色的接收和判断各有范围，补这些记录也不替玩家决定发信、披露秘密或接受后续安排。

新行动只有改变了具体条件，才重评相应后果；独立势力仍按已有目标、资源和消息行动。见[事件因果总览](event_causality_overview.md)。没有足够依据时留空或就真正影响设定的问题询问用户，不用固定原团日程或固定惩罚代替因果。
