## 对本次重玩的用法

一条需要产生后效的消息，按已有证据记录以下内容；不是每次聊天都必须展示的流程表：

| 记录内容 | 判断所需依据 |
|---|---|
| 发生了什么 | 当场结果、行动者与实际目击者；区分行为和企图 |
| 谁表达或发送了什么 | 区分亲历、转述、猜测、谎言；保留发送对象与实际载体 |
| 谁收到什么 | 有接触、送达或回应的依据；发送与收到可以不同时 |
| 接收者如何理解 | 记录其判断、证据和未解疑点；不把听见变成相信全部内容 |
| 谁采取了什么行动 | 意向、承诺、命令、出发、实际执行各保留成立时点 |
| 已留下哪些变化 | 已发生的资源支出、安置、接触或行为反应；未证的后果保留未知 |

帝在T0本就知道破关与达卡斯冒名，右近等仍在怀疑；新报信的作用应按具体接收者已有知识判断，不能每次将事件重置为帝首次得知。〔[UCL_20261004_041](user_clarifications.jsonl:57)〕角色的接收和判断各有范围，补这些记录也不替玩家决定发信、披露秘密或接受后续安排。

新行动只有改变了具体条件，才重评相应后果；独立势力仍按已有目标、资源和消息行动。见[事件因果总览](event_causality_overview.md)。没有足够依据时留空或就真正影响设定的问题询问用户，不用固定原团日程或固定惩罚代替因果。

### PN01 官署公告建立公共事实的共同起点，公布范围仍有限

推荐居民较容易接触到与自己有关的公开事项：道路与通航变化、公共工程、节庆、招募，以及官署决定公开的战果和表彰。官署所在地、常用集市场所或相关公共机构可让人看见公告，也有人将内容带回住处和乡里讲述；不要求人人都亲自读原件。

帝与帝国的威信使正式公布具有很大分量，多数实际听闻者可以接受公开结论。比如宣布某人为英雄，足以让很多人改变态度，而不必先知道全部案情。公告表达的是已经公开的部分，不能因此让民间掌握幕后原因、部署与秘密关系；也不把所有官署表述都预设为欺瞒，或规定全国同刻获得同一份文本。

### PN02 商旅、家信与返乡者让远方成为具体生活

推荐商旅带回亲眼见过的道路、水位、货物、城市景象和地方习惯；学生、外出雇工、探亲者及适当公开见闻的服役者，又带来课堂、工坊、家庭和驻地生活。家信能使远方不只是一座城名，而成为亲人住在哪里、做什么、是否安好的持续联系。村镇经验也随这些往来进入城市。

见闻各有覆盖：跑河运的人了解沿河，长期住一处的人熟悉当地；只看过码头的人也可能说起整座城。熟人信用和反复往来使讲述值得听，但诚实不保证看得全面；旅人也可能夸张、避谈不光彩经历或沿用旧印象。商人希望维持可信往来与希望促成生意可以同时成立，不把他们全部设成传谣者。

### PN03 免费教育使民间可以读、记与比较，城市出现简短消息单

推荐在帝都及主要商旅节点，有人将公开通告、交通见闻、节庆和公开教学活动编成便于传阅的地方消息单，利用已有书籍制作与抄录条件流转；作为已采用作者方案，不预设发行量、刊期、复制工艺、统一报社或全帝国网络。资料也可随信件、教材或行李带到别处。

受过教育的居民可以自行阅读、写信和记下不同说法，愿意的人也会给亲友解释文书、转述通用语消息或用本族语言讨论。口头交流同样服务于忙碌、共同消遣和语言习惯，不能据围听就判定村民普遍不识字。学校与师友可以帮助理解地名和常识，却不替每个人保证消息准确，也不拥有所涉及秘密。

### PN04 城乡差别在接触机会与关注重心，也受实际路线影响

推荐帝都和大城市居民较容易遇到不同来处的人，比较多个说法；普通人仍会依职业、邻里与兴趣选择听什么，并非人人通晓全国。位于干线的集镇可能比远离往来路线的城市片区更早听到某地消息，距离之外，实际联系同样重要。

村庄的消息常随赶集、交货、亲友家信、返乡与教学往来接续。讨论更容易落在自家有关的问题：亲人是否平安、渡口是否能过、外出学习是否顺利、下一季生活会受什么影响。乡村居民对本地土地、天气、路况及物候可以有深入经验，不能因外地知识少便设成普遍愚昧。两地都可能见识深广，也都可能凭有限经历想象远方。

这是生活倾向，不是人人必守的观点，更不固定族群或地区阵营。各地可共享帝国公共消息，同时以不同经历赋予它不同分量；知识不必一律由帝都向外输送。

### PN06 传闻填补解释空白，信任与有限认识可以并存

推荐民间传闻常围绕仍不清楚的原因、夸张的强者事迹、遥远地区的生活和少见魔法生长。真实世界存在奇异力量，居民觉得某个奇闻“有可能”很自然，听来精彩、亲近可信与确有证据仍是不同判断。故事也会在反复转述中压缩时间、合并人物或将一次事件当成当地常态，并不都出于故意欺骗。

人们可接受帝公布的战果，同时对如何取胜各有猜想；可相信旅人确实受困，却误判困境是否遍及整条道路。新的亲历、家信与公开消息有机会改变认识，已经好记又符合旧经验的说法也可能继续流传。古精灵覆亡等少为人知的旧史不会自动随普通奇闻完整传开，实际保密渠道依既有知情边界判断。

作为纯生活示例，同一条“北地来船晚了”的消息，沿岸居民可能想到海冰，洛汀船工会先问哪段航程耽搁，帝都听客可能把它讲成北方到处都封冻；更熟悉该线路的人可能给出不同解释。这只是认识差异示例，未确定任何真实船期、事故或本分支事件。
