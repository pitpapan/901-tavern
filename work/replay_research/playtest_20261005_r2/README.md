## 六项边界检查

| 输入或回应情况 | 采用边界 |
|---|---|
| 无【】但明确是想到、猜测、内心盘算 | 保持私人，不被旁边NPC听见 |
| 引号外已经声明的停顿、目光或行动 | 只传播实际可观察的部分，不附带完整动机 |
| 玩家已公开某项推测 | NPC得到这一说法，可以相信或行动；世界真伪需独立依据 |
| NPC提出相近推理 | 必须来自自己的已知线索，不能用独立想到为读取私人思路找理由 |
| 倒置、遗漏引号 | 局部语义判读，不把相邻内心段吞成对白；重要且无法判断时局部澄清 |
| 摘要保存上述内容 | 记录来源、知情者与推测性质，已指出的泄漏不能反过来成为证明 |

两句对白对潜入的可行性判断，也不等于全队同意、已经清除暗桩或实际进入医馆。明确转告、朗读或展示文字是可成立的传播行为，但必须由玩家声明；不能靠主持自动补出它们。
