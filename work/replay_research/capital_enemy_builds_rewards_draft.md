本稿把帝都已安排的对手落实为七类可主持短卡，并给出具体XP。**状态为ADOPTED_AUTHOR_DESIGN：2026-10-18按UCL_20261018_006整版采用，含七类短卡、定量能力、场景参数和XP方案。**既有敌种、场景与能力依据继续有效；实际相遇、受伤、击杀、领奖均须在游戏中发生。

## 一 构筑口径与使用方法

沿用[强度阶梯](empire_military_strength_20261007.md#t0t8统一个人战力工作版)：T1常规兵、T2老兵、T3精英成员、T4精英副手、T5精英队长。开局御临风为T3是已有定位；本稿敌人T档现为**已采用的场景构筑定位**。T档帮助判断其在世界中的位置，不保证四人队打同档敌人仍有同等难度，也不换算为RE支线或固定属性预算。战斗型八柱将常态T7、真正达卡斯略高于T7继续有效；冒名的凌迟不因此自动取得真正达卡斯的战力。

参考RE《ST指南》第二部分，先明确敌人的主要威胁，再分配攻击、防护、感知、移动和特殊能力。下面各卡分别突出服役训练、水域夹持、心智控制、固定阵地和高速双刀；不把所有能力都堆成攻击加值。负面限制须真实生效，不在玩家利用之后补能力抵消。

这些卡是已知表现的基础，不是NPC能力白名单。沿身份、专长和T档补充合理能力仍然允许；新能力影响当前结果时先明确必要的动作、效果、条件与代价，再结算并保持连续。不得借“未写完整”临时增加一个档次的战力、恢复已受的伤或让已经成功的行动失效。

**三种用法共用同一实力与结果：**

- 概述：结果已经足够明确时直接叙述，保留实际消耗、位置、伤势和未解决危险。
- 简化：围绕真正不确定的冲突作少量关键检定，说明检定决定什么；不伪造逐轮掷骰。不得替玩家新增杀敌、主动承受伤害的取舍或放弃救人的选择；已声明行动实际导致的受伤、失败与消耗仍可裁定。
- 详细：使用下面数值与901动作、攻击、状态规则。切换详细模式不刷新生命、能量或能力次数。

### 数值读法

六属性顺序均为**力量／敏捷／智力／感知／意志／风度**。`E=主技能+一个匹配子技能`；E达到5本身不产生自动成功，须主技能或该子技能实际达到5。`A`表示901自动成功，独立于骰池，按适用属性和技能分别计入。

HP=`体积+力量+2×A(力量)`；基础防御=`min(敏捷,感知)`；基础速度=`力量+敏捷+体积`；先攻=`敏捷+风度`。表内速度是每个移动动作的米数，明确异式见单卡。初始没有已成立伤势时各槽完好；实际有伤则沿用。

普通近战攻击表列**扣除目标防御前的DP**。结算只扣一次目标适用防御，再加列明自动成功；每个最终成功通常造成1点对应伤型，上限单列。没有列明的DR、抗力、硬度、吸收、抵消均为0；状态与伤势继续用901规则，不以“HP扣光”代替B／L／A生命槽。

## 三 旧涵洞Chuul T4

依据[已采用讨伐稿](capital_high_risk_hunt_draft.md)选择的Basic Rules 2014原型：本场仍只有一只。水陆呼吸、暗视、魔法感知、双螯夹持、触须毒与毒素免疫有既有原型依据；以下全部901数字与动作组合为本稿适配，不搬DND的AC、HP、CR或豁免DC。

| 字段 | 本稿参数 |
|---|---|
| 六属性与体积 | 8／3／2／4／4／1；体积7 |
| HP 防御 速度 先攻 | HP17；基础3+甲壳2=防御5；陆行与游泳均18；先攻4 |
| 常用技能 | 肉搏4+螯钳2；运动3+游泳2；求生3；侦查3+水下感知1 |
| 螯钳 | 4L，触及3米；攻击18DP−防御，力量A1；伤害上限18L |
| 擒抱对抗 | 力量8+肉搏4+螯钳2=14DP，力量A1；依PHB再算体积差 |

**螯击与夹持。**一个标准动作进行一次螯击；命中后可用同一螯发起一次不另占动作的擒抱对抗。目标选择力量+有效肉搏或敏捷+有效运动；抓住后按PHB擒抱处理减值、牵带、防御与第三者误击，不能把命中直接当定身。这个“伤害后尝试夹持”是本卡天生能力，不授予所有普通攻击。每只螯最多夹一个体积不超过7的目标，已占用的螯不能再攻击第三者；释放其所夹目标是自己回合内的自由动作。对原本已在擒抱中的目标作普通伤害攻击仍沿PHB擒抱内攻击，下面的触须毒则是单独的能力例外。

**双螯连击。**整轮动作，占用本回合标准、移动、迅捷：两只空闲螯各攻击一次，每次16DP−防御、力量A1，单次上限仍18L。可打同一或两个够得到的目标；先逐次结算两次螯击，再由命中的螯分别尝试夹持。不足两只空闲螯时不能使用。不能同轮再接触须或移动追击，也不凭原型多重攻击获得三个标准动作。

**触须毒。**标准动作，仅对已经被自己夹住、仍在3米触及内的一名目标使用；不给本次动作附带螯击伤害。毒素接触有效时产生**8点原始麻痹**，目标立即以`min(力量,意志)+有效求生`抵抗，扣除成功数后剩余点数按PHB麻痹／定身处理。点数超过`max(力量,意志)`才进入定身；不追加毁灭性后果。随后目标每个自身回合结束可用同一骰池再次削减当前点数，不占动作；本次毒最多持续1分钟。重复施毒各留来源、并列取最高，不叠加点数。已有有效抗毒或免疫照常生效。Chuul自身免疫毒素；这不等于免疫所有麻痹来源。

**感官。**暗视18米。魔法感知36米，感到范围内持续魔法或正在运作的魔法效果的存在与大致方向；不能由此知道姓名、属性卡、魔法用途，不能读取未施展能力。普通非魔法肉体强弱不被自动识别；明确隔绝侦测的屏障仍有效。这是本场901适配的感知范围与内容，不把所有异能一律标为魔法。

**场地与行为。**沿既有五处涵洞位置，建议入场前锁定：入口净宽4米；贴壁步道宽1米；淹水弯段水深1.5—2.5米；维修平台约6×5米；支洞净宽1.2米，Chuul不能正常穿过。实际水位变化保留，不为补足难度回涨。它可逼近魔法气息、夹住近处目标、尝试往实际有水的方向牵带，受重创时考虑退到仍可抵达的水域。牵带要按擒抱与移动结算，不自动把人拖入深水；没有现场活人质就不临时补一个。降水、失去行动空间或准备充分都可以使战斗明显容易。

**奖励建议：4XP。**御临风有实质贡献、持续威胁确已排除时发放；亲手最后一击不是条件。有效捕获、可靠转移等解决同一威胁也可给4XP。击杀时可以立即结算，不必等回城或剧情节点。风七曜石与团队金币继续按原委托单独兑现；不另加一份只把“杀掉同一只Chuul”换名的完成节点XP。

## 四 催眠魔兽 T3

依据[驻处介入](capital_intervention_playable_draft.md)与[催眠机制](capital_arrays_hypnosis_rules_draft.md)。具体种族、外貌与姓名仍未补定；本稿只为已存在的施术者补必要参数。T3来自有条件的强心智威胁，不表示它能与T3近战者正面互砍。

| 字段 | 本稿参数 |
|---|---|
| 六属性与体积 | 3／4／4／5／5／5；体积4 |
| HP 防御 速度 先攻 | HP7；基础防御4；速度11；先攻9 |
| 常用技能 | 魔法5+催眠3；肉搏1；运动2；求生2；侦查3；掩饰3 |
| 应急肉搏 | 无额外天生武器伤害，攻击4DP−防御，无A；上限4B；标准动作 |
| 催眠魔力 | 上限6，单次施术2；本卡完成8小时长休恢复至上限，切换场景不恢复 |

**一次催眠。**标准动作，消耗2魔力；单个10米内、可受心智影响的目标。施术者看见目标，目标看见施术者并理解其话语，才有施术资格。以`风度5+魔法5+催眠3=13DP，魔法主技能A1`产生原始魅惑点数。目标以`min(意志,风度)+有效求生`抵抗，残留为`max(0,原始点数−抵抗成功数)`；大于`max(意志,风度)`才进入迷情，1点至该门槛为轻度影响，0点无影响。没有额外毁灭性控制。

施术内容与服从对象须在施术时明确，沿既定案情指向目标理解中的“达卡斯”。一次清晰指示不等于即时灌入整套计划。持续、额外抵抗、同类取高、不能读心／改忆／远程遥控，以及施术者死亡不解除旧影响，全部沿已采用催眠稿。重复施术须重新满足条件并付费，不能靠后台无限重试宣布必然成功。

**行为。**它可能靠近尚肯保护自己的同伴，利用能被理解的话语施术，或者从真实可用出口离开。有人逼近不等于自动施法成功；普通擒抱也不自动封住它的表达。消耗完魔力仍有普通行动，但不能临时以“隐藏储备”增加本能力次数。

**奖励建议：3XP。**在它仍能施术、有人保护或逃逸风险真实存在的情况下，击败、有效捕获或阻止其继续危害，按御临风的实质贡献发奖。若右近已经独立控制它，御临风仅见证，不能按旁观击杀领3XP；此前实际促成定位、接近或控制的贡献仍可计入这一挑战。后续救治受控者若另有独立工作，可以另奖，不能把“制服施术者”重复算成“已解除所有控制”。

用于[古雷姆林场景](capital_gremlin_playable_draft.md)入口已准备的**一具**石像及阵纹，不增殖为无穷波次。

| 字段 | 本稿参数 |
|---|---|
| 六属性与体积 | 6／2／1／3／3／1；体积6 |
| HP 防御 速度 先攻 | HP14；基础防御2；石质构体提供物理DR2；速度14；先攻3 |
| 常用技能 | 肉搏3+重击1；运动1；求生2；侦查2 |
| 石拳 | 3B，触及2米；标准动作；攻击13DP−防御，力量A1；伤害上限13B |

**固定阵地。**在既有地面圈内触发与攻击；本稿建议有效圈半径6米，石像不能把力量传到圈外，也不会临时发现新远程攻击。能感到圈内实际可定位目标的活动，但不获得墙后或远处的全知。它按已安装用途阻挡闯入者，不自动追出山洞。

**构体与停止。**无呼吸、饮食和有机神经，免疫毒素、疾病与作用于生物神经的麻痹；没有可受魅惑的自主心智。实体限制、位移、冻结等按实际作用仍可生效，不授予通用状态免疫。使用B／L／A槽记录损坏；本卡构体例外为完好槽归零即停机，不作活体昏迷与自然伤势恶化，全部为A表示彻底毁坏。恢复需要实际修复，不因离场自然回满。

阵纹与石像的连接须先可观察。无敌对干扰且有合适工具时，切断暴露的关键连接可使其停止，不另设必须耗光14HP的门槛；不适合切断、有人争夺或只够一次仓促动作时，才按具体操作结算。断线不损坏所有其他布置，古雷姆林也不能隔空免费重连。

**奖励建议：2XP。**实际击破或有效排除此阵地阻碍均可发放。若石像根本未构成阻碍、他人早已停机或只是路过，不凭其T3标签发奖。它与古雷姆林是两个可分别解决的对手，但追捕节点不能再次重复支付这2XP。

## 六 古雷姆林常态 T5

| 字段 | 本稿参数 |
|---|---|
| 六属性与体积 | 8／10／5／7／6／5；体积5 |
| HP 防御 速度 先攻 | HP15；基础7+身法闪避2=防御9；基础速度23，高速陆行46；先攻15 |
| 常用技能 | 白刃5+双刀3；运动4+杂技3；魔法3+土系2；求生3；侦查4；掩饰4；潜行3 |
| 双刀中的单刀 | 3L，触及1.5米；标准动作；攻击19DP−防御，力量A1+白刃主技能A1=2A；伤害上限19L |
| 土系魔力 | 上限8；完成8小时长休恢复至上限，逃走、变形、再登场不恢复 |

**高速。**常态能够以两倍基础速度在可通行地面移动，当前为46米／移动动作，不消耗魔力，不额外获得动作或攻击。用于高速突进、改变攻击方向、拉开距离或追逐；不能只在需要逃跑时才想起这个特点。实际伤势、负重与地形先影响基础速度，再计算倍率。高速不等于瞬移、穿越实体、自动摆脱擒抱，或无条件取消脱离威胁范围的攻击；拦截仍需有实际反应、距离与行动条件，不能只因玩家想拦就宣布成功。身法闪避2在失去闪避资格时也会失去。

**双刀压迫。**整轮动作，占标准、移动、迅捷，对近战触及内同一或不同目标各作一次刀击，每次17DP−防御、2A，单刀上限19L。不能一边完成整轮双刀连击，一边又获得46米的免费高速移动；需要移动时使用普通移动加一次标准攻击即可。受缴械影响时不能凭空补出另一把刀。

**土遁。**标准动作消耗2魔力进入可用土层；地下每个移动动作最多8米，不能同时套用高速陆行；重新出土用标准动作。单次最长30秒，期限结束须在可用出口出土。可以沿松土、自然土层及本场已经接通的土系通路移动，不能凭此穿过完整金属、虚空或已有效封死的区段。土遁本身不提供隔层精确感知、地下攻击、解除拘束或修复伤势；携带他人还须满足真实负重和束缚条件。进入前已经发现的通路变化有效，不能在逃跑受阻时补出原来没有的直达出口。

**形态变化。**标准动作切换空的外貌与Phantom形态，不花上述土系魔力；保持同一HP槽、消耗、位置及实际束缚。高速与本体战斗能力不因为外貌变化自动清空；外观也不授予随意冒充其他人的能力。常态没有吸石进化、进化体魔力冲击波或自动第二条生命。

**不轻易用高速退场。**主持优先让高速服务交锋。他有维持老师姿态、控制试炼、证明自己或压过真正天才的动机，局部受挫并不使这些目的消失。可以换位继续施压、交涉或试图抢回局面；不在每次受伤后直接写“高速消失”。确实决定撤离时才落实路线、距离、阻挡和追逐。剧情编排可以影响其选择时机，但不临时关掉高速，也不保证玩家必抓到他；有效封路或成功压制同样不能被高速抹掉。不会替御临风安排追击、领悟或台词。

**奖励建议：5XP。**击杀或有效制伏这个仍构成重大威胁的常态敌人可获得；若未抓到但已实质破坏加害计划、救下目标，可以先按已完成挑战发2—3XP，余下追捕成果后续结算，不把一次逃走视为所有努力归零，也不在下次见面把同一份成果重发。若当前遭遇只击退他、仍保留现实危害，不能直接写成已领取完整制伏奖。具体分项例见下一节。

## 七 XP建议与结算实例

以下数额以**御临风的个人XP**为单位；同行NPC不从这份数额机械分走若干分之一，其成长另按各自实际记录。不是“每具尸体的总额”，也不采用RE战力差、奖励点或支线兑换式。未来有多个真实玩家时应在开局明确相同贡献的分配方式，不默默套用NPC口径。

| 实际挑战 | 建议XP | 使用尺度 |
|---|---:|---|
| 无挑战的清扫、旁观、重复结算、已制伏后补刀 | 0 | 不因发生死亡自动产生收益 |
| 稍有难度的独立敌人或小阻碍 | 1 | 例如仍有现实抵抗能力、确实形成挑战的单个T2老兵 |
| 明确有难度的普通遭遇 | 2 | 四人搜捕造成的救援阻拦，或一具启用中的石像 |
| 强控制或多重目标的显著挑战 | 3 | 仍有实际施术与逃逸条件的催眠魔兽 |
| 高危讨伐 | 4 | 旧涵洞Chuul；水域和控制能力真实存在 |
| 阶段性强敌 | 5 | 古雷姆林常态；高速、双刀与土遁仍构成现实威胁 |

**这不是T档价目表。**低档敌人组成的危险遭遇可以比孤立个体更值得奖励；高档目标已经无力抵抗也不会凭标签不断产出XP。按尚未解决时的真实威胁、角色的实质贡献、实际取得的结果确定额度。准备、交涉取得的支援、恰当克制或优秀行动使战斗变容易，不反过来取消其贡献；也不以“必须流血／耗蓝”作为有难度的唯一证据。

有一定难度的怪物击杀可以**当场独立发奖**，不要求Boss、剧情节点或完整任务完成。使用概述或少量检定跳过战斗细节，不自行降奖。只有结果仍未取得，或御临风实际上没有相关贡献，才按事实少发、暂缓或不发；不为维持预设XP曲线增援、改判或强迫打满回合。

### 击杀 挑战和节点如何合计

同一个对手或障碍的**同一份解决成果只领取一次**。击杀、捕获、谈妥可靠移交可以是不同达成方式；不会因为先制服再杀死而领两次。节点清算汇总尚未领取的成果，另有独立调查、救援、人物发展成果时才分项加奖，不能把已经发过的击杀改名为“任务完成”再发一遍。对新发生且实质不同的危险，可另作挑战，不能凭敌人复活、重复放跑或重置场景刷同一成果。

| 实际结果示例 | 本次结算 | 后续处理 |
|---|---|---|
| 四人共同排除Chuul；御临风有实质贡献，战斗最后用概述收束 | 击杀／解决威胁4XP | 回城不再为同一次清除发4XP；金币、风七曜石按委托另结 |
| Chuul因事前调查、降水或争取的帮助而被轻松解决 | 仍可4XP | 认可使结果变容易的贡献，不按最后掷骰多少扣奖 |
| 无关强者先行独立杀死Chuul，御临风到场后才得知 | 此次击杀0XP | 实际完成的其他工作另看，不能把未参与讨伐写成4XP |
| 击破石像，之后在仍有危险的交锋中制伏古雷姆林 | 石像2XP+古雷姆林5XP=7XP | 对同一追捕结果的节点加奖0；另有独立成果须另列 |
| 石像被排除；成功打断加害并使A脱险，但古雷姆林逃走 | 石像2XP+本案阶段成果3XP=5XP | 此3XP属于本次5XP制伏／消除该威胁成果中的先行部分；后来完成同一追捕补2XP。新的独立危机另计，不自动套5XP再发 |
| 交接中实质促成控制催眠魔兽；另完成一项独立救治协调难题 | 控制挑战3XP+救治挑战建议1XP=4XP | 若所谓救治只是重复报告“魔兽已被抓”，则不加1XP；抓捕也不等于已解控 |
| 四人搜捕由两名老兵、两名城卫参与，护送伤者的真实阻碍被解决 | 遭遇／救援挑战2XP | 不另计2×老兵1XP，不追加2×城卫奖励；战斗与有效交涉均按实际贡献衡量 |

节点奖励与独立击杀的区分，是**奖励来源与查重**，不是让每场击杀必须依附节点。对于没有主线节点的小型敌人，主持仍可直接宣布“这次击杀有实际难度，获得1XP或2XP”。

**成长量级核对。**普通主／子技能升一级通常3XP，普通属性一级6XP；主技能升到5、子技能升到5的倍数及属性升到6／11等门槛级，依现行费用另算。因此中等击杀1—2XP有积累价值，Chuul的4XP可以支持一次普通技能提升并余1XP；石像与古雷姆林合计7XP可支持一次普通属性提升并余1XP，前提是满足成长条件。这里不用“几只怪必升一T档”控制节奏。

**记录例。**在既有奖励／状态记录中写“旧涵洞持续威胁已排除；御临风实质参与；4XP；已发放；委托的同一清除成果已结”。这是记录格式示例，不是已经发出的奖励，不另建奖励台账系统。传奇智力红利仍只在明确的节点清算触发一次，单次击杀与上述分项发奖不另触发。

## 八 场景接入和来源边界

| 场景 | 接入方式 |

| 旧涵洞讨伐 | 使用单只Chuul卡与4XP建议；四人仍须实际会合，无额外小怪、主案幕后者或强制人质 |

凌迟、黄祸龙狼与八柱将之间的高层交战不在本次补成供T3队伍正面对砍的Boss表。它们继续按已有身份、真实部署和能力运行；不能冒用真正达卡斯的T7+，也不因需要剧情高潮临时调低或调高。玩家参与的是当场实际可及的救援、毁阵、战斗与取舍；不以亲手杀死主将作为获得贡献奖励的前提。
