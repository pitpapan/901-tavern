## 二、哪些消息会主动传来

首次实际建立合作时，可自然约定一个已经存在的回报地点或联系人，例如右近府邸接报处、协会柜台或当前照护者。御临风可以接受、改选或不留联系方式；不新建全城追踪、统一联络册或专属信使。已有接触只支持实际可用的联络，不能默认送信者知道其新住处。

| 消息与主动发送者 | 什么时候会发、通过什么渠道 | 向御临风说清什么 |
|---|---|---|
| 雪老照护变化：实际照护者，经右近或原求助渠道 | 已接手且确有交接、位置改变、急需协助或重要病情变化；送到约定处或真实可联系者 | 人现在何处、由谁照看、需要他提供的是事实还是帮助。情况稳定时可在下次会面简短说明，不每次换药催来 |
| 露露和医馆查问：实际经手的右近／哈克或获准转话者 | 获得具体探视、放行、继续拘押的答复，或发现执行与已知命令不符 | 谁已见到、谁能离开、谁仍需核问、下一步由谁做。获释不是等御临风到场才执行 |
| 达卡斯调查进展：实际负责者 | 取得影响调查范围的答复、新危险或可核对矛盾；普通进展可合并在原约定回报 | 已确认什么、还差哪项亲历或决定。仅通知进展时说明无需立刻赶来 |
| 收网及命令调整：右近或实际有权传令者 | 决定已作出、确需相关参与者得知；只通知各人执行所需部分 | 是正式任务、有限求助，还是情况通知；地点、范围及真实时间要求。非参与者不自动收到全案部署 |
| 悠悠求诊：悠悠同意的接待者／实际医者 | 有具体检查安排、研究结果、需要她决定的治疗或确实恶化；私人细节向其认可的陪伴者说明 | 是请陪同、说明病情，还是实际请求一项帮助。御临风不是医者开工和向帝报告的必经人 |
| 帝与谢尔伦的合作进展：实际负责联络者，经主治者转达 | 回信或可用资料已经收到，且与当前治疗或当事人的决定有关 | 到的是意见、资料还是人员；能开始哪一步。只有“信已发出”时不装作龙方已答应 |
| A的试炼邀请：A本人或实际受邀者 | 真正接触时提出；若约定以后答复，可再联系一次确认当前意向 | 邀请内容、他知道的来路、是否已经约定同行。未接受不成为失约；没有出发时限就不声称今晚必须去 |
| 古雷姆林案回报：实际承办者，可能是欧基、诺斯莉与哈克 | 有身份、现场、保护或追踪结果；已知威胁实际涉及御临风或同伴时主动提醒 | 哪条线索已核实、具体谁有危险、哪一项工作已有人接手。目标正在移动的消息要说明所见位置和时间，不能当作实时定位 |

主动消息来自实际接报链，不来自作者全知。消息送不到就保留在实际接收处，普通口信不改成守卫全城搜人。重要情况可向现有相关机构求助；若御临风本来没有联络义务，不因未被找到就判擅离职守。

示例短句〔新DRAFT〕：哈克：“露露出来了。有人接着，你办完再来。”医者：“检查能做了。她想请你陪着，方便时回个话。”诺斯莉：“人找到了，还平安。我们先照看。”是否能说这些，取决于相应结果确实成立。

## 三、哪些事情可以等待，什么时候需要及时行动

“可以等待”指当前没有必须由御临风立即完成的事，不表示时间停止、永不恶化或对手不行动。主持用当前事实说明等待会影响什么，不用统一小时数代替判断。

| 当前情况 | 可等待／可交接的部分 | 需要改变安排的实际变化 |
|---|---|---|
| 雪老已经稳定并由实际照护者接手 | 普通探望、补问旧事、参与下一次查问；右近继续承诺的工作 | 真实病情恶化、照护中断、藏处暴露或追兵已迫近。尚未完成救援的雪老不能当成已经安置 |
| 露露及医馆人员仍受看管，但已确认生活与查问情况 | 下一次普通会面和非紧急补问；释放请求继续由经手人推进 | 发现正在强行转移、阻止必要救治或违背已送达的放行命令，先处理对应风险 |
| 达卡斯调查暂在核对消息 | 等一次答复、交换新发现、讨论是否继续参与 | 现场正在扣人、阻报、移走关键对象，或已确认的行动窗口将改变。没有这些事实，不凭空制造即将出征 |
| 帝已准备行动但御临风并非不可替代的执行者 | 已委派者执行；他可不参加、改做别事或按已有职责交接 | 他已经承担的具体工作确实无人接手，或当场危险需可及者帮助；说明实际冲突，不把全案压在他一人身上 |
| 悠悠当前可交谈、有人照护，研究进行中 | 普通陪伴、一次非紧急谈话和不需本人参与的研究；专家能独立会诊 | 医者实际观察到恶化、准备的治疗需当事人决定，或原照护条件无法维持。悲伤、争执和玩家离场均不自动算恶化 |
| 谢尔伦回信、材料或专家安排尚在途中 | 已能做的诊治继续；玩家可以做其他事 | 得到具体延误、缺项或新可行方案，才更新可选安排；不每天重复“可能来不及” |
| A只有未定期的试炼邀请、尚无具体受害证据 | 回绝、改期、请其先核实。新稿默认找到同伴后再确认出发，不能忽然改为已约定今夜 | A实际另约同行者或向空确认，或出现新的失联、威胁、袭击事实；其决定须有经过，不由玩家选另一线自动触发 |
| 古雷姆林案正在查学院和旧址，具体人已有保护 | 普通资料比较、下一次会面；承办者继续核查 | 真实袭击、正在被带走的人、尚可跟随的目标或不再安全的保护地点。机会会失去，但不据此预定伤亡 |

告知危险时尽量说可用事实：“搜查的人已经到街口”“他刚从那条路离开”“她现在无法完成原定检查”，而不是只说“再不来就晚了”。具体症状须沿当前真实诊断，不为本稿另造病理征兆或固定余命。

## 五、共用人物忙不过来时，怎样协调

**哈克及姐弟。** 哈克已经在核问达卡斯口径时，不同时在洞穴汇总现场；欧基、诺斯莉若正在接回医馆人员，不无声切换成全程追凶。新消息先交给真实可接触的人员，能先做的普通查问与保护先做。确需他们时说明正在忙什么、能否完成交接，不能只为让玩家赶场而让所有助手突然失联。

**右近与帝。** 右近可交办一次联络或由实际有权者承接局部工作，不必每件事都亲到。帝协调的是资源和命令，不实时替所有人查案；已知死亡传送影响原军事判断时，按World调整相关部分，允许缩减行动目标。不能为了“先治悠悠”把已有可靠条件的所有收网工作一律冻结，需要抽调照护者时先说明谁能承接；若确实无人可接，必须面对真实代价，不能同时宣称照护无损和追凶人手齐备。

**医者、法师塔与资料。** 三位专家实际准备治疗时，不同时全员赶往追凶现场；可以通过已有可用人员传递意见，或只让确有余力者承担另一项工作。士兵解控、悠悠研究与普通伤者治疗按真实需要协调，不因都叫魔法问题就捆成同一疗程。宝石翁能空间穿越，但联系、意愿、施术准备和精力仍各自成立，不成为无限交通与支援资源。

**秘密内容。** 经手者可只说明自己被一项工作占用、预计何时能再联系，以及谁能接下一步；无需为了排会面泄露全部军情或悠悠私人经历。信息不足可能影响安排，应允许再问具体需求，不用保密让协作必败。

## 六、不同时催促的具体主持方式

1. **普通进展在自然停顿处交代。** 返回约定处、结束当前谈话、治疗结束或准备出门时，可以收到已经送达的口信。普通结果能合并交代，不安排三个报信者轮流冲进房间。合并只限同一接报者实际收到的内容，不造全知简报。
2. **把通知、邀请与紧急求助说清。** “露露已获释”是进展；“悠悠想请你陪诊”是邀请；“有人正被强行带走”才是具体危险。收到消息不等于接受任务或必须马上行动。
3. **正在发生的紧急事实及时告知。** 不为保持单线节奏压住已送达的求救，也不为了营造自由而假称一切可以等待。两处真有急事时，讲清各自已有谁处理、实际缺什么，由玩家选择自己的参与，NPC继续承担能做的部分。
4. **不因玩家转向而同步升级另外两线。** A发出邀请、悠悠取得新诊断、帝准备收网，各有原因；并非选择其中一件，另外两件就同时限时。御临风休息也不自动换来袭击。
5. **实际时间足以改变局面时再更新。** 一段短谈不逐个模拟全城，较长外出或完成一场行动后，核对真正经过的时间、已承诺任务和实际新消息。只记录发生过的进展，不补出为迫使回线而选择的最坏结果。

主持在当前场景末尾简短记下“已有人处理什么、等待哪条消息、谁还不知道、下一次何时有理由变化”即可；复用现有分支记录，不新建任务引擎、全局警报表或后台自动调度系统。

## 七、三种可直接接上的转场示例〔DRAFT〕

**医馆查问后，先去见悠悠。** 露露已经由右近实际安排接回，馆主仍待进一步答复。哈克告知自己继续查问，不需要御临风留守。悠悠的医者已经联系成功，若她确实希望有人陪同，可以在约定处留邀请。御临风先去求医，不会让已经获准的释放撤回；哈克的新答复稍后正常送达。

**陪诊后，先核查A的试炼。** 诊断已说明，悠悠当下仍能正常交谈且有人接手，专家正在等龙方相关意见。主治者说清何处可再问消息，不要求全队守在门外。A的邀请若已实际传来，可以独立处理；研究结果到达后先交主治者，不必因为找到新资料就把御临风从洞穴强召回来。真正需要当事人决定的治疗，先向悠悠说明。

**追凶途中，帝方准备收网。** 右近通过实际可用渠道告知相关安排；御临风此前没承接不可替代职责，就不因收网而必须离开眼前救助。若确有撞期任务，说明哪项需要交接。欧基等当前已经在本案现场，就由实际指挥者决定留在现场、完成后归队或交接，不同时算作两边战力。

这些例子依其中事实成立才使用，不强制选定场景顺序。若当前悠悠确已危重、雪老尚未脱离追兵或古雷姆林正在加害，就按实际危险改写安排，而不是套用“稳定可等”。
