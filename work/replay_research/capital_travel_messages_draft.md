## 二、城内行程

表内均为单程，正常可通行、知道地址、不进行额外调查。区间是事前估计；主持在行动开始前按当天情况选定基准，必要时告知角色约需多久。不得看到玩家选择后再挑一个恰好使其失败的端点。

| 路段 | 正常行程 | 依据与适用条件 |
|---|---|---|
| 本次入城城门→九雪医馆 | 步行30分钟 | 新DRAFT；只定位本次入口，不代表每座城门 |
| 医馆↔邻居店 | 走几步，同街相邻 | 沿用已采用关系；交谈、取物另计 |
| 医馆↔协会 | 步行15分钟 | 已采用 |
| 医馆↔钟塔维修间 | 步行15分钟 | 已采用；进入小屋、搜寻或警戒另计 |
| 医馆↔右近宅邸 | 步行60分钟 | 已采用 |
| 协会↔右近宅邸 | 步行45分钟；熟路、轻装信使快跑20—25分钟 | 新DRAFT；为既有约60分钟往返递话提供具体条件，不假定普通步行能同样快 |
| 钟塔维修间↔右近宅邸 | 走已知通路约60分钟；已到场马车约30分钟 | 新DRAFT；选可通车接应口，最后窄巷仍须步行搬运 |
| 右近宅邸↔宫门收信处 | 步行30分钟 | 新DRAFT；仅到门口，不包含获准入内、找到帝或召见 |
| 医馆↔法师塔；协会↔国立图书馆 | 分别步行30分钟、20分钟 | 新DRAFT；提供求治查书的本地连接，不改变开放或准入条件 |

协会递话往返约60分钟的正常情形：轻装信使两程各20—25分钟，递入与简短回应约10分钟，且右近或能处理该事的留守者恰在。不满足时仍可送达，但不保证一小时内带回答复。只剩普通步行人员，往返路上便约90分钟，应当先说明。

**救雪老的实际车辆：**若车仍在宅邸，不能把“撤离车程30分钟”当作报信后30分钟就安置完毕。先送消息，再由宅邸备车10—15分钟、驶到接应口约30分钟，完成伤情允许的搬运后才开始回程。若右近或车已在附近，则从其实际位置算，不强行走完整套。徒步搀扶雪老由维修间到宅邸暂估90分钟；需要抬行、止血或避追时在出发前另估，不能催伤者按健康人速度走。

其他拘押点、经手处若尚未定位，先由实际线索确定地址，再从已知街区给本次路程。不能用一个虚构的统一监狱替代不同押送去向，也不能将核查释放所需时间藏在“路程”里面。

## 三、帝都至峡谷及外线地点

以下精确时间均为新DRAFT，原团支持的是数量级与相对位置。营地指初次与哈克会合的当晚营地；之后大军移动，应沿实际位置重估，不能让“营地”跟着人物移动却保持原距离。

| 路段 | 本轮建议基准 | 条件 |
|---|---|---|
| 右近宅邸→初次会合营地 | 黄翔驾月夜枫马车4—6小时 | 包括正常出城、抄熟路与短暂停靠；符合原团几个时辰。临时搜寻军队或道路受阻另计 |
| 同一路线返回帝都 | 健康乘员4—6小时；伤员需平稳运输6—8小时 | 新DRAFT，仅限此车此程；负伤不能仍照来时颠簸赶路 |
| 初次营地→峡谷近侧入口 | 熟路小队步行约60分钟；夜间辨路约90分钟 | 不包含详细侦察与攀岩；不推定军队列队、工兵运输同速 |
| 峡谷近侧→远侧林缘 | 通路正常约30分钟 | 到谷口的位移；爬山、检查工事、隐蔽观察另计，不保证有安全通路 |
| 远侧林缘→原线魔兽短暂停留区域 | 已知路径快行60—90分钟 | 只作初始摆位候选；不知道地点须先找，敌军一旦移动不能再按旧坐标到达 |
| 峡谷近侧→湖岸会合处 | 熟路步行45分钟；夜行或照护伤者约60—90分钟 | 地点须已获知；涉水进入水下巢穴另看个人能力与伤情，不默认伤者能下水 |
| 初次营地→湖岸 | 熟路步行约60分钟 | 新DRAFT直达林路，作为实际约定后可用的会合连接；战斗封路后重估 |

由此能说明“人在同一外线”也可能相隔一两个小时。深入森林的人员不会因切回峡谷镜头自动听到军营新令；折返也不是免费动作。但不额外为每次叙述、每个检定或玩家讨论扣时。

## 四、消息与援手分别何时到

| 渠道 | 时间候选 | 收信及行动边界 |
|---|---|---|
| 城内现有人手口信／封信 | 采用上述实际路程；当面交代通常数分钟 | 到收信处不等于本人已阅；目的地无人时留下或追送须有实际安排，不自动找到移动目标 |
| 黄翔向右近报简短急情 | **新DRAFT：既有联络手段接通后10—15分钟送抵已约定收信处**；需要找黄翔或到可联络地点的路程另计 | 出发时明确谁接收、能否带回回复。保留器具／术式细节未知，不赋予黄翔个人施法、全城定位或随时通话能力。黄翔离营报信可到实际联络处，不先断言必须往返帝都 |
| 另一副官的实时通信 | 实际确认能联系目标且接通后，短报可在数分钟内说完 | 原团由哈克转述能力，须核实对象与可用状态；被阻断即中止，不自动升级成全天候群体通信 |
| 其他法师的委托通信 | 接单时说明本次施术、接收条件及预计送达时间 | 不另定全国服务时限；仅“法师能通信”不足以承诺马上接通右近或帝 |

**短报收到后：**右近在场、问题明确且权限内可办，暂估10—20分钟作出简短回应或启动附近人员；需要找本人、核对证词或请示帝时说明实际下一步，不暗加固定一天审批。这个时段既不是保证采信，也不是完整调兵时间。哈克收到现场急报，同样可以先做其权限内的保护、警告和核查，不等所有信息齐全。

**城内支援：**附近可用人员简要交代并动身约10—15分钟，加他们到现场的实际路程。只有人已在途且方向正确才可能提前遇到；右近亲自出发仍受其实际位置和当前任务约束。

**城外支援：**已在帝都待命、交通确已备妥的小股快速支援，接令整备约30—60分钟；本稿暂以赴初次营地4—6小时作为这次地面驰援估值，随后到峡谷仍须走外线段。不能把月夜枫车程直接赋给全军：步兵与辎重未定统一速度，需指挥者给本次预计到达时段。即时通信只能使其早出发，不能让地面支援在一场短促交手内必然赶上。

原线已有空中投送或提前部署可以改变上述结果，但只有对应力量已实际部署、可调用、知道地点时才另报预计到达时间；不得凭原线出现过就补造运输者与速度，也不得以玩家将败作为自动到达触发。帝方事先准备的部队与接到新急报后才动身的部队要分开说明。

## 五、主持时怎样落实

- **leads：**大妈可说明医馆、塔旁和熟悉街区的脚程；协会可说明去宅邸的人员、路线与何时回来；黄翔说明本次追军和报信条件；哈克根据当时地图说明营地、谷口及已掌握敌军方向。没人知道的敌军位置不作为玩家已知目的地。
- **next_actions：**每次跨处报信，只在现有场景记录留“何时出发、往哪里、何时预计到、实际带了什么消息”。消息到达后再更新接收者知识和可启动行动；无需新增数据库或逐分钟表。
- **contingencies：**玩家参加则按实际路线和观察用时推进；不参与则既有搜索、军令、行军按自身起点推进；道路被毁、会合点暴露或人员改道，则由实际知情者改变去向，并留下其确实有条件留下的消息。不得倒推所有人早就知道改变。
- 会合前说清地点和预计等到哪个时段即可，例如“到天亮前”“报信往返一趟后”；失约只意味着尚未会合，不能自动认定死亡、背叛或立即全队出发追人。具体去留由玩家和各NPC自己决定，不强设追人方案。
- 搜队“约120分钟到塔旁”从其实际开始查这段路线起算；大妈“约60分钟”从她实际取物返程安排起算。玩家入城、进医馆或切换镜头不会同时启动全部倒计时。若玩家很晚才得知，应说明可观察的进度，而不是给一个已经用完的隐形期限。
- **例：**修理间派人经医馆去协会，正常走30分钟；协会再派熟路急使到宅邸约20—25分钟，右近在场听取短报并决定出人10—20分钟。至此是他约一小时后知情并开始安排，绝不是援手已到修理间。已在附近的右近则用真实位置另算。本例仅展示时序，不建议玩家必须走此路。
- **resolution_conditions：**相关人员实际到达、消息实际交付或确认改道，即接回对应场景。战场进度与搜查线索按真实变化处理，时间表不保证救援成功，也不强制错过。
