# 城镇服务续稿

2026-10-07。**proposed_not_adopted**。按[UCL_20261007_007](user_clarifications.jsonl:76)继续补服务，不再设计街区。城市等级见[当前工作初稿](empire_working_draft_20261007.md)：一座首都、五座区域重点城市，以及宝石翁塔镇、最初小镇。原团已有服务与本轮拟补服务分开；服务存在也不保证T0当天人员、材料与接待容量都可用。

## 常用服务

下表为可供继续采用的服务基础，不是已确认每个聚落都有全套机构。重点城市可以有更完整的人员与供给；小镇通常先满足本地和旅人的常用需求，特殊能力仍按具体人物与来源确认。

| 服务 | 可以解决的需求 | 条件与范围 |
|---|---|---|
| 食宿与生活补给 | 短住、较长停留、普通饭食、耐储口粮、衣物与日用品 | 住宿容量和库存有限；长期住宿不默认保密，提供食宿不等于担保身份 |
| 车马与旅途整备 | 照料坐骑、修补挽具与车辆、采购旅行用品 | 具体供应看人员与材料，不预设每镇都有大型马场或充足坐骑 |
| 工艺、修理与定制 | 普通衣具、器械、武器与工具的修补，提出定制需求 | 特殊装备需合适工匠、材料和时间；提出要求不等于能做成 |
| 普通医疗与照护 | 清创、包扎、常规药物、伤病观察与恢复期照顾 | 特殊治疗、解咒、魔法诊断取决于实际医者；医馆存在不意味着能处理任意诅咒或复活 |
| 学习与知识服务 | 基础学习、学徒指导、书籍与抄录、寻找合适的专业咨询 | 魔法学习有体质、天赋和知识门槛；资料可得与成功学会分开，私人学者不默认公开授课 |
| 办事与委托 | 反映地方问题、报告危险、询问职责明确的处理渠道，寻找合适的受托人 | 延续既有地方与协会权限，不新增办证制度；不能认定每座小镇都有独立协会分部 |
| 消息与通信 | 获取公开信息、核实路况、寻找可用的通信或转交途径 | 公开消息、传聞和专业施法分别处理；城镇通信能力不等于无条件公共通信窗口，私人通信能否承接另定 |

基础依据：帝国原有市场、市政、工坊与医疗实例见[帝国专题43—77行](empire_dossier.md:43)；魔法教育和魔导应用分别见[UCL_014](user_clarifications.md:601)、[UCL_015](user_clarifications.md:622)；地方、协会与通信范围见[制度简版](empire_operations_consolidated.md)。这些依据支持服务种类存在，逐城供给与新增安排仍是本稿提案。

## 各地服务重点

| 地点 | 已有依据或已采用定位 | 本轮可补的服务重点 |
|---|---|---|
| 帝都 | 全国首都；已有教育、医疗、市政和工坊材料 | 较广的专业咨询、进修与复杂修造选择，处理需要国家协调的事务；具体专家与接待机会仍需来源 |
| 佛萨罗伦 | 原团大城市，有衣物、装备、马匹整备与诊疗实例 | 长途旅行整备、较多住宿选择、物资补充和车辆器具修理；区域居民的常用服务也较完整 |
| 宝石翁塔镇 | **小城镇**；原团有酒家、食品、装备店及求访者停留 | 食宿、旅行用品、等候期间的生活补给；拟补行李寄存、车马照料与基础修理时，按实际经营者和容量处理 |
| 白暮城 | 北境南缘重点城市；北方长雪季已确认 | 保暖衣具修补、耐储物资采购、普通伤病照护、寻找熟悉当地道路的向导；水路服务取决于实际解冻条件 |
| 洛汀 | 东部内河区域重点城市 | 船只与器具修理、货物暂存和水陆转运、询问可用船程；其他普通城市服务并存，不设全国唯一贸易口 |
| 烬辉城 | 东南区域重点城市，生产维修特色已采用 | 材料采购、常用器具制作维修、寻找工艺师与学徒指导；特殊术具另看专业人员，不包办一切魔法装备 |
| 风门城 | 南部山前区域重点城市，腹地与边地往来节点 | 出行物资、车辆修造、途中伤病照护、向导与道路消息；未设固定驻军支援或通往失陷边关的安全保证 |
| 最初小镇 | 保持小镇定位；原团有地方受理、魔法传讯和求援实例 | 食宿、日常补给、简单维修及向当地负责人员报告情况；其他专门服务依个案，不套用省会级供给 |

各地“侧重”不是专营权。其他地区也可能提供同类服务；不能因表内未列出，就断言那里没有医者、工匠或教师。服务规模、库存、专业水平和当次能否完成是不同字段。

## 宝石翁塔镇的特别边界

小城镇可以因求访者而有较多旅宿与消费需求，不必补成大型学城。原帖描写大量酒家、塔前队列、装备与食品商店，居民熟悉外来者；这些都是该次场景的直接依据：[MUTOU #216/msg867911](../../extracted-mutou/page-05/posts.jsonl:17)。

- 食宿和购买旅行用品有原帖依据；拟补寄存、坐骑照料和修理时，不默认安保、赔付、材料或工匠水平。
- 商家可以转述公开的塔门消息、介绍本地采购地点；除非另有依据，不把商家设为宝石翁的代理人、预约人或担保人。
- 阿伊达被拒、等待半月等说法及塔不定时开放的店家证言保留来源归属；到镇只意味着可以尝试求访，不保证会面、治疗、授课或委托被接受。[#222](../../extracted-mutou/page-05/posts.jsonl:23)、[#224](../../extracted-mutou/page-05/posts.jsonl:25)。
- 塔边物价高的实例不变成全镇统一价格；特殊材料和魔法道具是否有货也不由求访者多直接推定。

## 记录服务的粒度

后续有必要细化时，每项只记录：**服务内容、提供者或机构类型、所需条件、地域与时期、来源及确定性**。特殊服务再补实际限制，不预先生成整张价目表、营业时刻、员工名单或办理流程。

已有原团服务保存为对应场景事实；本轮新服务安排保持uncertain / proposed_not_adopted，采用后才更新其状态。原团后期的医生、军队资源或魔法通信改革不前置到T0。本稿不安排必遇事件，也不建立新的难度引擎。
