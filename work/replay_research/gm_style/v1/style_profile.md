# 原 GM 的叙事风格与本次采用方式

本轮的核心结论是：GM“剑”习惯顺着玩家行动写眼前的变化，让具体场景和人物接话推进故事。普通时候语气平实、带口语感；重要抵达、交涉、感情和战斗场面会展开，偶尔出现浓重修辞或轻松吐槽。以下是对样本的风格归纳，属于作者研究与预设设计，不增加本团设定。

用户喜欢的抵都段落并非单靠“鬼斧神工”这一类形容词取胜。它先写离村、数日行程，再从山丘另一边看见城市，靠近后才给出惊叹，并与现代以及路上村镇对照。这段文字有时间、距离和观察过程。原导入卡把这些压成“城门在眼前、推荐信待用、尚未选择”，留下了状态，却丢掉了经历场景的过程。

## 不同线路的区别

第一、二部提供了大量行路、办事、熟人交谈和调查的平实基础。第三部的高潮修辞更重，但仍紧跟战斗后果；其中不少长篇招式宣言来自玩家，不能把整场战斗所有华丽文字都归给 GM。

沐透线的粤语、夸张自称、粗口与特摄音效，主要与影魔等具体人物和题材有关。大墓地线更多通过礼仪、通报、观察以及动作与客气对白的反差表现人物。这些帮助我们理解 GM 如何随人物调整表现，不应被编成所有 NPC 通用的语气，也不据此改判阵营性格。

## 原有习惯与本次取舍

本次不是机械复制原帖的每一种习惯。原 GM 确实有直接询问下一步、替玩家写心情、全知切镜、作者吐槽和不够顺畅的长句。保留自然感与接话方式，同时按这次重玩的要求收窄这些部分。

| 原帖中存在的习惯 | 本次处理 |
|---|---|
| 在转场或笑点中直接写主角评价、心情与选择 | 指定历史开场保留用户选定的反应；新回合只承接用户给出的主动言行与内心。客观结果、受伤和阻碍仍按主持规则处理。 |
| 揭示幕后思想、未来解释和其他地点的秘密 | 作者层可以研究写法；实际叙事继续遵循 F3 的知情与揭示条件。 |
| 每轮显式追问“如何行动” | 不设为默认尾句；需要 NPC 当场提问时正常说话。不能以“自然推进”为名替玩家选下去。 |
| 旧规则、XP、先攻、括号说明与正文混排 | 不作为文风示例；实际需要的规则仍由已有主持规则处理。 |
| 网络梗、重复词、错字和人称漂移 | 允许轻松口语，修正语言毛边；不把笔误认成正式别名。 |
| 特殊梦境、后期结局和人物秘密 | 保留在离线研究资料，运行提示与示例没有携带这些段落。 |

因此，预设里的克制规则部分来自用户的游玩要求；它们不是伪称“原 GM 从不这样写”的统计结论。我们模仿的是可以保留下来的叙事习惯。

## 为什么只选两段短示例

两段分别提供“接住一个具体动作”和“接住请求，再让 NPC 提出自己的事”的示范，均不晚于入都开局。场景条件是根据紧邻原帖作的作者简述，GM 主体原句只作注明的错字与标点修正。

- **P1:816062**：布莱特点灯后的可见范围与整理所需时间。玩家动作来自 P1:816061，作者是布莱特玩家“夜小胖”，不是御临风的宣言。
- **P1:816130**：老村医答应配药、准备离开，又提出收购手稿。承接 P1:816127 的说明与 P1:816129 的玩家请求。
- **P1:816583**：用户指定的抵都两段另作开场，不把同帖的救火、财物结算、图片与物品机制一起拷入。

这些不是当前正在发生的事，运行模块已明确这一点。短示例做成独立提示，方便关闭；没有把全量语料塞进 Data Bank、世界书或角色卡的对白示例字段。P2、P3 与两旁线只贡献无剧情信息的风格归纳。

## 成果与下一轮

[文风模块与开场使用说明](../../../../output/replay_tavern/gm_style_v1/README.md)是给用户的交付入口。[authoring.json](authoring.json)保存可编辑源稿；[兼容性备忘](analysis/preset_compatibility.md)记录本地 1.19.0 的代码依据与龙血玄黄边界。

这次只检查全量提取、来源、示例时点及提示词导入结构。没有调用模型，也没有证明不同模型已经能稳定复现这种文风。后续用一个真实想玩的短场景看效果，出现具体问题再修改对应提示；不需要为每次文风微调重审设定或重新精读全团。
