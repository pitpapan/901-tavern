**时间。** 原全局表要求每轮计算当前时间，纪要表强制填写两个精确时刻。候选同时修正活动模板、聊天表指南、数据库检查点及填表提示：有明确起止或可推算的时间才记具体区间；相对时间照原文；没有依据则全局时间列留空，纪要 `time_span` 填“未交代”。表结构不需更动。

**回忆。** 自动纪要保留已知群体量词，遇已描述的人群只分别记录有证据的人数和来向。续写按相同精度回答身份、数量及方向，群体称谓与人数表述保持一致。两条规则的文本和应用范围在 [prepare.py](prepare.py)。续写措辞常驻隔离角色，不以测试问题关键词决定是否加入；第二轮历史条数置零是独立的验收控制。

**最终候选，两轮从空纪要实测。** 玩家只说“一拨镇民经过”，当面与黄泉约定“蓝鹊五铃”，在 ASCII 方括号内私下另想“砂灯六纹”。首轮回复复述公开记号，也新写了镇民挑着杂货和干菜。自动生成的 AM0002 把这群人与“人数未详”“来向未详”一同记录。第二轮实际请求保留该纪要，排除了首轮玩家原文和助手回复。被直接追问时，黄泉答“一群”镇民，表示没有数具体人数、没有留意来向，只知道公开记号。她在否定句中提到岔口或街角作为没有留意的可能，没有指认实际来路。末轮后台写回 AM0003 后仍记“具体人数与来向并未特意留意”。两轮纪要的时间均为“未交代”，全局表的上轮时刻、经过时长和当前时刻均为空。
