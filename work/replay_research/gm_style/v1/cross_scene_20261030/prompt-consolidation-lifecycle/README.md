## 用例设计

`fixture.json` 全部为受控隔离测试素材，不是本分支已游玩剧情或采用设定。沿用实际 classic 模式及已启用的大总结模式，默认阈值15，不降低阈值。既有阶段总结1条、近期纪要14条，包含生活约定、身份订正、关系两面性和私人备用记号。

1. **below**：14条时无新增事件，检查不提前总结、不造日志。
2. **closeout**：从23:55实际经过20分钟；完成寻钥、送药失败、凭证过期，保留未送信任务；黄泉增加对黎舟特定事项的信任，同时保留借伞义务、对掌柜的感谢与戒心、苏岚暂离档案。
3. **summary**：达到15条后形成阶段总结；旧总结不改，订正旧身份，保留早期取物暗号、尚未归还青竹伞、未拆信、已结束任务、私人想法归属；系统隐藏被归纳纪要。
4. **repeat**：阶段归纳后无新剧情，不再重复写纪要或总结。
5. **blind recall**：隔离主持入口仅对验收问题使用 `max_chat_history:0`；实际当前模型续写，从数据库总结取出旧事实和任务状态，黄泉不能说出未告知的备用记号。采集实际请求以区分数据库读取与原对话复述。

这是阶段压缩与读取链路测试，不是数百轮自然游玩的耐久性证明。四次填表与一次续写为计划次数，最终实际次数与结果另列。
