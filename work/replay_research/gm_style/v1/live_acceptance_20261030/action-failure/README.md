## 原因与修复范围

正式原聊天 `901 初始卡石像撤离实测 - 2026-10-22` 共31楼。失败玩家楼为索引29的“测试”，助手索引30显示固定提示。其规则根 revision 10，battle.mode 为 story，仍保留历史战斗快照；该助手楼只有 `901_narrative`，没有底层错误诊断。
