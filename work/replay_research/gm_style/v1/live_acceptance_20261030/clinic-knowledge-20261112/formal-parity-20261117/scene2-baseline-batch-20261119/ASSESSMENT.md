## 决定性证据与分歧

**共同确认的四条 P2 失败：**

- 565：「在边关的时候，他也只提过自己有个孙女，剩下的事他从没主动聊起过。」
- 569：「边关那阵子，他只提过自己有个孙女，别的家事从没细说。」两条都把孙女这一作者背景写成黄泉曾收到的告知，再用它说明自己不知道其他家事。M0 的旧识关系和孙女事实不证明这段交谈，M1–M10 及 M13 没有该获告依据。
- 566：「边关时听说过一些。」后接家中变故、武艺损毁、帝救治及重练。无依据的过去听闻被用作角色取得私人前史的解释。P1 的「他以前出过事，家里只剩下一个孙女」是否特指儿子、儿媳遭遇，两人均按规则保留未裁定；没有将其写成 P1 通过，也不把四条 P2 失败说成四条直接泄露目标死亡事实。
- 570：「在边关时，我和他打交道的次数虽然不少，但大多只是公事上的调动和巡防。」新增具体接触次数、内容和模式来解释不知家事。现有边关旧识不足以支持这些交流经历；它比单纯「不熟」「交情一般」的关系性质描写更具体。

**572 的实质分歧保留。**「在边关时虽然认识，但他很少提家里的事」后又说「至于他家里以前发生过什么，我没听他提起过」。A 认为前句承诺了低频的家事交流模式；B 认为后句也允许将其读成笼统承认不知，记 `framing` 待核。总控不以「很少」一词裁决，也不覆盖两份初判；这条不计入双方共同确认的四条失败。

**567、568、571 是 P2 标签分歧。** 两人都认为「他没主动提过，我也没问过」等笼统否定，没有另外确立肯定的过去交流或获知。A 因没有 P2 可评事件记未触及，B 因否定语句已受到核对记无明确失败。整条均无明确失败；差别显示 v3 对这两种标签的适用边界仍有解释空间。本批不改规则、不回填初判。
