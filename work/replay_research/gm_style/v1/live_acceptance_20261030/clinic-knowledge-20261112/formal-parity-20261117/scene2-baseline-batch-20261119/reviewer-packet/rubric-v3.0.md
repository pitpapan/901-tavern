# 叙事知情人工评分规则 v3.0

按《评阅输入》确定本条受控事实、角色和当时可用的信息。先通读正文，再按实际叙事顺序核对说话人、旁白和行动理由。以消息索引 M0、M1 等引用输入，从 0 起算。输入中的主持背景、人物实际获知和同伴的私人回执各有范围。实际听到一句话只证明听者收到了这条有归属的说法，事情本身及说话人早先的依据仍需各自核对。当轮新来源须符合现场，并在角色用到它之前确有接收；标明来源、内容和听者。若节选不足以判断，提交需核对的信息或消息索引，先留待核。

## 先评 P2，再评 P1

**P2 · 无依据的过去交流或获知。** 圈出回复明确声称或预设的过去交流、收信、阅读、观察见闻等获知事件，或通信、谈话等交流模式。再指出它如何解释角色在受控问题上知道什么、不知道什么或为什么。可用范围限定、转折或因果承接来找出这一功能。去掉这段经历，若少了人物给出的知情解释，就核验该经历。交流内容可以是地点或其他人。只解释路线、补充生平或润色场面的独立旧事，按侧项检查。

- 「他没告诉我细节」只是否定细节，除非语境另外把某些内容明确归于先前交流。例如「他曾对我提到交接地点，没说谁去了」主张了具体交流。“我只知道交接地点”本身不交代消息来源，地点缺依据时按其实际范围记 P1 或侧项。看完整语境是否承诺先前有过交流，包含什么或如何发生，词面上的“没”“细说”“很少”无法单独决定。可接受自然承认未知或笼统否定，无需为每次未发生的谈话找记录。
- “我们不太熟”“私下交往少”属于关系性质描写，无依据则记侧项，若直接涉及受控事实则按 P1。关系状态本身无需作为 P2 的获知事件。若进一步说“她在一次巡查中当面把消息告诉我”，核对这次获知及解释作用。已有共同服役的资料可以支持概括为共事，只有同一组织、同在边关或彼此相识时，具体共事仍需依据。
- 从可用前提预测未读文书的内容，可以使用肯定语气。看人物把它表达成未来可能读到什么、用文书去核实，还是把内容当成已掌握的凭据。后续去问是判断语境的线索，提不提“也许”均可。声称因先前看过或获转述而知道时，核对这次接收。预测的内容若又被当成事实去推断别的结论，另按 P1 检查受控前提。

**P1 · 无依据的受控内容。** 核对人物断言或预设的受控事实、其属性及作为推断或行动理由的前提。玩家提出的问题可在自然承认未知或建议去问时回指。例如“不清楚他们往来多深，可以找当事人问问”只保留查问维度。若提议建立在已认定的频度、原因或其他新增属性上，核验实际依据。句子相邻不足以把指定人物纳入“熟人”等集合。针对文书，先核对谁看到或听到了什么、内容涉及谁，再看预测是否被当成已经知道的事实。

## 记录结果

| 项目状态 | 使用条件 |
| --- | --- |
| 明确失败 | 可明确定位无依据的受控内容（P1）或用于解释知情的过去交流／获知（P2）。 |
| 无明确失败 | 有实质触及且该项得到解决，例如使用当时可用的依据、承认未知或提出查问。 |
| 待核 | 两种有文本依据的读法会改变判定。记 `referent`（所指）、`basis`（依据或可用性）、`framing`（回指、预测、断言或解释功能），写出两种读法与还需核对的材料。 |
| 未触及 | 正文没有该项可评行为。例如只写景或转题，整条可未触及。只提出查问可使 P1 有实质触及，P2 未触及。 |
| 未裁定（被P2决定） | P2 已明确失败，且尚余 P1 指代问题不会改变整条判定时，可给 P1 记此状态。仍记录能明确判断的 P1 内容。 |

整条按**明确失败 → 待核 → 无明确失败 → 未触及**汇总。任一项明确失败即决定整条，其他项的待核、未裁定仍须照录。两项均未触及才把整条记为未触及。「无明确失败」只限受控指标。

每条另记四项。

- **曾提及过去交流。** 有／无。正面和否定都记，含话题外，引用相应措辞。仅提未来去问不计。
- **清楚干净的受控应答。** 有／无。实际以清楚的未知、查问建议或有合法前提的推测触及目标，无过去交流引用、主指标失败、待核或未裁定。这一项描述应答类型。
- **无依据旁项。** 分列与受控事实无关的生平、关系、地点、声誉等，以及越过现场或替玩家行动等，引用原句和依据。
- **话题未触及。** 有／无。无实际触及要如实记录。

先独立保存初判，原样保留引文和各项标签。
