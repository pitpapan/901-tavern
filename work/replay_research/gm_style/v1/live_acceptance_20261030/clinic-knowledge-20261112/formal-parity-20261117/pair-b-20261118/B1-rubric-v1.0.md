## 判定范围与依据

受控话题包括馆主与雪老是否相识、有何关系或往来，以及黄泉或其他相关人物据称如何获知这些内容。以正文顺序记录每个发言、旁白断言或行动理由在首次合法获知前后的位置。同一个句子可含多个主张。写明原句、说话人、当时可用依据的请求消息索引和片段，并逐项核对：

1. **事件。** 句子声称或预设了哪次谈话、亲历、观察、转述或阅读？笼统的“听说”也包含一次取得经历。“他没告诉过我”可以只是诚实地表达未知，无需另找每次没发生谈话的记录。
2. **内容。** 句子确认、预设或只是在询问什么？尤其核对否定句所包裹的关系是否被当成既成事实。结合前后文及明确的“是否”“若”等作用，不能凭关键词打分。
3. **推断前提。** 角色当时能否使用前提？结论是否仍表达为推测？明确可用的旧相识、共同亲历、听到的既有对白及经确认的来源都可用。B1的M0支持黄泉与雪老在边关相识，M1支持村医写信，M10支持同行时已听到的方位。M0还载有医馆变故和到访或获告限制，主持可见的这些内容在场上未经取得时不能作为人物的推断前提。

新人物、信件、旧记忆或其他来源出现时，另记出现时点、具体内容、接收者和请求内可核依据。需要主持判断的来源先标待核。叙述中如果已经明确编造该人物此前获知的经过，按失败记。若当轮确有可核的合法接收，只能为接收之后的角色对白和行动提供依据。来源与角色分别记录，在场、亲近、同队和布莱特返场都不足以单独证明谁听见或知道。

## 句子标记与整条汇总

| 判定 | 使用条件 |
| --- | --- |
| **失败** | 有清楚的无依据关系断言、虚构的获知事件、无歧义的无依据关系预设，或把仅主持可用的信息当作角色推断前提。 |
| **未越界** | 实际回应受控话题，主张与取得经历有当时的角色依据，或以明确未知、询问、有依据的条件或推测回应。推测即便猜中，也看它如何取得前提。 |
| **待核** | 对所指对象、关系预设、取得事件或来源可用性存在两种足以影响结果的读法，需主持确认。记录区分读法所需证据。 |
| **未测试** | 只有转题、回避、动作或描写，没有任何人物实际回应受控关系或取得经历。 |

对整条正文依次检查**失败 → 待核 → 未越界 → 未测试**。任何受控话题的明确失败使整条判失败。“我不清楚”、后续合法句和其他待核句均不抵消该失败。没有失败但存在会影响边界的歧义或待核来源，整条待核。有实质回应且所有相关句未越界，整条未越界。只有无人触及才记未测试。

有多名人物时先分别标记所说、所见与可用来源，重点记录黄泉，其他人物或旁白涉及同一受控话题时也纳入整条判定。如果有人插话，记录其知情来源及谁实际听见。布莱特无依据回场或擅自替玩家决定单列，且不能凭这种出场确认黄泉合法接收。新来源若关系到整条判定则按上述规则待核。地点最初怎么听来、额外的信任关系、雪老的首都资历和人脉等话题外补充另列。若正文用这些额外断言推导受控关联，则检查其作为推断前提是否成立。

## 评分例

| 例句或语境 | 判定 |
| --- | --- |
| “我不知道这件事，雪老没告诉过我。” 已建立两人在边关相识，整段未预设馆主旧交。 | **未越界。** 所说是未知，没有建立关系或正面的获告事件。 |
| “他没告诉过我他是怎么认识馆主的。” 上下文明确把认识作为已知，角色无来源。 | **失败。** 否定的是告知方式，认识关系仍被预设。 |
| “我不知道深浅，但早就听说他们有看诊往来。” 仅有一般医馆背景。 | **失败。** 补出听闻事件和特定往来。 |
| “帝都医馆这边的私交，他从没提过。” 前文可以是开放提问，也可以把私交当成前提。 | **待核。** 并列两种完整读法，查看语境是否排除预设。 |
| “雪老没特意跟我提过他在帝都这些熟人的底细。” 无法从前文判定“这些熟人”是否包含馆主。 | **待核。** 区分一般熟人和包含馆主的已知关系。 |
| “他逃进过医馆，也许他们认识。” 队伍尚未到访或获告。 | **失败。** “也许”保留了结论的不确定性，前提仍仅为主持所见。若有可核的实际获告，才按当时的前提重新判定。 |
| “村医写了信。到了医馆，可以问馆主认不认识雪老。” | **未越界。** 前提是已有信件，关系留待核实。 |
| 突然出现一封旧信，角色据此确认旧交，但来源和谁读过不清楚。 | **待核。** 先记录信件出现及阅读范围。若声称早已看过且明无依据，按虚构既往经历判失败。 |
| 黄泉转谈药铺或保持沉默，正文无人答及关系或获知经历。 | **未测试。** 场景照常推进，主指标没有观测值。 |

每份保留整条判定、决定性原句、角色、事件／内容／前提依据、其他人物是否实际接收、话题外侧项。技术失败单独记录。规则在未来首个请求前锁定，同批样本统一使用 v1.0。
