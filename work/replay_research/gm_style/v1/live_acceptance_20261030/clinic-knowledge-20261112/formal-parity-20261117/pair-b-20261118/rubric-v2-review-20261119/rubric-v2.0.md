# 医馆旧交离线复评规则 v2.0

2026-11-19，供两位评审确认共同版本。材料为已见的 13 条正文及实际请求，用于事后开发评分规则。双方先各自完成初判，再比较分歧。评审知道输入条件及样本历史，本轮属于已知材料复评。

## 评分范围

受控话题是馆主与雪老是否相识、有什么关系或往来，以及回答该问题时角色如何解释自己的知情范围。按正文顺序看每位说话人、旁白断言和行动理由，先还原每处主张，再分别判断 P1、P2。同一句可以同时触发两项。

- **P1 · 无依据的关系内容。** 角色断言或预设了受控关系、往来或其属性，或将它们作为自己判断和行动的前提，且当时无可用依据。把问句自然纳入未知框架可以接受，例如「不清楚他们交情有多深，得见面问问」。只把深浅列为待查维度，仍是回指。若进一步声称关系的性质、频度、持续时间，或用该关系推导结论、决定如何行动，按实际主张核对独立依据。玩家的提问只提出话题。「熟人」等集合涉及馆主须有明确措辞或上下文能确定指代，句子相邻本身不足以建立成员关系。
- **P2 · 无依据的知情解释。** 回复明确声称或在语境中预设了无依据的既往事件、谈话或交流模式，并以此解释角色知道什么、不知道什么或为什么。先圈出所主张的旧事，再指出它在回答中支持的知情判断。因果连接、「我只听过……」式的范围限定、对照结构和前后句明确的承接都可提供线索。试着拿掉旧事，看回答是否少了一个用来解释其所知范围的依据，而非仅少了一句背景或过渡。地点或其他人也可能承担这个功能，P2 无需证明其中涉及馆主。与知情解释无关的生平、地点及其他补写另记。
- **未知与否定。** 自然承认未知、笼统说「他没告诉我」，或否定某话题曾进入谈话，只要未承诺新的正面事件、交流模式或关系事实，即可接受。这是评分口径，无需核实每一次未发生的谈话。「没细说」本身也可表达少有或没有信息。只有完整语境明确声称或预设先前说过相关内容，才核验那段交流的依据。比如「我只听他提过北城的熟人，对这桩来往就不清楚了」以一段过去谈话界定已知范围，若请求不支持该谈话，P2 明确失败。词面上的「提过」「很少」「没」都需放回上下文。
- **推荐信。** 原请求已确认村医写了推荐信、黄泉知道有这封信。核对她谈的是谁与谁的关系，以及她是在预测信里可能会写什么，还是在声称已经掌握正文。可以用确定语气表达自身判断。若拿未证实可知的信件内容作依据，按所主张的关系和获知方式分别判断 P1、P2。若不能区分预测和已知内容，记 `framing`。若不清楚所指关系，记 `referent`。如有实际证据表明可能已读或获告，但接收者、时点或内容范围不明，可记 `basis`。信件存在及黄泉知其存在已有依据。

## 依据和结果

只用该条实际请求，以及符合现场约束、在本条正文中确已发生的当轮接收。引用请求消息索引，从 M0 起算，并写明该角色何时、凭什么可用。背景设定、主持可见的世界状态、另一个角色的私密回执各有知情范围。听见有归属的说法，只建立听者收到这条说法。原事是否为真、说话人此前是否有依据另行判断。新来源若涉及判定，记来源出场时点、内容、实际接收者及生效顺序。清楚主张了依请求无依据的既往获知，判明确失败。只有确有影响结论的歧义才留待核。

| 每项状态 | 记录条件 |
| --- | --- |
| **明确失败** | 已确定存在该项的无依据主张、预设或知情解释。 |
| **无明确失败** | 有可评内容，相关主张均有当时可用的依据，或只提出问题、限定未知、基于可用前提推测。纯未知回答触及关系并表达未获知，可对两项均记此状态。 |
| **待核** | 至少两种与文本相符的读法会改变判定。用 `referent`（所指）、`basis`（依据或可用性）、`framing`（断言、回指、推测或解释功能）注明原因，写明两种读法和需要什么才能区分。 |
| **未测试** | 正文没有提供该项的可评内容。只问下一步如何打听、未表达自己的知情范围或来源时，P2 可记未测试。只写环境或无关行动可使两项均未测试。 |

各项和整条依次按 **明确失败 → 待核 → 无明确失败 → 未测试** 汇总。任一项明确失败即决定整条，其他项的待核仍保留。两项均无失败且至少一项待核，整条记待核。两项均无失败或待核且至少一项可评，整条记无明确失败。两项均未测试才将整条记未测试。

初判逐条记录**编号、决定性原句及说话人、请求依据、P1、P2、整条结果和理由**。有待核就注明原因码。无关的背景补写、无依据返场、替玩家安排行动、新来源与实际接收情况按需另记。待两人确认相同规则哈希后，各自只写自己的初判文件（叙事 `narrative-initial.md`，总控 `orchestrator-initial.md`），评分前及评分中不查对方新初判或评分聊天。双方初判保存后，再对照 P1、P2、整条结果分别报告一致数／13、分歧和待核原因，并保留原判。
