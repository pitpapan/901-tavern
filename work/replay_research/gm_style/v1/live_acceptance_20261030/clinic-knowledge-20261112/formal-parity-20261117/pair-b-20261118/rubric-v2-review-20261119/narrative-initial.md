## 逐条依据

M0、M1 等指该条实际请求中从 0 起算的消息。五份实际请求的 M0 都写明边关旧识及医馆一般看诊、受熟人托付的做法。医馆变故须到访或获告后才为角色所知。M1 记有村医给九雪医馆的推荐信，M3 显示黄泉知道信已带齐，M10 保留布莱特说明医馆城东方位、黄泉提议送信。各条 M11、M13 问的都是馆主与雪老有什么来往。M13 的受控知情只有 556 给布莱特单独登记旧交来源。

### 548

**P1 明确失败 · P2 明确失败 · 整条明确失败**

- 布莱特说「以往只听说他们都是帝都的老一辈人，偶尔有些托付或是看诊的来往，但具体深浅我并没有打探过。」他声称存在具体的托付或看诊往来，还给出频度和过往听闻。“以往只听说”把这些往来放入已听说的范围，“并没有打探过”只限制进一步掌握的详情。
- M0 的「馆主重视看诊与熟人托付」说的是馆主的一般做法。“逃至医馆昏迷”在同条后台资料中受「到访或获告」限制。M1、M10 只给推荐信和医馆方位，M13 中布莱特无对应回执。两项主张均缺依据。黄泉未发言，现场听见这句话不证实布莱特曾经获告。
- 话题外。两人都属于「帝都的老一辈人」也未建立。M0 的雪老履历是长期为帝国及兄弟会任事，不能用于确认在帝都的资历。

### 555

**P1 待核 · P2 明确失败 · 整条明确失败**

- 黄泉说「在边关时，雪老确实提起过帝都还有个熟识的医馆，但他没细说过与那位老馆主究竟是怎样的私交。」前半句是明确的既往谈话，“但”将它用作只知医馆、未知交情细节的解释。M0 有边关相识、后台医馆事件，M1 有推荐信，M13 中黄泉无这一获告记录。由此判 P2 明确失败。
- P1 待核 `framing`。读法一是她声称听过雪老认识一家医馆，把个人私交的问法留在未知框架内，后文「若是他们彼此相熟」支持这一读法。读法二是上下句的转折把与该馆主有私交当成已经知道，只说雪老没细讲性质，“若是”可理解为还不知两人是否熟到一定程度。需厘清后半句是在回接御临风的问题，还是承接她前半句声称的谈话、以既有私交为前提。M11 只是提问，M13 没有该人物关系的来源。
- 话题外。持推荐信说明来由有 M1、M3、M10 支持。正文没有实际递信或获得回答。

### 556

**P1 无明确失败 · P2 待核 · 整条待核**

- 黄泉说「边关那些旧事里，雪老没特意跟我提过他在帝都这些熟人的底细。只知道他在帝都待得久、认识的人多，具体跟医馆这位老馆主有什么交情，到了地方当面问，比乱猜省事。」句中未把馆主明确归为「这些熟人」，末句把馆主与雪老的关系留给当面查问。M11 只提出关系问题。M13 仅有布莱特的私下获告记录，原锚点明确御临风与黄泉均未听见，M12、M13 还明确布莱特缺席。
- P2 待核 `framing`。读法一是「没特意跟我提过」泛指雪老没向她交代此类底细，后句只是另列她自称知道的内容，未交代来源。读法二是在回顾边关旧事时，先前谈过一些帝都熟人，只未曾专门交底，后句「只知道」承接这段有限的交流以解释知情范围。需厘清「没特意」是否暗含当时有过概略谈话，以及「只知道」是否从该谈话而来。M0 支持边关相识，黄泉在 M13 没有这类谈话的依据。布莱特的私密回执即使与话题有关也不能供她使用。
- 话题外。「在帝都待得久、认识的人多」缺乏相应履历。M0 只有雪老长期为帝国及兄弟会任事，未给居住时长或人脉规模。单独的生平断言没有说明自己从何得知。
