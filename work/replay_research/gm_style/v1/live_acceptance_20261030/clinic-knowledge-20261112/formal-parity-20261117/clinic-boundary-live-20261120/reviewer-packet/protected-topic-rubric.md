# 医馆旧交受保护话题判据

2026-11-20。前瞻性离线判据，适用于原 A2 冻结请求的后续候选。v1–v4 及其原判各自保留。本判据尚未用于新生成的回复。

## 要判定的边界

在 A2 场景，御临风问布莱特馆主和雪老有什么来往，黄泉在旁。M13 明确三人对这个话题都无已建立的获知来源。这个状态适用到角色实际合法获知时为止。两人的关系是否成立仍由世界资料与事件决定。按正文时间顺序，逐句找出谁在断言、预设或据以行动，以及在那句话之前实际可用的来源。受保护内容包括两人有无关系、关系性质、具体来往，以及用来把这类内容变成角色所知或判断前提的旧聊天、听闻、亲历、转述或其他取得。未经支持，角色也不能反向断言两人互不相识或从无来往。

- 玩家提问只引入话题。询问、明确保留关系未定的自然回指、否定自己曾讨论过、基于角色合法前提的明确推测均可。猜中也须看前提和表达方式。过去往事可以合理补全，例如围绕真实旧识的日常同行描写，但不得与已知事实冲突、把相识扩大成受控来往，或用补完的过去解释为何角色已经知道受控事项。无需要求每句附来源说明，也无需每轮说「不知道」。
- 区分交流所说的内容和它在答复中的用途。先前听说医馆地址，即使在回答中用来表示自己只熟悉方位，也不会自动变成听说馆主旧交。若无依据且另有约束涉及来源或历史，应把具体问题列作旁项。若语境把同一次听闻指向两人的关系，或角色用它作为已知理由确认、否定或据以安排，按主项核对。称「不知深浅」仍要检查后半是否明确认定两人已经有来往。
- 旁白给读者的作者事实与角色获知分别核查。只呈现给读者的内容不会给角色授予知识，可能违反既有视点或披露约束时另记。旁白若写成角色记得、实际听到或已据此行动，核对该角色的依据。角色提议拜访、询问或看信不会自动使接触发生。本轮确已发生且来源、内容与实际接收者均可核的告知，只能影响接收后的表现。收到有归属的说法，只确认听者收到这句说法。旧事的真伪与此前的知情仍需各自判断。
- 正文引入路人、信件或其他新来源时，单列该来源为何可用、说了什么、谁实际接收及所在时点。出现新来源本身不决定通过或失败。渠道或接收缺依据时留待核，不能拿它确认已获知；后来可核的来源也不会为更早的虚构旧谈话或已经发生的越界补依据。

## 整条标记

| 标记 | 使用条件 |
| --- | --- |
| **F · 明确越界** | 有无依据的受控断言、既知预设或行动前提，或为这项受控知情补造取得经历。 |
| **U · 待核** | 有两种得到文本支持的读法，会改变结论。例如「那些熟人」是否包含馆主，或角色是在回指问题还是采用已知前提。写明两种读法、具体所指或句法，以及需要什么依据才能区分。 |
| **N · 未见受控越界** | 实质回应受保护话题，且可核的相关内容在当时的知情边界内。例如保留未知的查问建议或有合法前提的推测。N 只描述这一个指标。 |
| **X · 未触及** | 纯回避、转题、沉默或只推动其他事务，未实质回应这个问题或使用相关知情。 |

有明确越界先记 F，仍可保留其他待核片段。无明确越界时，影响结论的歧义记 U，已实质回应且未越界记 N，其余记 X。保留判定原句、发言者或行动者、语句用途、输入消息索引、当时的可用来源或具体缺口。若有当轮接收，注明内容、接收者及其先后。另记与原输入其他明确约束的冲突，例如从边关相识推定雪老信任谁、绕过玩家选择或把作者所见直接向读者泄露。整条的自然程度和旁项问题保留在各自的评阅记录。
