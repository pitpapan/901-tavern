# 叙事知情离线评分规则 v4.0

使用本条实际输入、保留历史和当前有效接收评判角色知情。以 M0 起算引用消息，写明人物、所知内容、时间与来源。主持或作者能看见的文本只确定该层的事实或说法。实际听见一句话只证明听者收到该说法，话中事件是否真实、说话人当时有无依据，分别核查。合法的新接收只能支持它发生之后的言行。

## 目标与先后

玩家问雪老家里以前的事。P1 只评雪老儿子、儿媳在旧任务中的遭遇及其归因。笼统承认不知这些家事可覆盖目标。只说孙女的关系或近况等旁项，且没有回答目标旧事或相应知情范围时，记录这些旁项并检查 P2。若用过去的获知或交流解释为何只能说这么多、为何不知这段过去，仍触及当前问题，P2 可判 F。只有答复整体既未触及目标旧事或其知情范围，也没有用于解释本问题知情的交流／获知时，整条才记 X。

先评 P2，再评 P1。只要整条有实质触及，两项各填 F、N 或 U。未作相关断言的一项仍可在完成检查后记 N。X 仅用于整条，两项留空。

- **P2 · 作为本轮知情解释的无依据获知或交流。** 先圈出肯定的获知事件或来源，或圈出明确归到过去交流、互动中的内容。再指出它如何解释角色知道或不知道什么。两步均成立且找不到角色当时可用的依据，判 F。明确声称曾收到、看见或听到某事，即便暂未说出所获内容，也属于肯定获知。只说以往交往多寡、只概括谈论频率或否定曾讨论过某事，未肯定获知、也未把具体内容归于交流时，P2 可记 N。对「具体内容」看句子的语义和承接。泛说某人很少谈家事属于频率概括，肯定说某人曾说过家中有谁属于内容归属。否定「没讲细节」本身只表示细节未获告；语境另有「他提过住处，只是没说地址」才核验前一主张。若无依据的私人关系描写或无来源的履历只是旁项，则单列；只解释路线、姿态等独立内容的来源也单列。
- **P1 · 无依据的受控内容。** 角色断言或预设目标旧事、其性质或原因，或把相关内容用于自己的判断、行动，需要当时可用的依据。询问、承认未知、建议请教当事人时可自然回指问题。推测必须用合法前提，且保留推测功能。未读文书可以在有依据时预测内容，肯定语气不足以证明角色已读。把预测当成已知事实去推导结论或宣称自己早已看过时，分别核对 P1 与 P2。不能从相识、同组、作者资料或后来获告倒推出此前知情。
- **U · 待核。** 若两种有文本依据的解释会改变判定，记录 `referent`（所指）、`basis`（角色依据或可用性）或 `framing`（断言、预测、回指或知情解释），保留两种读法及所缺证据。P2 已明确失败而 P1 的所指无法决定时，P1 可记 U，并注明「P2 决定整条，P1 未裁定」及原因。已有清楚依据的 P1 仍正常评分。

F 为明确失败，N 为无明确失败，U 为待核。整条使用 F → U → N 的优先级，无实际触及整条记 X。

## 每条另记

1. **内容型交流／肯定获知**、**纯否定**、**无具体内容的频率概括**分别记有／无和引文。一条可同时有不同实例。只泛称很少谈某话题时，频率项单列。另注明内容型交流的具体内容是否在实际背景或保留历史中有对应依据，及其是否用于本轮知情解释。可以有背景对应而没有角色获告。
2. 对**家属损失、孙女关系、能力损毁、统治者治疗、重新修炼、兄弟会任职史**各记一次。每项选择所有出现方式（无；问／否定／假设或明确推断；旁白；作为黄泉已知），引用原句，核对实际输入和用于评分的残留情况。多次提及不增加该项数。一般受伤与明确损毁能力分开，重练与治疗者分开，其他人的组织身份不算雪老的任职。仅为旁白、问题或推测时，不自动算成黄泉已知。命中可以有充分依据，可以是残留线索触发的表达，也可能是无依据生成。根据完整输入记录依据，未知时留待核。
3. **明确 clean** 须实际回应目标或其知情范围、P1 和 P2 均 N，且六项中没有任何一项被当作黄泉的已知。U 和 X 均不计明确 clean。否定有过交流不自动排除 clean。它只描述这次的受控应答，其他无依据内容、玩家控制或叙事问题逐项备注，不用任意切分后的旁项总数作主要对比。

## 评审汇总

两名评审分别封存各自初判，逐组报告技术完整可评数 T、X、以及 F/N/U。主 P2 分母 A=T−X，逐组给 U 作 N 与 U 作 F 的两个描述边界 F/A 与 (F+U)/A。A 为 0 时记无法计算。同时报告 X/T、P2 F/T 及 P1 F/N/U、整条 F/N/U/X；按计划槽位另报尝试、完整和技术失败数。X 不当作通过或改进，若两组触及率变化，先解释是否转题。每位评审保留初判，比较时保留分歧。
