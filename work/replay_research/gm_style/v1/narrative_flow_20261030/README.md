## 发现与调整

基线第1轮以“等着御临风做打算”收尾，第2轮又写“等待御临风迈步”，并逐人补闲置动作；第3轮普通听觉问询补出街对面可疑脚步、疑似等候或监视，随后又自行安抚。后者没有已有线索或本轮调查授权，给日常歇脚额外引入警情。基线记忆、隐私和动作执行没有失败。

实际请求已完整加载文风，问题不是上次的文风缺失或历史截断。正式入口末尾的`profile.narrationInstruction`仍只强调描述队友敌人和不替主角决定，未把已采用的自然收束、授权执行与日常场景边界落实到这一层。本批仅替换这个字段，具体前后文本见[candidate-change.json](candidate-change.json)，完整候选见[candidate-entry.js](candidate-entry.js)。这是针对当前模型的提示调整；两组随机生成不能证明基线所有问题都由旧句单独造成。

新指令承接已声明言行的客观后果及相关人物回应；应答完成即可结束，不逐人复述不变的环境/站位/闲置动作，不以等待安排交棒；普通休息和闲聊没有线索依据时，不借感官描写新增可疑人物或危险暗示。保持不代写新台词、心理、选择和承诺，不公开NPC数值，不自动开战。2757字符作者文风、六书、分类器、规则、历史设置与模型均未改变；没有加入词语黑名单或固定篇幅。
