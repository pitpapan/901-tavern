# 901 战力评估手册 Demo

2026-10-21 · 静态评估样稿

这份手册用于审阅人物卡、NPC和怪物构筑：查清资源预算，展开实际面板，选取可追溯的同类样板，并说明强项来自哪里。评估结果由**预算依据、常态数据、条件能力和来源**组成。本版先完成纸面评估，不包含战斗模拟、胜率或遭遇难度校准。

主要依据为RE《ST指南》、901现行核心、NPC／怪物模板和已整理的来源卡。文中区分**原文标注、按条文推导、901适配候选、作者粗估**；同一个数字在哪一层成立，写在它旁边。

实际应用：[主角团初始战力：静态评估](real_character/主角团初始战力_静态评估_20261022.md)，比较御临风与三名同伴的开场候选，单列补定项对结论的影响。

## 怎样使用

1. **固定对象。**写清人物、时期、形态和装备；常态、主动启动、单次爆发分别列。后期资源不能替开场补强。
2. **选预算路径。**有原卡战力就注明出处；有完整特性账就按对应构筑规则核算；只有补卡和面板时标为粗估或未定。
3. **展开卡面。**按901拆出攻击、防御、生命、动作、消耗、控制及感知，不把所有收益加成一个总分。
4. **查同类样板。**比较相同性质、相同条件的数据；写出一段可以从原文和算式复核的静态结论。

完整人物卡仍使用[901 NPC／怪物空白卡模板](npc_monster_card_template.md)。本手册补充评估方法，不另建一套人物规则。

## 五种数字分别表示什么

| 数字 | 含义 | 例子与使用方式 |
| --- | --- | --- |
| RE战斗力P | ST指南中的资源尺度，或来源卡标注 | “钢鬣狼人P15〔来源标注〕”；不是15点伤害 |
| D级特性预算 | 怪物构筑可分配的特性容量 | 1C特性可折3D；不能把“3D特性”当成“战力3” |
| D／C／B等资源等级 | 某件装备、能力或特性的等级 | 拥有B级武器不等于整个人物为B级或某个固定P |
| 901的T档 | 世界中的个人实力定位 | T1为正规士兵参照，T3为精锐战斗员参照 |
| XP | 901的成长资源，或RE原文预算输入 | 须说明使用哪套费用规则；不将当前剩余XP直接当战力 |

RE预算、T档和901面板并列记录，不建立固定互换关系。多人预算之和只表示投入总量；“十名P4”不等于“一名P40”。依据：[901核心的成长与构筑边界](../rules_fusion/901-core-rules-v0.1.md)、[追兵构筑中的人数说明](dakas_snow_pursuit_squad_candidate.md)。

## ST指南的预算规则

### 玩家资源账

RE原文先把标准建卡角色记作战斗力约1，再累计可计入的剧情资源。将原文步骤写成式子为：

`P参考＝1＋d＋(R－1000d)÷1500＋⌊X÷15⌋`

其中d为支线折算后的D级支线数，R为按指南口径计入的分数，X为计入的经验。原文对额外理财收益另作排除，不能把一切收益、已花投入和剩余余额重复累计。公式用于解释RE历史账；901已取消支线／奖励点兑换，不能把一张缺失历史账的901卡硬代入。

**算术示例：**标准建卡之后计入D支线、1000分和15XP，得到`1＋1＋0＋1＝3`。这只是原文预算算法的演示，不是给901人物补发资源。

**原文例题差异：**“B＋10000＋120XP”例题给出18。按其前文公式、B折9D计算应为`18＋2/3`；原文只明确经验项向下取整，未交代如何处理这里的分数余量。本Demo保留这处差异，不补造统一取整规则。[ST指南 玩家资源账](../../901_rules_source_library/content/RE/01_rules/04_附录/ST指南.md:23)

### 怪物和NPC的基础档

以下为**RE原文构筑路径**，其中属性是九属性、技能是RE原结构。不能删去三个属性后，直接宣布六属性人物成本完全相等。

| P | 原文直接模板摘要 | 原文XP建卡替代路径 |
| ---: | --- | ---: |
| −4 | 初始全属性1 | 0XP |
| −3 | 平均属性1；技能总数≤6；1专业、1D特性；技能上限3 | 15XP |
| −2 | 原文使用XP法 | 30XP |
| −1 | 原文使用XP法 | 45XP |
| 0 | 平均属性2、平均技能2、3专业、3D特性；单项属性／技能上限5 | 60XP |
| 1 | 平均属性3、平均技能2、3专业、6D特性；单项属性／技能上限5 | 75XP标准建卡 |

直接模板和XP建卡是替代路径，不同时领取两份收益。原文先分配平均属性与技能，再计算特性效果；不得把“初始单项上限5”误读成以后永远不能通过特性提高。[ST指南 基础档](../../901_rules_source_library/content/RE/01_rules/04_附录/ST指南.md:63)

### P不低于1时的追加特性

原文规定：以P1的6D特性为基础，每增加1战力，增加5D特性。因此本Demo按条文推导：

`D级特性总量＝6＋5×(P－1)`

| P | 总预算〔条文推导〕 | 相对P1增加 |
| ---: | ---: | ---: |
| 1 | 6D | 0D |
| 2 | 11D | 5D |
| 4 | 21D | 15D |
| 5 | 26D | 20D |
| 6 | 31D | 25D |
| 9 | 46D | 40D |

每三个同级特性可升一级：1C＝3D，1B＝9D，1A＝27D。只有在同一P1基础模板和同一追加规则下，才可反算`P＝1＋(总D特性－6)÷5`；不能拿任意成品资源的特性总量套用。

**原文例题差异：**P5例题同时写出“6＋5×5”“27D”和“1B＋2C＋7D”。这三者分别为31D、27D、22D，彼此不一致；按前文追加规则则为26D。本Demo采用条文推导的26D，标为推导值，原书例题保持原样。[ST指南 追加规则与例题](../../901_rules_source_library/content/RE/01_rules/04_附录/ST指南.md:73)

### 怎样记特性开支

| 获取内容 | ST指南的原文口径 |
| --- | --- |
| 已明确分离的一个同级特性 | 支付相应特性；已标清总容量的模板／能力组按其明示数量 |
| 未分离特性的普通兑换 | 符合原文非模板、非未开启树内技艺等条件时，通常3个同级特性 |
| 未开启技能树而获取树内技艺；或未分离特性、非武器防具且不认主的非消耗物品 | 4个同级特性 |
| 武器、防具、认主物品、魔导书专有法术 | 5个同级特性；认主武器／防具再加1个 |
| 消耗品 | 3个比消耗品高一级的特性 |

这里只是检索速查，具体对象先核原条文。例如一件注明特性数量的装备，不能又把其明价与“5个特性整件取得”重复相加。各特性须归入血统、改造、瞳术、能力组、技艺、能量或物品；优先引用已有资源。[ST指南 兑换条款](../../901_rules_source_library/content/RE/01_rules/04_附录/ST指南.md:97)

原文建议用于**直接取得攻击面数据**的特性不超过总量50%，包括范围攻击和状态点数；获取属性和技能不计入这一攻击分类。它是构筑分配指引，不能据此认定任何符合比例的怪物已经平衡。负特性只有确实能让玩家受益时才给怪物预算补偿；纯背景缺点不自动换取额外强度。[ST指南 分配与负特性](../../901_rules_source_library/content/RE/01_rules/04_附录/ST指南.md:95)

## 常态数值参考带

ST指南给出以下粗略常态基线：攻击主检定为`P＋13`，防御、三项豁免和其他相关检定为`P＋7`。

| P | 主检定DP参考 | 防御／豁免参考 |
| ---: | ---: | ---: |
| 1 | 14 | 8 |
| 2 | 15 | 9 |
| 4 | 17 | 11 |
| 6 | 19 | 13 |
| 9 | 22 | 16 |
| 15 | 28 | 22 |

这些是**RE公式参考数**，不是901卡的上下限。原文允许专精、偏科和爆发大幅偏离，并明确未包含生命、侦测、速度、射程、免疫、队友增益等。不能用“攻击18，所以P必为5”倒推评级，也不能把卡面差值直接称作战力差。[ST指南 数值参考与适用范围](../../901_rules_source_library/content/RE/01_rules/04_附录/ST指南.md:37)

## 901静态面板怎样展开

### 基础算式

| 项目 | 901计算方式 |
| --- | --- |
| 有效技能E | 主技能＋一个匹配子技能；不另加第三层普通专业 |
| 生命容量 | `max(1,2×力量＋2＋RE体积调整＋明确额外HP)`；体积5调整0 |
| 基础防御 | 敏捷、感知取低；装备、天生、闪避、格挡另列 |
| 基础速度 | 力量＋敏捷＋体积；明确速度能力另计 |
| 基础先攻／意志点上限 | 敏捷＋风度／意志＋风度；已确认异式另注明 |
| 普通力量近战攻击 | 力量＋E＋武器伤害＋适用加值－目标防御 |
| 对应普通力量近战上限 | 力量＋E＋武器伤害；以敏捷替代力量的攻击不再把力量加进上限 |

弓、枪、法术及直接伤害使用各自来源式，不套普通力量近战上限。力量自动成功不额外重复增加生命；攻击自动成功与RE附加成功的生效条件也分别记录。[901核心](../rules_fusion/901-core-rules-v0.1.md)

三种建卡路径各用自己的依据：原创901卡直接定六属性；机版来源卡按现有适配约定转换；已有901卡补全沿确认值。机版候选的旧体质承继补偿不是所有原创NPC默认享有的生命保底。[统一卡模板](npc_monster_card_template.md)、[机版适配约定](backup_npc_monster_adaptations/README.md)

### 六个评估栏

| 栏目 | 静态评估必读内容 | 正确的记录例子 |
| --- | --- | --- |
| 输出 | DP、自动成功、伤型、上限、穿透、单击或多击 | “18DP＋2自动；10L上限；标准动作” |
| 防护 | 常态／格挡防御、HP、DR、抗力、吸收、恢复 | “防御8；格挡后14另1自动；HP12” |
| 动作 | 启动、攻击、装填、格挡各占什么动作；反射锁定 | “移动拔刀＋标准攻击，不能再用同一移动动作格挡” |
| 资源 | 上限、每次消耗、恢复、持续与冷却 | “灵力5；每次1；冷却1轮；恢复另按来源” |
| 特殊影响 | 控制、感知、隐匿、飞行、召唤、免疫及条件 | “40米空气盲视，密闭障碍阻断” |
| 角色定位 | 上述能力集中在哪些用途，哪些用途依赖条件 | “近战剑士；拔刀后防御下降；可另耗动作守势” |

防御是在攻击DP端扣除；DR、抗力、吸收在伤害阶段各依条文处理。不能把它们统一相加为“总防御”，也不能把格挡、掩蔽、低先攻目标奖励和队友增益全塞进常态。每项特殊机制保留动作、条件、消耗和适用对象即可，不在本版展开战斗树。

## 演示一 核对一个预算草图

**对象：**假设采用P1基础模板、目标P2的RE怪物。这是算术练习，没有赋予任何实际角色能力。

总预算为`6＋5×(2－1)＝11D`，可写成`1C＋8D`。一种分配草图如下：

| 用途 | 预算 |
| --- | ---: |
| 直接攻击能力 | 4D |
| 防护与恢复 | 3D |
| 移动 | 2D |
| 感知 | 1D |
| 其他能力 | 1D |
| 合计 | 11D |

直接攻击占`4÷11≈36%`，符合原文不超过一半的分配建议。**当前能得到的结论是“预算算术与分配比例成立”。**还须把每笔预算填成有来源的具体特性，才能说能力购买账闭合；不能凭“防护3D”就自行发明一个防御值。

## 演示二 读一张真实来源样板

**对象：**灵魂献祭来源的哥布林，采用当前901候选卡；健康常态、不加外援。来源战力为P1，预算账本次不重新精算。

| 字段 | 数值 | 追溯方式 |
| --- | --- | --- |
| 六属性 | 力4／敏5／智1／感5／意2／风1 | 机版适配总表 |
| 生命 | 11 | `2×4＋2＝10`，来源生命承继补差1，合计11 |
| 咬／抓有效技能 | 6 | 肉搏母5＋对应子技能1 |
| 普通攻击 | 13DP＋1技能自动成功 | 力4＋有效肉搏6＋天生武器3L；力量无自动，母技能5有1自动 |
| 普通伤害上限 | 13L | 4＋6＋3；另有条件触发的第二伤害段，单列 |
| 基础防御 | 5 | min(敏5，感5) |
| 对单体攻击的特殊防护 | 攻击者−6DP | 次级集群；条件成立时叠加处理，不能永久把基础防御改成11 |
| 速度／先攻 | 14米／6 | 4＋5＋体积5；敏5＋风1 |
| 意志点 | 3 | 意2＋风1 |

其爪牙造成实际伤害后，另有1点指定能量或毒素L；范围攻击针对集群时另有增伤规则。两者的适用条件都能改变卡面含义，不能只摘“P1、13DP、11HP”当作普通哥布林。

**静态结论：**它的普通攻击基数13，比ST指南P1主检定参考14低1；但这个差值没有涵盖其技能自动、次级集群、第二伤害段和感官。评估记录应写“P1来源卡，集群防护与条件附伤型”，不据13DP下调来源评级。这里没有预测它能战胜哪名人物。

来源：[901总表](backup_npc_monster_adaptations/README.md)、[哥布林具体条目](backup_npc_monster_adaptations/lower_monsters.md:5)、[原卡与901数值对照](backup_npc_monster_adaptations/comparison.md)。

## 演示三 用于黄泉初始卡审阅

**对象：**2026-10-21的黄泉初始卡待审稿；包含补定轻甲与雷鸣剑。此示例沿稿读取，不视为已经采用。

| 评估项 | 本稿记录 |
| --- | --- |
| 预算依据 | 原团没有完整开场资源账；不填精确RE战力 |
| 常态输出 | 太刀18DP＋2自动，标准动作，上限10L |
| 拔刀 | 20DP＋2自动；先攻高于目标时另1成功；攻击后防御−2 |
| 防护 | HP12；常态防御8；满足先攻条件再＋2；移动格挡后14／16，另1技能自动 |
| 机动 | 16米；闪电狂奔的水上奔跑资格另列，不当额外米数 |
| 资源 | 灵力5；斩岩／雷鸣各1灵力、独立冷却；精神束缚代付另列代价 |
| 待审输入 | 意志与风度、轻甲、雷鸣剑开场持有属于推定／补定 |

**可写的结论：**初稿的主要投入体现在太刀技能、拔刀条件收益与灵力剑技。18DP常态和25DP的“拔刀＋全力＋意志”组合必须分开记录，后者包含支出与防御代价。其完整卡的心眼、御雷、狮子王和乱红莲不属于本次开场评估对象。

**尚不能写的结论：**“黄泉精确为RE战力5”“比佐间强多少”“对某怪物胜率多少”。本版没有用缺失预算或单项DP补出这些结果。
