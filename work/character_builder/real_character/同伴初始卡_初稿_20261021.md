# 黄泉、姜子尤、布莱特：初始卡初稿

2026-10-21｜待用户审阅｜未替换正式卡、酒馆或MVU。

黄泉、布莱特以原团首次进入帝都、第一部分#81之前为开场锚点；姜子尤采用黄金乡梦境中最早可恢复的人物数据，不据此安排他提前加入队伍。

**标记：**【原】早期原帖直接申报或主持确认；【推】结合后续强化账逆推，包含时期沿用假设；【补】本次为补全卡面提出的值或规则适配。表中“重算”表示由本稿属性、装备和能力计算，可靠程度随输入项，不冒充原团实报。

**版本选择：**本稿拟以早期实报的资源幅度为准；原帖没有完整条文时参照原人物卡与现行完整卡补全。同名RE完整版的高额加值不自动进入开场。保留现行901六属性、主／子技能、动作与生命规则；能量池沿当前已适配的公式。这里提出的是开场版本，不改封存的完整资源，也不声称旧版与RE版数值等价。

全部属性、技能已经包含本稿拥有资源的赠级与加值，不能读到血统／能力组后再加一次。攻击DP均为扣目标防御之前；自动成功单列，不直接加进DP。B为冲击、L为严重、A为恶性；伤害上限不是固定伤害。下列常态防御只针对能正常应对、且各项防护适用的攻击。

本稿展示满生命、满资源、无异常的建卡状态【补】，不是将原团T0当时的伤势和余量改写为满值。现金与未花XP未可靠恢复，不在本稿发放。
