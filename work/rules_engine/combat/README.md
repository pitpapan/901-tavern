## 文件与职责

| 文件 | 职责 |
| --- | --- |
| `catalog.mjs` | 可信人物配置、短能力条目、遭遇工厂；模型不能创建人物数值 |
| `mechanics.mjs` | 从当前属性、技能、装备及状态计算攻防、生命上限、速度、豁免；资源固定加值与属性分开 |
| `engine.mjs` | 纯函数处理动作、掷骰、伤害、防护、能量、连击、回合、召唤与状态 |
| `transitions.mjs` | 攻击宣言与受击反应的待定记录；完成选择后只结算一次 |
| `runtime.mjs` | 合法选项、真实消耗预览、知情限制、模型选择映射，以及进入／离开战斗 |
| `tavern.mjs` | 酒馆模型调用、报告、楼层状态衔接、玩家提交、失败后补发 |
| `host.mjs` / `host-ui.mjs` | 主持接入、玩家行动／反应选择框、主持补参界面和原生工具 |
| `../mvu_poc/adapter.mjs` | 唯一数值存档、版本检查、去重、读回确认；保留其他角色与 MVU 字段 |

`panel()` 和 `currentContext()` 提供程序／主持完整面板；模型使用 `decisionContext()`。后者只发送当前行动者完整面板、可见人物的公开状态、合法动作及相关能力短条目。对手的精确属性、HP、能量、防御、未展示能力默认不可见；主持明确登记 `knowledge[observer][target].stats=true` 才共享数值。`hiddenFrom` 控制不可见人物；观察到的动作只记录该能力已被展示。

预览复用实际结算，反映动作替代、能量或精神束缚代付、特殊攻击池、破甲、破魔、高速与范围内其他目标。它不是预定伤害。相同预览合并，选项用下标引用。模型只能返回选项编号，不能提交骰子、伤害、属性或 MVU 补丁。准备动作、装填和攻击的先后用短战术指导提示，仍由模型在合法选项中决策。

`generateRaw` 使用明确的本次输入、短指导及 `max_chat_history:0`，历史 operation、详细报告和全资源库不重复注入。NPC 选招期间暂停注册本宿主工具，防止主持入口被带回内部选招请求。卡内正则过滤历史计算块。数据缺项标记 `NEEDS_INPUT` 并写明字段；动作不合法标记 `UNAVAILABLE`。程序错误与网络错误直接报告，只有模型格式／选项错误有限重试。

## 反应与跨场景保存

攻击宣言后、实际掷骰前保存待定攻击，再询问符合条件的受击者是否使用伤害转换。这是当前引擎采用的交互时点，不声称原资源规定了精确时序。NPC 自己选择；玩家角色必须本地明确选择。未完成选择时不扣攻击资源、不使用真实骰源；刷新后继续同一个待定攻击。未受伤不消耗转换场景次数。

`actors` 是属性、伤势、能量等数值的唯一来源。战斗编排、待定反应与冷却位于 `battle`；装备、主持补参、箭矢与恢复限制随角色保留，离场人物不会被战斗写回删除。

战后移除本场增益、动作与连击，保留伤势、剩余能量、箭矢及压榨恢复限制。下一场从已有角色状态进入，重算先攻，跳过失去行动能力的单位。初始化只用于新隔离聊天；实际接入用 `enter()`，不把演练满状态覆盖到现有存档。

命名空间仍为 `stat_data.901_rules_poc`，提交绑定聊天、楼层、swipe、revision 与 operation ID。重复提交／补发报告只读取既有结果，不重投、不重扣；多个脚本同时写相同命名空间不在本次支持范围。

## 地图与连续战术（2026-10-21）

主持在进入场景时生成一次 JSON 几何：`battle.map` 保存米制边界、矩形或多边形地形、障碍和门。既有角色位置仍由战斗存档提供，模型不能用建图移动人物；旁观者也不能成为固定地标。只有明确封闭的场地才设置 `bounded:true`，普通绘图范围不会变成空气墙。旧聊天首次查看地图或下一次声明前补建一次，刷新不重建。

`map.mjs` 是移动、视线和路径计费的共同实现。移动接受玩家声明的 `to` 与可选 `via`，穿过实体障碍被拒绝；困难地形路段消耗双倍移动力，重叠不重复计费。完整障碍阻断攻击路线；部分掩体与高度按下文第3版处理。NPC 候选绕行与地图预览使用同一检查。

`installMap()`、`updateMap()` 沿用 operation ID、revision、保存读回。主持确认的场景变更或补参通过 `updateMap` 提交；玩家开门与破坏使用下文普通行动指令，不能调用主持接口绕过动作消耗。

`mapView()` 只交付观察者能知道的地形及可见人物的名字、位置和关系。遮挡后的单位不绘制，投影没有生命、能量或攻防字段。`map-art.mjs` 用 JavaScript 生成 SVG：方格、坐标轴、草地、树林、山壁、道路、水域、单位字标与路线都由程序绘制。`map-ui.mjs` 提供缩放、拖动、全图和定位自己，默认折叠；点击只预览路线，“写入移动声明”只填发送框，必须由玩家发送后才能结算。查看地图不调用选招、不消耗动作，也不新增主持回复。

地图第2版支持 `points` 多边形和 `rect` 矩形。`ground`、`surface` 只决定颜色与图案，通行、困难地形及视线仍由 `kind`、`blocksSight` 决定；不因画成树林或水面就擅自增加规则。显示格宽 `gridSize` 默认1.5米，可在建图数据中指定，移动与攻击仍按连续米制几何结算，不强制贴格或增加斜向移动规则。旧矩形存档直接兼容，不为重绘修改存档。

完整山道样例使用同一绘图器：`/901-narrative-combat/work/rules_engine/gm_runtime/map-reference-demo.html`。示例地形和单位仅用于展示，不接入战斗存档。2026-10-21方格版相关回归97项通过，真实酒馆刷新、路线草稿与状态不变验证见叙事测试候选包的 `verification.md`。

`tactics.mjs` 保存 NPC 最近六次实际动作与意图。移动候选必须改善接战、射击、掩护或恢复；贴身近战不会因还有移动动作而自动后退。可直接接战时优先保留同等收益的最短路线，避免格挡抢占接近后攻击的动作；健康尚可且上轮接近计划未完成、当前轮尚未行动时，不提供原地结束的无效选项。恢复、远程拉距及真实遮挡后的撤离仍保留。玩家声明不受 NPC 候选筛选限制。

### 地形实战补足（2026-10-21）

`transitions.mjs`在实际结算后更新观察者的lastSeen：移动途中以遮挡边界计算最后可见点，不记录隐藏终点，遮挡后的新能力也不传播。失去目标后NPC可查探最后目击位置；到达仍不可见则标为已查探，停止沿旧位置追踪。`decisionContext`单独标记这些过时位置，不将其列成当前可见目标。玩家声明上下文保留已知身份与目击记录，但始终不共享他人的数值。

### 第5项：地图互动（2026-10-22）

沿用现有的声明 → `act` → `settleCombat` → MVU → 地图与叙述流程。点击门或可破坏障碍只生成声明草稿；玩家发送后，才消耗动作和更新地形。完整自身面板仍在 MVU 界面显示；回复末尾由程序依据本次已保存操作，明确附上玩家实际受到的伤害类型、点数和负面状态变动（含解除与伤势减值加重），并简列仍生效的其他负面状态。这段结算说明不由模型猜测，不把“发麻”等修辞自动当作麻痹，也不重报历史结算。模型正文及公开地图不包含队友／敌人数值、物体耐久或硬度。事件保存当时的可见人物名单，开门后不会倒过来公开此前遮挡中的行动。

| 行为 | 本次实现 |
| --- | --- |
| 部分掩体 | `coverDegree` 为 `slight/partial/substantial`，对应少许／部分／大量，防御加值为 2／4／8。攻击连线穿过该掩体才生效，同类取最高。部分掩体不封死视线与效果线，但仍阻挡走穿。玩家防御方式未声明前仍不计算防御。 |
| 高低差 | 可通行高台为 `zone + elevation`；坡道或阶梯为 `zone + ramp:{from:[x,y,z],to:[x,y,z]}`，置于高台之后。寻路经过坡道两端，计入斜面实际长度；不允许直接跨越落差。高度影响武器射程、视线及掩体，没有额外攻防奖励。 |
| 开关门 | `{abilityId:'door',featureId:'门ID',open:true/false}`，相邻 1.5 米，移动等效动作。锁门不能直接打开，有人占据门口不能关门；成功立即更新通行和遮挡。 |
| 攻击障碍 | `{abilityId:'destroy',featureId:'障碍段ID'}`，标准攻击动作，共用普通武器攻击的骰池、上限与箭矢消耗；静止物体无主动防御，先限制上限再减硬度。只伤及指定障碍段，不穿透攻击后方人物，不叠加只针对活物的异常状态。 |
| 破坏写回 | 独立障碍段的 `durability:{current,max,hardness,source}` 必须有场景参数来源。耐久归零标记 `destroyed:true`，该段不再阻挡，地图显示残迹。不把整片山壁自动算成一扇门。 |

门锁与耐久可由主持通过已有 `updateMap({changes:[{id,locked,durability}],...})` 补齐；这是场景录入，不是玩家开门或攻击指令。生成地图的模型可以转写场景明确的锁门，但其输出的耐久和已破坏状态会被丢弃。没有耐久的障碍保持未知，不从材质名称自动推算。

高度为连续平面上的单层高程；默认站姿视线参考高度为地面以上 1.5 米，这是几何近似，可用于当前人形交战，不代表通用体型规则。不支持桥上桥下重叠楼层。攀爬、跳跃、坠落、开锁仍需各自的声明与规则适配，不会偷偷改为普通移动。
